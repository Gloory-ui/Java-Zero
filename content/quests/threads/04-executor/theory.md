## Зачем это нужно

Создавать поток на каждую мелкую задачу дорого: поток — тяжёлый объект операционной системы. Сервер с тысячей запросов в секунду так долго не проживёт. **Пул потоков** держит несколько готовых потоков и раздаёт им задачи из очереди.

## Как это работает

```java
import java.util.concurrent.*;

ExecutorService pool = Executors.newFixedThreadPool(3);   // три рабочих потока
Future<Integer> answer = pool.submit(() -> 6 * 7);        // задача с результатом
System.out.println(answer.get());                         // ждём и берём: 42
pool.shutdown();                                          // новых задач не принимать
pool.awaitTermination(1, TimeUnit.SECONDS);               // дождаться уже принятых
```

-   `submit(задача)` отдаёт задачу пулу и сразу возвращает `Future` — «обещание результата».
-   Задача, которая возвращает значение, — это `Callable`. Лямбда `() -> 6 * 7` подходит.
-   `future.get()` ждёт, пока задача выполнится, и возвращает результат. Бросает проверяемые `InterruptedException` и `ExecutionException`.
-   Пул обязательно закрывают через `shutdown()`. Иначе его потоки не дадут программе завершиться.

## Разбор: что выведет программа

```java
ExecutorService pool = Executors.newFixedThreadPool(2);
List<Future<String>> futures = new ArrayList<>();
for (String w : List.of("а", "б")) {
    futures.add(pool.submit(() -> w.toUpperCase()));
}
for (Future<String> f : futures) {
    System.out.print(f.get());
}
pool.shutdown();
```

Задачи могут выполниться в любом порядке, но результаты читаются по списку `futures`:

```text
АБ
```

### Что должна вывести программа

```text
5! = 120
6! = 720
7! = 5040
8! = 40320

Пул закрыт: true
```
