## Частые грабли

-   **`get` + `set` вместо одной операции.** `sum.set(sum.get() + x)` — снова три шага, и гонка вернётся. Используй `addAndGet`.
-   **`volatile` для счётчика.** `volatile int count; count++` всё равно теряет прибавления: `volatile` отвечает за видимость, а не за атомарность.
-   **Начальный максимум 0.** Для отрицательных чисел максимум 0 будет неверным. Надёжнее начинать с `Integer.MIN_VALUE`.
