## Зачем это нужно

«Возьми слова длиннее трёх букв, сделай их заглавными и отсортируй» — в обычном коде это цикл, условие, новый список и сортировка. **Stream API** записывает то же самое как конвейер: данные проходят через цепочку шагов, и каждый шаг — одно действие.

## Как это работает

```java
List<String> result = words.stream()      // источник: поток элементов списка
    .filter(w -> w.length() > 3)          // оставить подходящие
    .map(String::toUpperCase)             // превратить каждый
    .sorted()                             // отсортировать
    .toList();                            // собрать в список
```

-   `stream()` делает из коллекции **поток**. Исходный список он не меняет.
-   Промежуточные шаги — `filter`, `map`, `sorted`, `distinct` — возвращают новый поток, и их можно цеплять.
-   Конечный шаг запускает конвейер и выдаёт результат: `toList()` — список, `count()` — число элементов, `forEach(...)` — действие для каждого.
-   Без конечного шага конвейер вообще не работает: шаги ленивые.
-   Поток одноразовый: после конечного шага его нельзя использовать снова.

## Разбор: что выведет программа

```java
List<Integer> nums = List.of(5, 12, 7, 20);
List<Integer> result = nums.stream()
    .filter(n -> n > 6)
    .map(n -> n * 10)
    .toList();
System.out.println(result + " " + nums);
```

Пятёрка отсеялась, остальные умножились. Исходный список не изменился:

```text
[120, 70, 200] [5, 12, 7, 20]
```

## Твоё задание

Для списка слов выведи через потоки:

-   слова длиннее 3 букв заглавными, по алфавиту;
-   сколько слов начинается на «п»;
-   длины всех слов в исходном порядке.

### Что должна вывести программа

```text
[ОБЛАКО, ПАРУС, ПЕРО, ПОЛЕ]
На «п»: 4
Длины: [4, 3, 5, 3, 4, 6, 3]
```
