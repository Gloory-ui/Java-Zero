## Зачем это нужно

Таблица результатов олимпиады: лучшие трое, список разных баллов, остальные участники. Это одна задача на весь Stream API: сортировка по двум ключам, обрезка, пропуск, уникальные значения. Собери всё вместе.

## Как это работает

Ещё несколько шагов конвейера:

```java
stream.sorted(компаратор)     // сортировка по правилу
stream.limit(3)               // только первые 3
stream.skip(3)                // пропустить первые 3
stream.distinct()             // убрать повторы
```

Компаратор для записи строится как в квесте про коллекции:

```java
Comparator<Result> order = Comparator.comparingInt(Result::score).reversed()
    .thenComparing(Result::name);   // по убыванию баллов, при равенстве — по имени
```

`Comparator.reverseOrder()` — естественный порядок наоборот, например для чисел по убыванию.

Нумеровать результаты удобно обычным циклом по индексам готового списка.

## Разбор: что выведет программа

```java
List<Integer> nums = List.of(5, 3, 5, 9, 1, 9);
System.out.println(nums.stream().distinct().sorted().skip(1).limit(2).toList());
```

Без повторов: 5, 3, 9, 1. По возрастанию: 1, 3, 5, 9. Пропускаем 1, берём два:

```text
[3, 5]
```

## Твоё задание

Прочитай строки «имя балл» до конца ввода в список записей `Result`. Выведи:

-   тройку лучших — по убыванию баллов, при равенстве по имени, с номерами мест;
-   разные баллы по убыванию;
-   имена остальных участников в том же порядке.

### Что должна вывести программа

Для ввода из примера:

```text
1. Аня — 90
2. Гоша — 90
3. Даша — 81
Разные баллы: [90, 81, 72, 55]
Остальные: [Вика, Ева, Борис]
```
