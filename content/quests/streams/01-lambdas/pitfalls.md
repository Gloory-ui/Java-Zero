## Частые грабли

-   **Блок без `return`.** `(a, b) -> { a * b; }` — ошибка: в фигурных скобках результат возвращают явно, `{ return a * b; }`.
-   **Изменение внешней переменной.** `count++` внутри лямбды для локальной переменной — «Local variable count defined in an enclosing scope must be final or effectively final».
-   **Два абстрактных метода.** Лямбдой можно реализовать только интерфейс с одним абстрактным методом. `@FunctionalInterface` сразу сообщит, если методов больше.
