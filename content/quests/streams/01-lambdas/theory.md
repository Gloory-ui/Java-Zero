## Зачем это нужно

Калькулятору нужны операции: сложить, вычесть, найти максимум. Раньше для каждой пришлось бы писать отдельный класс с одним методом. **Лямбда** — это короткая запись такого метода прямо на месте: «вот параметры, вот что с ними сделать».

## Как это работает

Лямбда реализует **функциональный интерфейс** — интерфейс ровно с одним абстрактным методом:

```java
@FunctionalInterface                 // компилятор проверит, что метод один
interface Check {
    boolean test(int x);
}

Check positive = x -> x > 0;         // параметр -> результат
Check even = (int x) -> x % 2 == 0;  // тип параметра можно указать
positive.test(5);                    // true
```

-   Слева от `->` параметры: один без скобок, несколько — в скобках `(a, b)`, ни одного — `()`.
-   Справа — выражение, его значение и есть результат. Если нужно несколько строк, пишут блок с `return`:

```java
Check prime = x -> {
    for (int d = 2; d * d <= x; d++) {
        if (x % d == 0) return false;
    }
    return x > 1;
};
```

-   Лямбда видит переменные вокруг, если они не меняются после присваивания.

## Разбор: что выведет программа

```java
Check[] checks = { x -> x > 0, x -> x % 2 == 0 };
for (Check c : checks) {
    System.out.print(c.test(-4) + " ");
}
```

−4 не положительное, но чётное:

```text
false true
```

## Твоё задание

Интерфейс `Operation` и словарь операций уже есть, сложение добавлено. Допиши лямбдами:

-   «-» — разность;
-   «*» — произведение;
-   «max» — большее из двух;
-   «pow» — `a` в степени `b` через цикл в блочной лямбде.

Программа применяет каждую операцию к 12 и 5.

### Что должна вывести программа

```text
12 + 5 = 17
12 - 5 = 7
12 * 5 = 60
12 max 5 = 12
12 pow 5 = 248832
```
