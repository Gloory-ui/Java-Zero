## Зачем это нужно

Сумма, среднее, максимум, произведение — всё это «свёртка» многих значений в одно. У числовых потоков для частых свёрток есть готовые методы, а для любой своей — `reduce`.

## Как это работает

Для чисел есть особые потоки `IntStream`. Они не упаковывают числа в `Integer` и умеют считать:

```java
IntStream.rangeClosed(1, 5)            // 1, 2, 3, 4, 5 (range(1, 5) — без пятёрки)
    .map(x -> x * 10)                  // 10, 20, 30, 40, 50
    .sum();                            // 150

List<Integer> list = List.of(4, 8);
list.stream().mapToInt(Integer::intValue).average();  // OptionalDouble[6.0]
list.stream().mapToInt(Integer::intValue).max();      // OptionalInt[8]
```

-   `mapToInt` превращает поток объектов в `IntStream`.
-   `average()` и `max()` возвращают «может быть, значение»: у пустого потока среднего нет. Значение достают через `orElse(запасное)` или `getAsDouble()`.
-   `reduce(начальное, (накопленное, элемент) -> новое)` сворачивает поток по своему правилу:

```java
int product = IntStream.rangeClosed(1, 4).reduce(1, (acc, x) -> acc * x);  // 24
```

## Разбор: что выведет программа

```java
int s = IntStream.range(0, 4).reduce(0, (acc, x) -> acc + x * x);
System.out.println(s);
```

`range(0, 4)` — это 0, 1, 2, 3. Сумма квадратов 0 + 1 + 4 + 9:

```text
14
```
