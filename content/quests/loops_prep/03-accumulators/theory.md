## Зачем это нужно

«Сложить все чётные», «посчитать количество простых», «найти сумму оценок» — в каждой такой задаче цикл по одному значению собирает общий итог. Переменная, которая копит итог, называется **накопителем**.

## Как работает накопитель

1. Создать переменную **до** цикла и дать ей стартовое значение: для суммы 0, для счётчика 0.
2. Внутри цикла прибавлять к ней очередное значение.
3. После цикла вывести итог.

```java
int sum = 0;                     // 1. до цикла
for (int i = 1; i <= 5; i++) {
    sum += i;                    // 2. то же, что sum = sum + i
}
System.out.println(sum);         // 3. после цикла: 15
```

Похожие короткие операторы: `-=`, `*=`, `/=`. Счётчик увеличивают так: `count++`.

## Раздельные суммы

Если нужно две суммы, заводят два накопителя, а условие решает, в какой прибавить:

```java
if (i % 2 == 0) {
    sumEven += i;
} else {
    sumOdd += i;
}
```

## Разбор: что выведет программа

```java
int sum = 0;
for (int i = 1; i <= 4; i++) {
    sum += i * i;
}
System.out.println(sum);
```

| `i` | `i * i` | `sum` после круга |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 4 | 5 |
| 3 | 9 | 14 |
| 4 | 16 | 30 |

Выведется `30` — сумма квадратов от 1 до 4.

### Что должна вывести программа
