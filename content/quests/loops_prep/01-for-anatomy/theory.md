## Зачем это нужно

Вывести числа от 1 до 10 можно десятью командами `println`. А от 1 до 1000? Цикл повторяет одни и те же команды столько раз, сколько нужно. Без циклов не обходится почти ни одна задача.

## Как устроен цикл for

`for` используют, когда число повторений известно заранее:

```java
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}
```

В заголовке три части через точку с запятой:

| Часть | Пример | Когда выполняется |
|---|---|---|
| старт | `int i = 1` | один раз перед циклом: заводит счётчик |
| условие | `i <= 10` | перед каждым кругом: если `false`, цикл заканчивается |
| шаг | `i++` | после каждого круга: `i` растёт на 1 |

Команды в фигурных скобках — **тело** цикла, один «круг». `i++` — короткая запись `i = i + 1`.

## Порядок выполнения

1. `i = 1`, проверка `1 <= 10` — да, тело печатает 1, шаг: `i = 2`.
2. Проверка `2 <= 10` — да, печатает 2, `i = 3`.
3. … так до `i = 10`: печатает 10, шаг: `i = 11`.
4. Проверка `11 <= 10` — нет, цикл закончен.

Счётчик объявлен в заголовке, поэтому после цикла переменной `i` уже нет.

## Границы

Самая частая ошибка — граница на единицу. `i <= 10` включает 10, `i < 10` — нет. Сколько раз выполнится цикл, считай так: от старта до последнего значения, для которого условие ещё истинно.

## Разбор: что выведет программа

```java
for (int i = 2; i <= 8; i += 3) {
    System.out.println(i);
}
```

`i += 3` — шаг по три. Значения: 2, 5, 8. Следующее, 11, условие не проходит. Программа выведет `2`, `5`, `8`.
