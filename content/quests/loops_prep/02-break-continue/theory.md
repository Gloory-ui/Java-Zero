## Зачем это нужно

Иногда цикл должен пропустить неподходящее значение или остановиться раньше времени. В задании 2 КТ 1 нужно и то и другое: пропустить кратные 5 и 7 и остановиться на 41. Для этого есть `continue` и `break`.

## Два оператора

-   `continue` — **пропустить остаток текущего круга** и перейти к следующему: сразу выполняется шаг `i++`, потом проверка условия.
-   `break` — **выйти из цикла совсем**: выполнение продолжится со строки после закрывающей скобки цикла.

```java
for (int i = 1; i <= 20; i++) {
    if (i == 15) break;        // на 15 цикл заканчивается
    if (i % 2 == 0) continue;  // чётные пропускаем
    System.out.println(i);     // сюда доходят только нечётные меньше 15
}
```

Короткая запись `if (условие) команда;` без фигурных скобок допустима, когда команда одна. В задачах подлиннее ставь скобки.

## Порядок проверок решает всё

Команды в теле выполняются сверху вниз. Если `break` стоит **после** вывода, стоп-число успеет напечататься. Поэтому стоп-проверку и пропуски ставят в начало тела, а вывод — в конец.

## Разбор: что выведет программа

```java
for (int i = 1; i <= 6; i++) {
    if (i % 3 == 0) continue;
    System.out.println(i);
    if (i == 4) break;
}
```

| `i` | `i % 3 == 0`? | Что происходит |
|---|---|---|
| 1 | нет | печатает 1 |
| 2 | нет | печатает 2 |
| 3 | да | `continue`, вывод пропущен |
| 4 | нет | печатает 4, потом `break` |

Выведется `1`, `2`, `4`. Здесь `break` стоит после вывода, поэтому 4 напечаталось.

## Твоё задание

Напиши цикл от 1 до 20. Если число равно 15 — `break`. Если кратно 3 (`i % 3 == 0`) — `continue`. Иначе выведи число.
