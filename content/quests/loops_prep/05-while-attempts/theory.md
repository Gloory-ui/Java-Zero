## Зачем это нужно

`for` удобен, когда заранее известно, сколько будет кругов. А если цикл должен идти, **пока** выполняется условие — пока пользователь не угадал число, пока не кончились попытки? Для этого есть `while`. Он понадобится, например, в игре «Угадай число».

## Как устроен while

```java
int attempts = 0;
int maxAttempts = 3;

while (attempts < maxAttempts) {     // проверка перед каждым кругом
    attempts++;
    System.out.println("Попытка " + attempts);
}
```

-   Условие проверяется **перед** каждым кругом. Если оно сразу ложно, тело не выполнится ни разу.
-   Счётчик заводят **до** цикла, а меняют **внутри**. Если его не менять, условие навсегда останется истинным — бесконечный цикл. Лаборатория остановит такую программу через 3 секунды.

`for` и `while` взаимозаменяемы. Запись `for (int i = 0; i < 3; i++)` делает то же, что `while` с отдельным счётчиком. Выбирай, что понятнее читать.

## Почему attempts++ в начале тела

Счётчик увеличивается до печати, поэтому первая строка — «Попытка 1», а не «Попытка 0». Если поставить `attempts++` после `println`, номера начнутся с нуля.

## Разбор: что выведет программа

```java
int n = 20;
while (n > 3) {
    n = n / 2;
}
System.out.println(n);
```

| Проверка | Условие | `n` после круга |
|---|---|---|
| 20 > 3 | да | 10 |
| 10 > 3 | да | 5 |
| 5 > 3 | да | 2 |
| 2 > 3 | нет | цикл закончен |

Выведется `2`.
