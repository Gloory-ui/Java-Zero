## Зачем это нужно

Таблица — это строки и столбцы. Один цикл проходит одну линию, а для сетки нужен цикл внутри цикла. На вложенных циклах построены таблица умножения (задание 1 КТ 1) и перебор делителей для простых чисел (задание 6).

## Как это работает

```java
for (int i = 1; i <= 3; i++) {          // внешний цикл: строки
    for (int j = 1; j <= 3; j++) {      // внутренний: столбцы в строке
        System.out.print(i * j + "\t");
    }
    System.out.println();               // конец строки таблицы
}
```

-   На **каждом** круге внешнего цикла внутренний проходит **целиком**, от начала до конца. 3 строки по 3 столбца — тело внутреннего цикла выполнится 9 раз.
-   `System.out.print` печатает без перевода строки, поэтому числа одной строки встают рядом.
-   `"\t"` — табуляция: выравнивает числа по колонкам.
-   `System.out.println()` без аргументов только переводит строку. Он стоит **внутри внешнего** цикла, но **после внутреннего**.

## Разбор: как выполняется

| Круг внешнего | Внутренний проходит | Что печатается |
|---|---|---|
| `i = 1` | `j = 1, 2, 3` | `1 2 3`, потом перевод строки |
| `i = 2` | `j = 1, 2, 3` | `2 4 6`, потом перевод строки |
| `i = 3` | `j = 1, 2, 3` | `3 6 9`, потом перевод строки |

Счётчики называют по-разному: `i` для строк, `j` для столбцов. Если во внутреннем цикле снова написать `int i`, компилятор скажет, что переменная объявлена дважды.

## Твоё задание

Напиши вложенные циклы от 1 до 3 и выведи таблицу умножения 3 × 3. Числа в строке разделяй табуляцией `\t`.

### Что должна вывести программа

```text
1	2	3	
2	4	6	
3	6	9	
```

Число пробелов и табуляций между значениями не важно: проверка сравнивает сами значения. После сдачи посмотри трассировку: она покажет, в каком порядке заполняются клетки.
