## Зачем это нужно

Иногда цикл ищет ответ на вопрос «да или нет»: есть ли у числа делитель, встретилось ли нужное значение. Ответ запоминают в переменной-**флаге** типа `boolean`. Проверка на простоту — основа задания 6 КТ 1.

## Простое число

**Простое** число больше 1 делится без остатка только на 1 и на само себя: 2, 3, 5, 7, 11… Единица простой не считается: у неё один делитель, а нужно ровно два.

## Алгоритм с флагом

1. Сначала предполагаем, что число простое: `boolean isPrime = true;`.
2. Перебираем возможные делители от 2 до `n - 1`.
3. Нашли делитель — число составное: `isPrime = false;` и `break`, дальше искать незачем.
4. После цикла смотрим на флаг.

```java
int n = 9;
boolean isPrime = true;

for (int j = 2; j < n; j++) {
    if (n % j == 0) {
        isPrime = false;   // нашёлся делитель
        break;
    }
}
if (isPrime) {
    System.out.println("Простое");
}
```

`if (isPrime)` — то же, что `if (isPrime == true)`: флаг сам по себе `true` или `false`.

## Разбор: что происходит для 9

| `j` | `9 % j` | Что делаем |
|---|---|---|
| 2 | 1 | делителя нет, идём дальше |
| 3 | 0 | делитель! `isPrime = false`, `break` |

Цикл остановился на 3, флаг `false`, «Простое» не печатается. Для 7 ни один `j` от 2 до 6 не делит нацело, флаг остаётся `true`.

Перебирать можно и до корня: `j * j <= n`. Если у числа есть делитель больше корня, парный к нему меньше корня и уже найден. На защите это частый вопрос.

## Твоё задание

Проверь число `n = 7` на простоту циклом от 2 до `n - 1`. Если простое — выведи `Простое`.
