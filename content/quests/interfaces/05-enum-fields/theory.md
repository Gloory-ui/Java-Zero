## Зачем это нужно

У размера кофе есть не только имя, но и подпись для меню и цена. Держать их в отдельных массивах неудобно: легко перепутать порядок. У `enum` могут быть **поля, конструктор и методы** — тогда данные живут рядом с константой.

## Как это работает

```java
enum Planet {
    MERCURY("Меркурий", 0.38),
    EARTH("Земля", 1.0),
    MARS("Марс", 0.38);                 // после списка — точка с запятой

    private final String label;
    private final double gravity;

    Planet(String label, double gravity) {   // конструктор без public
        this.label = label;
        this.gravity = gravity;
    }

    String label() { return label; }
    double weight(double kg) { return kg * gravity; }
}
```

-   В скобках после константы — аргументы конструктора.
-   Список констант заканчивается `;`, дальше идут поля и методы.
-   Конструктор `enum` вызывает только сама Java, по одному разу для каждой константы. `new Planet(...)` написать нельзя.
-   `Planet.valueOf("MARS")` превращает строку в константу: так удобно читать значения из ввода.

`while (sc.hasNext())` читает слова, пока ввод не закончится: `hasNext()` возвращает `false`, когда слов больше нет.

## Разбор: что выведет программа

```java
Planet p = Planet.valueOf("MARS");
System.out.println(p.label() + ": " + p.weight(50));
```

У Марса `gravity = 0.38`, а 50 × 0.38 = 19.0:

```text
Марс: 19.0
```

## Твоё задание

Дай перечислению `Size` поля `label` и `price`:

-   `SMALL` — «Маленький», 150;
-   `MEDIUM` — «Средний», 200;
-   `LARGE` — «Большой», 250.

Программа читает размеры до конца ввода. Для каждого печатает подпись и цену, в конце — итог.

### Что должна вывести программа

Для ввода `MEDIUM LARGE SMALL LARGE`:

```text
Средний: 200
Большой: 250
Маленький: 150
Большой: 250
Итого: 850
```
