## Зачем это нужно

Интерфейс `Priced` реализуют десять классов. Ты добавляешь в него новый метод — и все десять перестают компилироваться, пока в каждом не появится реализация. Чаще всего она у всех одинаковая. Поэтому в интерфейсе можно написать метод **с телом**: он называется `default`-методом, и классы получают его готовым.

## Как это работает

```java
interface Greeter {
    String name();

    default String greet() {             // готовая реализация
        return "Привет, " + name() + "!";
    }
}

class Cat implements Greeter {
    public String name() { return "Мурка"; }
    // greet() берётся из интерфейса
}

class Robot implements Greeter {
    public String name() { return "R2"; }

    @Override
    public String greet() {              // своя версия вместо общей
        return "БИП. Я " + name();
    }
}
```

-   Слово `default` разрешает методу интерфейса иметь тело.
-   Внутри `default`-метода можно звать другие методы интерфейса: `name()` у каждого класса свой.
-   Класс может переопределить `default`-метод, если общая версия ему не подходит.
-   Ещё бывают `static`-методы интерфейса. Их вызывают через имя интерфейса: `Greeter.hello()`.

## Разбор: что выведет программа

```java
Greeter[] all = { new Cat(), new Robot() };
for (Greeter g : all) {
    System.out.println(g.greet());
}
```

`Cat` пользуется общей версией, `Robot` — своей:

```text
Привет, Мурка!
БИП. Я R2
```

## Твоё задание

В интерфейсе `Priced` есть `title()` и `price()`. Добавь `default`-метод `int withDiscount(int percent)`: цена минус `percent` процентов, то есть `price() - price() * percent / 100`.

На кофе скидок нет: в классе `Coffee` переопредели `withDiscount`, чтобы он возвращал обычную цену.

В `main` для каждого товара выведи название, цену и цену со скидкой 10% через стрелку `→`.

### Что должна вывести программа

```text
Книга: 500 → 450
Кофе: 200 → 200
Торт: 850 → 765
```
