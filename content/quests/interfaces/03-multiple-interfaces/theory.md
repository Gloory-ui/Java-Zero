## Зачем это нужно

Утка и плавает, и летает. Пингвин только плавает, самолёт только летает. Одного родительского класса на всех не придумать, а интерфейсов у класса может быть сколько угодно. Каждый интерфейс — отдельная способность.

## Как это работает

```java
interface Swimmer { void swim(); }
interface Flyer { void fly(); }

class Goose implements Swimmer, Flyer {   // две способности через запятую
    public void swim() { System.out.println("Гусь плывёт"); }
    public void fly() { System.out.println("Гусь летит"); }
}
```

Проверить, есть ли у объекта способность, помогает `instanceof`:

```java
Object thing = new Goose();
if (thing instanceof Flyer f) {   // проверка и новая переменная f сразу
    f.fly();
}
```

-   `thing instanceof Flyer` — `true`, если объект реализует `Flyer`.
-   `instanceof Flyer f` заодно заводит переменную `f` типа `Flyer`. Внутри `if` у неё можно вызвать `fly()`, приводить тип вручную не нужно.
-   `Object` — родитель всех классов, поэтому в массив `Object[]` помещается что угодно.

## Разбор: что выведет программа

```java
Object[] things = { new Goose(), "строка" };
for (Object t : things) {
    if (t instanceof Swimmer s) s.swim();
    if (t instanceof Flyer f) f.fly();
}
```

Гусь проходит обе проверки. Строка не умеет ни плавать, ни летать, поэтому для неё ничего не печатается:

```text
Гусь плывёт
Гусь летит
```

## Твоё задание

Пингвин и самолёт готовы. Утка пока только плавает: пусть `Duck` реализует и `Swimmer`, и `Flyer`. Утка летит с текстом «Утка летит».

В `main` пройди по массиву `things`. Если объект умеет плавать, вызови `swim()`. Если умеет летать, вызови `fly()`.

### Что должна вывести программа

```text
Утка плывёт
Утка летит
Пингвин плывёт
Самолёт летит
```
