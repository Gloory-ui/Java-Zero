## Частые грабли

-   **`getName()` вместо `name()`.** У записи геттер называется как компонент: `s.name()`. Метода `getName()` нет, и компилятор скажет «The method getName() is undefined».
-   **Попытка изменить поле.** `this.score = 100;` в обычном методе записи — ошибка: поля `final`. Поправить значение можно только в компактном конструкторе, присвоив параметру `score = 100;`.
-   **Скобки у компактного конструктора.** `Student(String name, int score) { ... }` — уже полный конструктор, и тогда поля придётся присваивать самому. Компактный пишется без скобок: `Student { ... }`.
