## Зачем это нужно

Абстрактный класс даёт наследникам общий код, но родитель у класса может быть только один. Часто общий код и не нужен, нужен договор: «у этого объекта есть метод `area()`». Такой договор в Java называется **интерфейсом**. Прямоугольник и треугольник друг другу не родственники, но площадь умеют считать оба.

## Как это работает

```java
interface Shape {
    double area();       // только заголовок, тела нет
    String name();
}

class Square implements Shape {
    double side;

    Square(double side) {
        this.side = side;
    }

    @Override
    public double area() {
        return side * side;
    }

    @Override
    public String name() {
        return "Квадрат";
    }
}
```

-   `interface` перечисляет методы без тела. Все они `public`, даже если слово не написано.
-   `implements Shape` — класс подписывает договор и обязан реализовать **все** методы интерфейса. Пропустишь один — ошибка компиляции.
-   В классе такие методы тоже `public`: сузить доступ, который дал интерфейс, нельзя.
-   Объект интерфейса создать нельзя, `new Shape()` не скомпилируется. Зато переменная типа `Shape` хранит любой объект, который его реализует.

Цикл `for (Shape s : shapes)` называется for-each: он по очереди кладёт в `s` каждый элемент массива, индексы не нужны.

## Разбор: что выведет программа

```java
Shape[] shapes = { new Square(2), new Square(5) };
double total = 0;
for (Shape s : shapes) {
    System.out.println(s.name() + ": " + s.area());
    total += s.area();
}
System.out.println("Всего: " + total);
```

Цикл не знает, какие именно фигуры лежат в массиве. Он зовёт `area()` у каждой, и срабатывает метод её класса:

```text
Квадрат: 4.0
Квадрат: 25.0
Всего: 29.0
```

## Твоё задание

Интерфейс `Shape` уже объявлен. Пусть его реализуют два класса:

-   `Rect` — прямоугольник со сторонами `w` и `h`, имя «Прямоугольник», площадь `w * h`;
-   `Triangle` — треугольник с основанием `base` и высотой `height`, имя «Треугольник», площадь `base * height / 2`.

В `main` положи в массив `Shape[]` прямоугольник 3 × 4 и треугольник с основанием 3 и высотой 4. Выведи имя и площадь каждой фигуры, а в конце — сумму площадей.

### Что должна вывести программа

```text
Прямоугольник: 12.0
Треугольник: 6.0
Сумма площадей: 18.0
```
