## Зачем это нужно

Бот в чате получает строки «ADD 5», «PRINT», «END». Чтобы выполнить команду, строку режут на слово-команду и аргумент, превращают аргумент в число и выбирают действие. Это настоящий маленький интерпретатор, и строятся так любые консольные меню.

## Как это работает

```java
String line = "  mul   3 ";
String[] parts = line.trim().split("\\s+");   // ["mul", "3"]
String cmd = parts[0].toUpperCase();          // "MUL" — регистр не важен
int arg = Integer.parseInt(parts[1]);         // 3 — строку в число
```

`switch` умеет выбирать по строке. Сравнение внутри идёт через `equals`, так что регистр важен — поэтому команду сначала приводят к заглавным:

```java
switch (cmd) {
    case "ADD" -> value += arg;
    case "MUL" -> value *= arg;
    default -> System.out.println("Неизвестная команда: " + cmd);
}
```

Читать строки до конца ввода помогает `while (sc.hasNextLine())`. Пустые строки удобно пропускать: `if (line.isEmpty()) continue;`.

Аргумент есть не у всех команд. У «PRINT» части одна, и `parts[1]` выйдет за границу массива. Поэтому число читают только там, где оно нужно.

## Разбор: что выведет программа

```java
int value = 10;
String[] script = { "ADD 5", "neg", "MUL 2" };
for (String line : script) {
    String[] parts = line.split(" ");
    switch (parts[0].toUpperCase()) {
        case "ADD" -> value += Integer.parseInt(parts[1]);
        case "MUL" -> value *= Integer.parseInt(parts[1]);
        default -> System.out.println("Неизвестная команда: " + parts[0].toUpperCase());
    }
}
System.out.println(value);
```

10 + 5 = 15. Команда «neg» неизвестна, а 15 × 2 = 30:

```text
Неизвестная команда: NEG
30
```

## Твоё задание

Напиши интерпретатор. Значение начинается с 0. Команды читаются по строке:

-   `ADD n`, `SUB n`, `MUL n`, `DIV n` — изменить значение, деление целочисленное;
-   `PRINT` — вывести «Значение: …»;
-   `END` — закончить чтение команд;
-   всё остальное — «Неизвестная команда: …» с именем команды заглавными буквами.

Регистр букв в командах не важен. После окончания выведи «Итог: …».

### Что должна вывести программа

Для ввода из примера:

```text
Значение: 5
Неизвестная команда: POW
Итог: 15
```
