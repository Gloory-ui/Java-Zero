## Зачем это нужно

Чек из магазина, таблица результатов, цена с двумя знаками после точки — числа нужно выводить красиво. `System.out.println(45.5)` напечатает «45.5», а в чеке должно быть «45.50», и столбцы должны стоять ровно. Для этого есть форматированный вывод.

## Как это работает

`System.out.printf(шаблон, значения...)` печатает шаблон, подставляя значения вместо **спецификаторов**:

```java
System.out.printf("%s: %d шт. по %.2f%n", "Чай", 3, 79.9);
// Чай: 3 шт. по 79.90
```

| Спецификатор | Что подставляет |
| --- | --- |
| `%d` | целое число |
| `%s` | строку или любой объект |
| `%.2f` | дробное число с двумя знаками после точки |
| `%5d` | целое, шириной 5 символов, выравнивание вправо |
| `%-10s` | строку шириной 10, выравнивание влево |
| `%n` | перевод строки |

-   `printf` сам строку не переводит: в конце шаблона ставят `%n`.
-   `String.format` работает так же, но возвращает строку, а не печатает: `String line = String.format("%.1f", 2.25);`.
-   Значений должно быть столько же, сколько спецификаторов, и нужных типов: `%d` с дробью бросит исключение.

## Разбор: что выведет программа

```java
System.out.printf("%-6s|%4d|%n", "Ян", 7);
System.out.printf("%-6s|%4d|%n", "Ульяна", 125);
```

Имя дополняется пробелами справа до 6 символов, число — слева до 4:

```text
Ян    |   7|
Ульяна| 125|
```

## Твоё задание

Напечатай чек. Для каждой покупки — название шириной 8 влево, количество, цену за штуку и сумму с двумя знаками: шаблон `"%-8s %2d x %6.2f = %7.2f%n"`. В конце — итог через `printf` с `%.2f`.

Покупки: хлеб 2 шт. по 45.50, молоко 1 шт. по 89.90, сыр 3 шт. по 120.00.

### Что должна вывести программа

```text
Хлеб      2 x  45.50 =   91.00
Молоко    1 x  89.90 =   89.90
Сыр       3 x 120.00 =  360.00
Итого: 540.90
```
