## Зачем это нужно

Строки не меняются, поэтому каждое `s = s + "x"` создаёт новую строку и копирует в неё всю старую. В цикле на тысячу шагов это тысяча копий. `StringBuilder` — изменяемая строка: он дописывает символы на месте, а готовый текст отдаёт методом `toString()`.

## Как это работает

```java
StringBuilder sb = new StringBuilder();
sb.append("Java");        // Java
sb.append('-').append(17); // Java-17 — вызовы можно цеплять
sb.insert(0, ">> ");      // >> Java-17
sb.reverse();             // 71-avaJ >>
sb.length();              // 10
String result = sb.toString();
```

-   `append` дописывает в конец что угодно: строку, символ, число.
-   `insert(i, x)` вставляет по индексу, `deleteCharAt(i)` удаляет символ.
-   `reverse()` переворачивает содержимое на месте.
-   `sb.toString()` превращает результат в обычную `String`. Сравнивать `StringBuilder` через `equals` бесполезно: сравниваются объекты, а не текст.

## Разбор: что выведет программа

```java
String word = "кот";
StringBuilder sb = new StringBuilder();
for (int i = 0; i < word.length(); i++) {
    sb.append(word.charAt(i));
    if (i < word.length() - 1) {
        sb.append('*');
    }
}
System.out.println(sb);
```

После каждого символа, кроме последнего, дописывается звёздочка:

```text
к*о*т
```
