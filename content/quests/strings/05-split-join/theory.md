## Зачем это нужно

Данные часто приходят одной строкой: «Аня;Борис;Вика», «3 14 15», «ключ=значение». Чтобы с ними работать, строку режут на части по разделителю. Обратная операция — склеить части с разделителем между ними.

## Как это работает

```java
String line = "red,green,,blue";
String[] parts = line.split(",");   // ["red", "green", "", "blue"]
parts.length                        // 4 — пустая строка между запятыми тоже часть

"  Анна  ".trim()                   // "Анна" — убраны пробелы по краям
"a  b   c".split("\\s+")            // ["a", "b", "c"] — по одному и больше пробелам
String.join(" | ", "x", "y", "z")   // "x | y | z"
String.join(", ", parts)            // склейка массива через разделитель
```

-   Аргумент `split` — регулярное выражение. `"\\s+"` означает «один или больше пробельных символов». Точку и вертикальную черту приходится экранировать: `split("\\.")`, `split("\\|")`.
-   `trim()` убирает пробелы только по краям, пробел внутри строки остаётся.
-   `String.join` ставит разделитель **между** частями, поэтому лишнего разделителя в конце не бывает.

## Разбор: что выведет программа

```java
String[] words = " мама  мыла раму ".trim().split("\\s+");
System.out.println(words.length);
System.out.println(String.join("_", words));
```

После `trim()` по краям пробелов нет, а `split("\\s+")` не оставляет пустых частей между словами:

```text
3
мама_мыла_раму
```

## Твоё задание

Прочитай строку с именами через `;`. Вокруг имён могут быть лишние пробелы. Выведи, сколько имён, список через запятую с пробелом и самое длинное имя. Если длинных несколько, выведи первое.

### Что должна вывести программа

Для ввода ` Аня ; Борис;Вика ;  Гоша `:

```text
Имён: 4
Список: Аня, Борис, Вика, Гоша
Самое длинное: Борис
```
