## Зачем это нужно

Логин, адрес, сообщение в чате — всё это строки. Чтобы проверить, есть ли в сообщении слово, вырезать домен из почты или привести имя к заглавным буквам, у `String` есть готовые методы. Писать эти циклы самому не придётся.

## Как это работает

Строка — объект, символы в ней пронумерованы с нуля, как ячейки массива:

```java
String s = "Привет, мир";
s.length()            // 11 — сколько символов
s.charAt(0)           // 'П' — символ по индексу
s.indexOf("мир")      // 8 — где начинается подстрока, или -1
s.lastIndexOf("и")    // 9 — последнее вхождение
s.substring(8, 11)    // "мир" — с 8 включительно до 11 не включая
s.toUpperCase()       // "ПРИВЕТ, МИР"
s.contains("вет")     // true
s.replace("мир", "код") // "Привет, код"
```

-   Строки **не меняются**. `s.toUpperCase()` возвращает новую строку, а `s` остаётся прежней. Результат нужно сохранить или сразу напечатать.
-   Последний символ — `s.charAt(s.length() - 1)`.
-   Сравнивай строки через `equals`, а не `==`: `==` проверяет, один ли это объект, а не одинаковый ли текст. Без учёта регистра — `equalsIgnoreCase`.

## Разбор: что выведет программа

```java
String mail = "anya@java.ru";
int at = mail.indexOf("@");
System.out.println(mail.substring(0, at));
System.out.println(mail.substring(at + 1).toUpperCase());
```

`@` стоит на индексе 4. `substring(0, 4)` — всё до собаки, `substring(5)` — всё после неё до конца:

```text
anya
JAVA.RU
```

## Твоё задание

Дана строка `s = "Java-Zero учит Java"`. Выведи её длину, первый и последний символ, индекс слова «Zero» и последнего «Java», вырезку «Zero» через `substring`, строку заглавными буквами, есть ли в ней «учит» и строку, где Java заменена на Kotlin.

```text
Длина: 19
Первый символ: J
Последний символ: a
Zero начинается с индекса 5
Последнее Java с индекса 15
Вырезка: Zero
Крупно: JAVA-ZERO УЧИТ JAVA
Есть «учит»: true
Замена: Kotlin-Zero учит Kotlin
```
