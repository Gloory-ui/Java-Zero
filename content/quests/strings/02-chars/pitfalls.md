## Частые грабли

-   **Двойные кавычки для символа.** `char c = "a";` — ошибка «Type mismatch: cannot convert from String to char». Символ пишется в одинарных кавычках: `'a'`.
-   **`next()` вместо `nextLine()`.** `sc.next()` читает одно слово до пробела, и остаток строки не посчитается.
-   **Цифра в `else` букв.** Если писать `if (isLetter) ... else if (isWhitespace) ... else` без проверки цифр, цифры уйдут в «другие». Проверь все четыре группы.
-   **Заглавные внутри `else`.** Заглавная буква — тоже буква. Считай её отдельным `if`, иначе пропустишь либо букву, либо заглавную.
