## Зачем это нужно

Пароль должен содержать цифру, имя — начинаться с заглавной буквы, а в номере телефона не должно быть букв. Такие проверки идут символ за символом. Один символ в Java — это тип `char`, а класс `Character` умеет рассказать о нём всё.

## Как это работает

```java
char c = 'Ж';                 // одинарные кавычки — символ, двойные — строка
Character.isLetter(c)         // true — буква любого алфавита
Character.isDigit('7')        // true — цифра
Character.isWhitespace(' ')   // true — пробел, табуляция, перевод строки
Character.isUpperCase(c)      // true — заглавная
Character.toLowerCase(c)      // 'ж'
```

Пройти по всем символам строки можно обычным циклом по индексам:

```java
String word = "Код42";
for (int i = 0; i < word.length(); i++) {
    char ch = word.charAt(i);
    // проверяем ch
}
```

`char` — это число, код символа. Поэтому `'a' + 1` даёт 98, а `(char) ('a' + 1)` — букву `'b'`.

## Разбор: что выведет программа

```java
String word = "Код42";
int digits = 0;
for (int i = 0; i < word.length(); i++) {
    if (Character.isDigit(word.charAt(i))) {
        digits++;
    }
}
System.out.println(digits + " из " + word.length());
```

Цифры — только «4» и «2»:

```text
2 из 5
```
