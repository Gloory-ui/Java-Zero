## Зачем это нужно

Логин должен начинаться с латинской буквы и состоять из 3–16 символов, среди которых только буквы, цифры и подчёркивание. Такую проверку можно написать циклом на двадцать строк. А можно описать шаблон строки — **регулярное выражение** — и проверить её одной строкой.

## Как это работает

Регулярное выражение описывает, какие строки подходят:

| Шаблон | Что значит |
| --- | --- |
| `[a-z]` | одна строчная латинская буква |
| `[a-z0-9_]` | буква, цифра или подчёркивание |
| `\d` | одна цифра |
| `x{2,5}` | от 2 до 5 повторов `x` |
| `x+` | один или больше |
| `x*` | ноль или больше |
| `x?` | ноль или один |

В строке Java обратную черту удваивают: шаблон `\d+` записывается как `"\\d+"`.

```java
"2024".matches("\\d{4}")          // true — ровно 4 цифры
"20a4".matches("\\d{4}")          // false
"тел: 8 900 123".replaceAll("\\d", "*") // "тел: * *** ***"
```

-   `matches` проверяет, что **вся** строка подходит под шаблон, а не её кусок.
-   `replaceAll(шаблон, замена)` заменяет каждое совпадение.
-   Для поиска совпадений внутри текста есть `Pattern` и `Matcher`: `Matcher m = Pattern.compile("\\d+").matcher(text); while (m.find()) { m.group(); }`.

## Разбор: что выведет программа

```java
String[] codes = { "A-12", "B-7", "AB-123" };
for (String c : codes) {
    System.out.println(c + " " + c.matches("[A-Z]-\\d{2,3}"));
}
```

Шаблон: одна заглавная буква, дефис, 2–3 цифры. У «B-7» только одна цифра, у «AB-123» две буквы:

```text
A-12 true
B-7 false
AB-123 false
```

## Твоё задание

Проверь логины до конца ввода. Правильный логин начинается со строчной латинской буквы, за ней идут от 2 до 15 строчных латинских букв, цифр или подчёркиваний. Для каждого выведи «OK» или «ошибка». В конце выведи, сколько логинов подошло.

### Что должна вывести программа

Для ввода из примера:

```text
java_hero: OK
7up: ошибка
ab: ошибка
anna2008: OK
Vasya: ошибка
very_long_login_name_2: ошибка
Подходит: 2 из 6
```
