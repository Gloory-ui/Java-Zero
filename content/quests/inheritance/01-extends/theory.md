## Зачем это нужно

У кошки и собаки есть имя и возраст, обе умеют представиться. Если написать эти поля в каждом классе заново, код начнёт повторяться, а исправление придётся вносить в пять мест. **Наследование** решает это: общее пишут один раз в **базовом классе** (родителе), а конкретные классы (наследники) его **расширяют**.

## Как это работает

```java
class Animal {                  // базовый класс: то, что есть у всех животных
    String name;
    int age;

    void introduce() {
        System.out.println("Я " + name + ", мне " + age);
    }
}

class Dog extends Animal {      // Dog получает name, age и introduce()
    void bark() {
        System.out.println(name + ": Гав!");
    }
}
```

-   `extends` — «расширяет». Наследник получает поля и методы родителя и добавляет свои.
-   Внутри `Dog` можно обращаться к `name`, хотя в самом `Dog` это поле не объявлено: оно пришло от `Animal`.
-   У класса в Java ровно один родитель. Если `extends` не написан, родитель — встроенный класс `Object`.

В лаборатории все классы лежат в одном файле: `public` только у главного класса с `main`, у остальных его нет. В настоящем проекте каждый публичный класс живёт в своём файле.

## Разбор: что выведет программа

```java
Dog dog = new Dog();
dog.name = "Шарик";
dog.age = 4;
dog.introduce();
dog.bark();
```

`introduce()` объявлен в `Animal`, но работает с полями объекта `dog`. Выведется:

```text
Я Шарик, мне 4
Шарик: Гав!
```
