## Частые грабли

-   **`new Shape()`.** Абстрактный класс нельзя создать: «Cannot instantiate the type Shape».
-   **Не реализован абстрактный метод.** Если в `Triangle` нет `name()`, компилятор скажет «The type Triangle must implement the inherited abstract method Shape.name()».
-   **Тело у абстрактного метода.** `abstract double area() { ... }` не скомпилируется: у абстрактного метода тела нет, только `;`.
-   **Целочисленное деление.** Если бы стороны были `int`, `5 / 2` дало бы 2. Здесь поля `double`, и площадь треугольника считается точно.
