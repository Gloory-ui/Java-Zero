## Зачем это нужно

У любой фигуры есть площадь, но формула у каждой своя. Посчитать площадь «просто фигуры» нельзя. **Абстрактный класс** описывает общее — «у фигуры есть площадь и имя» — и заставляет каждый конкретный вид фигуры написать свою формулу.

## Как это работает

```java
abstract class Shape {              // создать new Shape() нельзя
    abstract double area();         // метод без тела: его напишет наследник
    abstract String name();
}

class Circle extends Shape {
    double r;
    public Circle(double r) { this.r = r; }

    @Override
    double area() { return 3.14 * r * r; }

    @Override
    String name() { return "Круг"; }
}
```

-   `abstract class` — класс-основа. Объект такого класса создать нельзя, только его наследников.
-   `abstract`-метод объявлен без тела, после скобок сразу точка с запятой.
-   Обычный наследник **обязан** реализовать все абстрактные методы, иначе не скомпилируется.
-   В абстрактном классе могут быть и обычные поля, конструкторы, методы с телом.
-   Наследовать можно и дальше: `Square extends Rectangle` получает готовую площадь прямоугольника.

## Разбор: что выведет программа

```java
Shape s = new Circle(2);
System.out.println(s.name() + ": " + s.area());
```

Переменная типа `Shape`, объект — `Circle`, работает версия круга: `Круг: 12.56`.

## Твоё задание

`Shape` и `Rectangle` готовы. Допиши `Triangle` (площадь — основание на высоту пополам) и сделай `Square` наследником `Rectangle`: передай сторону в `super(side, side)` и верни имя «Квадрат». `main` выводит площади и их сумму.

### Что должна вывести программа

```text
Прямоугольник: 12.0
Треугольник: 15.0
Квадрат: 25.0
Общая площадь: 52.0
```
