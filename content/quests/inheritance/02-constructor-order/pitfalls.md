## Частые грабли

-   **Тип результата у конструктора.** `public void Cat() { ... }` — это уже обычный метод с именем Cat, а не конструктор. Он не сработает при `new Cat()`, и строки не будет.
-   **Имя с маленькой буквы.** `cat()` — тоже обычный метод. Конструктор называется точно как класс.
-   **Вызов родителя руками в конце.** Писать `Animal();` внутри `Cat()` нельзя: так вызывают метод, а не конструктор. Родителя Java вызывает сама, до первой строки `Cat()`.
