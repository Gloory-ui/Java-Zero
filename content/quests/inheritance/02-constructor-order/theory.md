## Зачем это нужно

Объект наследника состоит из двух частей: той, что пришла от родителя, и своей. Кто-то должен построить обе. Если понимать порядок, ты не удивишься лишним строкам в выводе и не будешь обращаться к полям, которые ещё не готовы.

## Как это работает

Конструктор — специальный метод: имя как у класса, без типа результата. Он срабатывает при каждом `new`.

```java
class Animal {
    public Animal() {
        System.out.println("Отработал конструктор Animal");
    }
}

class Cat extends Animal {
    public Cat() {
        System.out.println("Отработал конструктор Cat!");
    }
}
```

При `new Cat()` Java **сначала** вызывает конструктор родителя, **потом** наследника. Писать вызов `Animal()` руками не нужно: компилятор делает это сам.

Как у дома: сначала фундамент (часть `Animal`), потом этажи (часть `Cat`). Наследник может рассчитывать, что родительская часть уже готова.

## Разбор: что выведет программа

```java
new Cat();
new Cat();
```

Каждый объект строится заново, и для каждого сначала работает `Animal()`:

```text
Отработал конструктор Animal
Отработал конструктор Cat!
Отработал конструктор Animal
Отработал конструктор Cat!
```

А `new Animal()` напечатает только первую строку: объект `Animal` ничего не знает о кошках.

## Твоё задание

Добавь конструкторы `Animal()` и `Cat()`, как в примере. `main` уже создаёт кошку, печатает разделитель и создаёт просто животное.

### Что должна вывести программа

```text
Отработал конструктор Animal
Отработал конструктор Cat!
---
Отработал конструктор Animal
```
