## Зачем это нужно

Все животные умеют издавать звук, но каждое по-своему. Метод `speak()` у родителя описывает общее поведение, а наследник может **переопределить** его — написать свою версию с тем же именем и параметрами.

## Как это работает

```java
class Animal {
    String name;
    void speak() {
        System.out.println(name + " издаёт звук");
    }
}

class Cow extends Animal {
    @Override
    void speak() {                          // та же сигнатура, что у родителя
        System.out.println(name + ": Муу");
    }
}
```

-   **Переопределение**: метод с тем же именем и теми же параметрами, что у родителя. Для объекта `Cow` работает версия `Cow`.
-   `@Override` — подсказка компилятору: «я переопределяю метод родителя». Опечатаешься в имени — получишь ошибку, а не тихий баг.
-   `super.speak()` вызывает версию родителя. Так наследник **дополняет** поведение, а не заменяет его.

Не путай с перегрузкой: перегрузка — несколько методов с одним именем, но **разными** параметрами в одном классе.

## Разбор: что выведет программа

```java
class Rooster extends Animal {
    @Override
    void speak() {
        super.speak();
        System.out.println(name + ": Кукареку!");
    }
}
// new Rooster("Петя") с name = "Петя", затем speak()
```

Сначала сработает версия родителя, потом своя строка:

```text
Петя издаёт звук
Петя: Кукареку!
```

## Твоё задание

Переопредели `speak()` в `Cat` и `Dog` с `@Override`. Кошка печатает «Барсик: Мяу». Собака сначала вызывает `super.speak()`, потом печатает «Шарик: Гав!». Просто `Animal` говорит по-старому.

### Что должна вывести программа

```text
Барсик: Мяу
Шарик издаёт звук
Шарик: Гав!
Ёжик издаёт звук
```
