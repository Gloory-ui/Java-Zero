## Зачем это нужно

В зоопарке десятки животных. Писать для каждого вида отдельный цикл — долго. **Полиморфизм** («много форм») позволяет хранить всех в одном массиве родительского типа и вызывать `speak()` одинаково, а каждое животное ответит по-своему.

## Как это работает

```java
Animal pet = new Cat("Мурка");  // переменная типа Animal указывает на кошку
pet.speak();                    // «Мурка: Мяу» — сработала версия Cat
```

-   Ссылка родительского типа может указывать на объект наследника: кошка «является» животным.
-   **Какой метод вызвать, решает класс объекта**, а не тип переменной. Это и есть полиморфизм.
-   **Что можно вызвать, решает тип переменной.** Через `Animal pet` доступны только методы `Animal`.
-   `объект instanceof Класс` проверяет, из этого ли класса объект: `pet instanceof Cat` даст `true`.

## Разбор: что выведет программа

```java
Animal[] pets = { new Dog("Рекс"), new Animal("Ёж") };
for (int i = 0; i < pets.length; i++) {
    pets[i].speak();
}
System.out.println(pets[0] instanceof Dog);
```

Для собаки сработает её версия, для простого животного — общая:

```text
Рекс: Гав!
Ёж издаёт звук
true
```
