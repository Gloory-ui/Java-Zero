## Зачем это нужно

Иногда нужно знать что-то общее для всех объектов: сколько животных создано, сколько из них кошек. Такое значение не принадлежит одному объекту, поэтому его делают **статическим**. А в наследовании важно понимать, **когда** что инициализируется, — иначе счётчики покажут не то.

## Как это работает

```java
class Animal {
    static int count = 0;   // одно поле на весь класс Animal
    String name = "без имени";

    public Animal() {
        count++;            // каждый новый объект увеличивает общий счётчик
    }
}
```

Когда создаётся объект наследника, Java идёт по шагам:

| Шаг | Что происходит |
|---|---|
| 1 | статические поля базового класса (один раз за программу) |
| 2 | статические поля наследника (тоже один раз) |
| 3 | обычные поля базового класса с начальными значениями |
| 4 | конструктор базового класса |
| 5 | обычные поля наследника |
| 6 | конструктор наследника |

Шаги 1–2 — подготовка **классов**, 3–6 — сборка **объекта**. Поэтому конструктор наследника видит уже готовые поля родителя.

## Разбор: что выведет программа

```java
class Dog extends Animal {
    static int dogCount = 0;
    public Dog() { dogCount++; }
}
// в main:
new Dog();
new Dog();
System.out.println(Animal.count + " " + Dog.dogCount);
```

Каждый `new Dog()` вызывает и `Animal()`, и `Dog()`, поэтому выведется `2 2`. Статические поля при этом не обнуляются: они подготовлены один раз.
