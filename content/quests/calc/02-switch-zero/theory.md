## Зачем это нужно

Калькулятор получает знак операции: `+`, `-`, `*` или `/`. Можно написать цепочку из четырёх `if`, но когда выбор идёт по одному значению, нагляднее `switch`. А при делении нужна защита: делить на ноль нельзя.

## Как читается выражение

```java
Scanner sc = new Scanner(System.in);
double a = sc.nextDouble();        // 10
char op = sc.next().charAt(0);     // '/'
double b = sc.nextDouble();        // 4
```

-   `char` — тип для одного символа. Символ пишут в **одинарных** кавычках: `'/'`. Строка — в двойных: `"/"`.
-   `sc.next()` читает слово до пробела, то есть строку `"/"`. `charAt(0)` берёт из неё первый символ.

## switch

```java
switch (op) {
    case '+':
        System.out.println(a + b);
        break;
    case '-':
        System.out.println(a - b);
        break;
    default:
        System.out.println("Неизвестная операция");
}
```

-   `switch` сравнивает `op` с каждым `case` сверху вниз и начинает выполнение с совпавшего.
-   `break` выходит из `switch`. Без него выполнение **проваливается** в следующий `case` — частая ошибка.
-   `default` срабатывает, если ни один `case` не подошёл.

## Деление на ноль

Для `double` Java не падает, а возвращает `Infinity` или `NaN`. Пользователю это непонятно, поэтому перед делением проверяют делитель:

```java
if (b == 0) {
    System.out.println("Ошибка: деление на ноль!");
} else {
    System.out.println(a / b);
}
```

## Разбор: что выведет программа

```java
char op = '+';
switch (op) {
    case '+':
        System.out.println("плюс");
    case '-':
        System.out.println("минус");
        break;
}
```

После `case '+'` нет `break`, поэтому выполнение провалится в `case '-'`. Выведется `плюс` и `минус`.

## Твоё задание

Сложение, вычитание и умножение уже есть в стартовом коде. Допиши деление в `case '/'`: если `b` равно нулю, выведи `Ошибка: деление на ноль!`, иначе — результат `a / b`.

### Что должна вывести программа

При вводе `10 / 4`:

```text
2.5
```

При вводе `5 / 0`:

```text
Ошибка: деление на ноль!
```
