## Зачем это нужно

Калькулятор должен помнить последние результаты — журнал вычислений. Заводить переменные `r1`, `r2`, `r3`… неудобно: их число заранее неизвестно, и цикл по ним не пройти. Для набора однотипных значений есть **массив**.

## Как создать массив

```java
double[] history = new double[5];   // 5 ячеек типа double, в каждой пока 0.0
```

-   `double[]` — тип «массив чисел double».
-   `new double[5]` создаёт массив из пяти ячеек. Размер после создания не меняется.
-   Ячейки нумеруются **с нуля**: `history[0]` … `history[4]`. Ячейки `history[5]` нет.
-   `history.length` — длина массива, здесь 5. Без скобок: это поле, а не метод.

Если значения известны заранее, массив можно заполнить сразу: `int[] marks = {5, 4, 5};`.

## Запись и чтение

```java
history[0] = 10.5;                  // записать в первую ячейку
System.out.println(history[0]);     // прочитать: 10.5
```

## Проход циклом

Массив почти всегда обрабатывают циклом: номер ячейки — это счётчик `i`, от 0 до `length - 1`.

```java
for (int i = 0; i < history.length; i++) {
    System.out.println(history[i]);
}
```

Условие `i < history.length`, а не `<=`: при `i = 5` ячейки уже нет, и программа упала бы с «выходом за границы массива».

## Где лежит массив

Массив — объект, он живёт в куче. В переменной `history` хранится ссылка на него. Открой вкладку «Память»: в стеке — ссылка, в куче — сами пять чисел.

## Разбор: что выведет программа

```java
int[] a = new int[3];
a[1] = 7;
for (int i = 0; i < a.length; i++) {
    System.out.print(a[i] + " ");
}
```

Новый массив `int` заполнен нулями, во вторую ячейку записали 7. Выведется `0 7 0`.

## Твоё задание
