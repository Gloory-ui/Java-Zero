## Зачем это нужно

В этом квесте ты соберёшь консольный калькулятор. Он читает выражение вроде `10 / 4`, считает, защищается от деления на ноль, ведёт журнал результатов и умеет считать факториал. Каждый этап добавляет одну деталь, как в настоящем проекте.

## С чего начинается программа

Ты уже знаешь каркас из «Фундамента Java»: класс, имя которого совпадает с файлом, и метод `main` — точка входа.

```java
public class Calculator {
    public static void main(String[] args) {
        System.out.println("...");
    }
}
```

Теперь разберём, что значат слова в заголовке `main`:

| Слово | Смысл |
|---|---|
| `public` | метод виден снаружи класса — Java может его вызвать |
| `static` | метод принадлежит классу, для вызова не нужно создавать объект |
| `void` | метод ничего не возвращает |
| `String[] args` | массив аргументов запуска; в лаборатории он пустой |

С `static` и возвращаемым типом ты ещё встретишься в этапе про методы.
