## Частые грабли

-   **Метод внутри main.** Метод объявляют рядом с `main`, внутри класса. Внутри `main` его написать нельзя — будет синтаксическая ошибка.
-   **Нет return.** Метод с типом `double` обязан вернуть значение: «Метод не всегда возвращает результат».
-   **Нет static.** `public double average(...)` без `static` из `main` не вызвать: «нужно объявить static».
-   **Скобки в среднем.** `a + b / 2` — это `a + (b / 2)`. Среднее — `(a + b) / 2`.
-   **print вместо return.** Если метод печатает результат, а не возвращает, `main` получит пустоту: печатать должен тот, кто вызвал.
