## Зачем это нужно

В калькуляторе одни и те же вычисления нужны много раз: процент от суммы, среднее. Копировать формулу в каждое место — путь к ошибкам. Формулу один раз оформляют как **метод** и потом вызывают по имени. Без методов не обойтись и в рекурсии — финальном этапе квеста.

## Как устроен метод

```java
public static double average(double a, double b) {   // заголовок
    return (a + b) / 2;                              // тело: вычислить и вернуть
}
```

-   `public static` — пока пиши так у всех методов: `main` тоже `static` и может вызывать только такие методы.
-   `double` перед именем — **тип результата**: что метод вернёт.
-   `average` — имя. Как у переменных: с маленькой буквы.
-   `(double a, double b)` — **параметры**: значения, которые метод получает при вызове.
-   `return` отдаёт результат туда, откуда метод вызвали, и сразу завершает метод.

Если метод ничего не возвращает, а только, например, печатает, вместо типа пишут `void`, и `return` со значением не нужен.

## Вызов

Метод вызывают по имени и передают значения в скобках. Результат можно напечатать или сохранить:

```java
public static void main(String[] args) {
    double avg = average(3, 4);        // a = 3, b = 4 → вернёт 3.5
    System.out.println(avg);           // 3.5
    System.out.println(average(10, 20)); // 15.0
}
```

Методы пишут внутри класса, но **снаружи** `main` — рядом с ним, а не внутри.

## Что происходит в памяти

При каждом вызове у метода появляется свой кадр в стеке: там живут его параметры и локальные переменные. После `return` кадр исчезает, остаётся только результат. Поэтому переменная, объявленная в одном методе, не видна в другом.

## Разбор: что выведет программа

```java
public static int twice(int x) {
    return x * 2;
}

public static void main(String[] args) {
    int a = twice(5);
    System.out.println(twice(a) + 1);
}
```

`twice(5)` возвращает 10, это `a`. Потом `twice(10)` даёт 20, плюс 1. Программа выведет `21`.

## Твоё задание

В стартовом коде есть два метода-заглушки и готовый `main`, который их вызывает. Допиши тела методов:

-   `percent(value, p)` возвращает `p` процентов от `value`: `value * p / 100`;
-   `average(a, b)` возвращает среднее двух чисел.

`main` не меняй.

### Что должна вывести программа

```text
30.0
40.0
3.5
4.0
```
