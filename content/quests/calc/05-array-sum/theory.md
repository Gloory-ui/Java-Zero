## Зачем это нужно

Журнал вычислений хранит результаты, а теперь по ним нужна сводка: сумма, самый большой результат, среднее. Эти три задачи встречаются везде, где есть массивы, и на них часто спрашивают на защите.

## Чтение массива из ввода

Сначала пользователь вводит, сколько будет чисел. Под это количество создают массив и заполняют его циклом:

```java
int n = sc.nextInt();
double[] results = new double[n];
for (int i = 0; i < n; i++) {
    results[i] = sc.nextDouble();
}
```

## Сумма

Накопитель заводят **до** цикла и прибавляют каждый элемент — как с суммами в подготовке к КТ:

```java
double sum = 0;
for (int i = 0; i < results.length; i++) {
    sum += results[i];
}
```

## Максимум

Запоминаем лучший элемент, который видели, и сравниваем с ним остальные. Начинать нужно **с первого элемента массива**, а не с нуля:

```java
double max = results[0];
for (int i = 1; i < results.length; i++) {
    if (results[i] > max) {
        max = results[i];
    }
}
```

Если начать с `max = 0`, для массива `{-5, -2, -9}` программа ответит 0 — числа, которого в массиве нет.

## Среднее

Среднее — сумма, делённая на количество: `sum / n`. Сумма здесь `double`, поэтому деление дробное.

## Разбор: что выведет программа

```java
double[] a = {4, -1, 7};
double max = a[0];
for (int i = 1; i < a.length; i++) {
    if (a[i] > max) max = a[i];
}
System.out.println(max);
```

Старт: `max = 4`. При `i = 1`: −1 не больше 4. При `i = 2`: 7 больше 4, `max = 7`. Выведется `7.0` — число `double`.

## Твоё задание

Первое число ввода — сколько будет результатов, дальше сами результаты. Сохрани их в массив и выведи сумму, максимум и среднее.

### Что должна вывести программа

При вводе `4` и `12.5 3 47.25 8`:

```text
Сумма: 70.75
Максимум: 47.25
Среднее: 17.6875
```
