## Зачем это нужно

Книги в библиотеке сортируют то по году, то по автору, то сначала новые. Естественный порядок у класса один, а нужных порядков много. **Компаратор** — отдельный объект-правило сравнения. Их можно заводить сколько угодно и передавать в сортировку.

## Как это работает

```java
record Film(String title, int year, double rating) { }

films.sort(Comparator.comparing(Film::year));             // по году
films.sort(Comparator.comparing(Film::rating).reversed()); // по рейтингу, сначала высокий
films.sort(Comparator.comparing(Film::year)
        .thenComparing(Film::title));                      // по году, при равенстве — по названию
```

-   `list.sort(компаратор)` сортирует список по правилу.
-   `Comparator.comparing(Film::year)` — правило «сравнивай по `year()`». Запись `Film::year` называется **ссылкой на метод**: «возьми у фильма `year()`».
-   `.thenComparing(...)` — второй ключ, если по первому элементы равны.
-   `.reversed()` переворачивает порядок.

## Разбор: что выведет программа

```java
List<Film> films = new ArrayList<>(List.of(
    new Film("Б", 2010, 7.5), new Film("А", 2010, 8.1), new Film("В", 1999, 9.0)));
films.sort(Comparator.comparing(Film::year).thenComparing(Film::title));
for (Film f : films) System.out.println(f.year() + " " + f.title());
```

Сначала 1999 год, а два фильма 2010 года идут по алфавиту:

```text
1999 В
2010 А
2010 Б
```
