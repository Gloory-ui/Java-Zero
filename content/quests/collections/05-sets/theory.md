## Зачем это нужно

Сколько разных городов в списке заказов? Какие номера встречаются дважды? Для таких вопросов нужна коллекция, которая сама отбрасывает повторы. Это **множество** (`Set`).

## Как это работает

```java
import java.util.HashSet;
import java.util.Set;
import java.util.TreeSet;

Set<String> cities = new HashSet<>();
cities.add("Казань");        // true — добавлено
cities.add("Омск");          // true
cities.add("Казань");        // false — уже было, повтор не добавится
cities.size();               // 2
cities.contains("Омск");     // true
```

-   `add` возвращает `true`, если элемент новый, и `false`, если такой уже есть. Так удобно ловить повторы.
-   Индексов у множества нет: `get(0)` не существует. Обходят его через for-each.
-   `HashSet` хранит элементы в непредсказуемом порядке, `TreeSet` — по возрастанию, `LinkedHashSet` — в порядке добавления.

## Разбор: что выведет программа

```java
Set<Integer> seen = new TreeSet<>();
for (int n : new int[] { 5, 1, 5, 3, 1 }) {
    if (!seen.add(n)) {
        System.out.println("повтор " + n);
    }
}
System.out.println(seen);
```

Второе добавление 5 и 1 возвращает `false`. `TreeSet` печатается по возрастанию:

```text
повтор 5
повтор 1
[1, 3, 5]
```

## Твоё задание

Прочитай числа до конца ввода. Выведи, сколько всего чисел, сколько среди них разных, разные числа по возрастанию и числа, которые повторялись, — каждое один раз и тоже по возрастанию.

### Что должна вывести программа

Для ввода `4 7 4 1 9 7 4 3`:

```text
Всего чисел: 8
Разных: 5
По возрастанию: [1, 3, 4, 7, 9]
Повторялись: [4, 7]
```
