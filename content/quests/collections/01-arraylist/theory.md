## Зачем это нужно

Длину массива задают при создании, и потом она не меняется. А список покупок растёт и сокращается: что-то дописали, что-то купили. `ArrayList` — массив, который сам расширяется, когда места не хватает, и умеет вставлять и удалять элементы.

## Как это работает

```java
import java.util.ArrayList;

ArrayList<String> list = new ArrayList<>();   // в <> — тип элементов
list.add("чай");            // [чай]
list.add("сахар");          // [чай, сахар]
list.add(0, "лимон");       // [лимон, чай, сахар] — вставка по индексу
list.get(1);                // "чай"
list.set(1, "кофе");        // [лимон, кофе, сахар]
list.remove("лимон");       // [кофе, сахар] — по значению
list.remove(0);             // [сахар] — по индексу
list.size();                // 1
list.contains("сахар");     // true
list.indexOf("сахар");      // 0, или -1 если нет
System.out.println(list);   // [сахар]
```

-   В угловых скобках — тип элементов. Примитивы туда писать нельзя: вместо `int` — `Integer`, вместо `double` — `Double`. Java сама переводит `5` в `Integer` и обратно.
-   Размер — `size()`, а не `length`.
-   `println(list)` печатает элементы в квадратных скобках через запятую.
-   Обойти список можно через for-each: `for (String s : list)`.

## Разбор: что выведет программа

```java
ArrayList<Integer> nums = new ArrayList<>();
nums.add(10);
nums.add(20);
nums.add(1, 15);
nums.set(0, 5);
System.out.println(nums + " " + nums.size());
```

Вставка по индексу 1 сдвигает 20 вправо, потом 10 заменяется на 5:

```text
[5, 15, 20] 3
```

```text

Где батон: 1
```
