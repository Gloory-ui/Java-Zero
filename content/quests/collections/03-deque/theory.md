## Зачем это нужно

Очередь в кассу: кто первым пришёл, того первым обслужили. Стопка тарелок: последнюю положенную берут первой. Обе структуры встречаются в программах постоянно, и в Java для обеих есть `ArrayDeque` — «двусторонняя очередь», с которой можно работать с обоих концов.

## Как это работает

```java
import java.util.ArrayDeque;

ArrayDeque<String> q = new ArrayDeque<>();
q.offerLast("Аня");       // в конец:    [Аня]
q.offerLast("Боря");      //             [Аня, Боря]
q.offerFirst("Вика");     // в начало:   [Вика, Аня, Боря]
q.peekFirst();            // "Вика" — посмотреть, не удаляя
q.pollFirst();            // "Вика" — забрать из начала
q.isEmpty();              // false
```

-   Очередь: кладём `offerLast`, берём `pollFirst`.
-   Стек: `push` кладёт в начало, `pop` берёт оттуда же.
-   `pollFirst()` у пустой очереди вернёт `null`, а `pop()` бросит исключение. Перед взятием удобно проверить `isEmpty()`.

Команду из ввода «+Аня» разбирают по первому символу: `word.charAt(0)` — знак, `word.substring(1)` — имя.

## Разбор: что выведет программа

```java
ArrayDeque<Integer> stack = new ArrayDeque<>();
stack.push(1);
stack.push(2);
stack.push(3);
System.out.println(stack.pop() + " " + stack.pop());
System.out.println(stack);
```

Стек отдаёт элементы в обратном порядке:

```text
3 2
[1]
```

## Твоё задание

Смоделируй очередь в кассу. Команды приходят словами до конца ввода:

-   `+Имя` — встать в конец очереди;
-   `!Имя` — пропустить вперёд, в начало очереди;
-   `-` — обслужить первого: «Обслужен: Имя», а если никого нет — «Очередь пуста».

В конце выведи, кто остался.

### Что должна вывести программа

Для ввода `+Аня +Борис !Вика - - +Гоша - - -`:

```text
Обслужен: Вика
Обслужен: Аня
Обслужен: Борис
Обслужен: Гоша
Очередь пуста
Осталось: []
```
