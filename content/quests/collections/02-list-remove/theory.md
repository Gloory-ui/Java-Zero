## Зачем это нужно

Из списка оценок нужно убрать все двойки. Самое очевидное — пройти по списку и удалять лишнее. Но список меняется прямо во время обхода, и for-each на этом ломается. Есть два надёжных способа: итератор и `removeIf`.

## Как это работает

**Итератор** — объект, который ходит по коллекции и умеет безопасно удалить текущий элемент:

```java
Iterator<Integer> it = marks.iterator();
while (it.hasNext()) {           // есть ли следующий элемент
    int m = it.next();           // взять его
    if (m == 2) {
        it.remove();             // удалить то, что только что взяли
    }
}
```

**`removeIf`** делает то же самое в одну строку. Ему передают условие, записанное коротко:

```java
marks.removeIf(m -> m == 2);     // «удали каждый m, для которого m == 2»
```

Запись `m -> m == 2` — это **лямбда**: слева от стрелки параметр, справа условие. Подробно лямбды разберём в отдельном квесте, пока достаточно этого шаблона.

## Разбор: что выведет программа

```java
ArrayList<Integer> list = new ArrayList<>(List.of(1, 2, 3, 4));
list.remove(1);
System.out.println(list);
list.remove(Integer.valueOf(1));
System.out.println(list);
```

У списка `Integer` есть ловушка: `remove(1)` удаляет элемент **по индексу 1**, то есть двойку. Чтобы удалить само число 1, нужен объект `Integer.valueOf(1)`:

```text
[1, 3, 4]
[3, 4]
```
