## Частые грабли

-   **Удаление в for-each.** `for (int n : list) if (n < 0) list.remove(...)` бросит «ConcurrentModificationException»: список изменился посреди обхода.
-   **`list.remove(n)` для `Integer`.** Для списка чисел `remove(5)` удаляет элемент с индексом 5, а не число 5. Число удаляют через `remove(Integer.valueOf(5))`.
-   **Два `next()` за шаг.** Каждый вызов `it.next()` берёт новый элемент. Сохрани его в переменную и проверяй её.
-   **Удаление по индексам вперёд.** В цикле `for (int i = 0; ...)` после удаления элементы сдвигаются, и следующий пропускается.
