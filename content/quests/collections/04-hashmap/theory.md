## Зачем это нужно

Телефонная книга: по имени найти номер. Счётчик слов: по слову найти, сколько раз оно встретилось. Перебирать список ради этого долго. **Словарь** (`Map`) хранит пары «ключ → значение» и находит значение по ключу сразу.

## Как это работает

```java
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> ages = new HashMap<>();
ages.put("Аня", 19);          // добавить пару
ages.put("Борис", 20);
ages.put("Аня", 20);          // ключ уже есть — значение заменится
ages.get("Аня");              // 20
ages.get("Гоша");             // null — такого ключа нет
ages.getOrDefault("Гоша", 0); // 0 — значение по умолчанию
ages.containsKey("Борис");    // true
ages.size();                  // 2
```

-   Ключи уникальны, значения могут повторяться.
-   Обойти пары можно через `entrySet()`: `for (Map.Entry<String, Integer> e : ages.entrySet())`, у пары есть `getKey()` и `getValue()`.
-   `HashMap` хранит пары в непредсказуемом порядке. Нужен порядок по алфавиту — бери `TreeMap`, порядок добавления — `LinkedHashMap`. Методы у них те же.

Счётчик — классический приём: `counts.put(w, counts.getOrDefault(w, 0) + 1);`.

## Разбор: что выведет программа

```java
Map<Character, Integer> counts = new TreeMap<>();
for (char c : "мама".toCharArray()) {
    counts.put(c, counts.getOrDefault(c, 0) + 1);
}
System.out.println(counts);
```

`toCharArray()` превращает строку в массив символов. `TreeMap` выводит ключи по порядку:

```text
{а=2, м=2}
```

## Твоё задание

Прочитай слова до конца ввода и посчитай, сколько раз встретилось каждое. Регистр не важен: «Кот» и «кот» — одно слово. Выведи пары по алфавиту в виде «слово: число», а потом самое частое слово. Если таких несколько, выведи первое по алфавиту.

### Что должна вывести программа

Для ввода `кот пёс Кот мышь пёс кот`:

```text
кот: 3
мышь: 1
пёс: 2
Чаще всего: кот
```
