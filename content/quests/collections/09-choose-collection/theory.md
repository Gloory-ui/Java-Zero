## Зачем это нужно

Одна и та же задача решается разными коллекциями, но удобно — только правильной. Выбор зависит от вопроса: важен ли порядок, нужны ли повторы, ищем ли по ключу. Правильная коллекция делает код коротким, неправильная — превращает его в циклы с проверками.

## Как это работает

| Вопрос | Коллекция |
| --- | --- |
| Порядок важен, повторы нужны, доступ по индексу | `ArrayList` |
| Только уникальные, порядок не важен | `HashSet` |
| Уникальные в порядке добавления | `LinkedHashSet` |
| Уникальные по возрастанию | `TreeSet` |
| Найти значение по ключу | `HashMap` |
| Ключи по возрастанию | `TreeMap` |
| Очередь или стек | `ArrayDeque` |

Приём «скользящее окно» хранит только последние N элементов: новый кладём в конец, и если элементов стало больше N, убираем самый старый из начала.

## Разбор: что выведет программа

```java
ArrayDeque<Integer> last2 = new ArrayDeque<>();
for (int n : new int[] { 1, 2, 3, 4 }) {
    last2.offerLast(n);
    if (last2.size() > 2) {
        last2.pollFirst();
    }
}
System.out.println(last2);
```

Каждый новый элемент вытесняет самый старый:

```text
[3, 4]
```

## Твоё задание

Журнал посещений — имена в порядке прихода, до конца ввода. Выведи:

-   кто приходил, в порядке первого визита и без повторов — `LinkedHashSet`;
-   сколько визитов у каждого, по алфавиту — `TreeMap`;
-   трёх последних посетителей в порядке прихода — `ArrayDeque` как окно на 3.

### Что должна вывести программа

Для ввода `Аня Борис Аня Вика Аня Борис Гоша`:

```text
Первые визиты: [Аня, Борис, Вика, Гоша]
Визитов: {Аня=3, Борис=2, Вика=1, Гоша=1}
Последние трое: [Аня, Борис, Гоша]
```
