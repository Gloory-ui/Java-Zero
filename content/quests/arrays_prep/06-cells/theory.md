## Зачем это нужно

В таблице часто ищут ячейки по условию: где стоит ноль, где свободное место, где оценка ниже тройки. Ответ — не само число, а **адрес** ячейки: пара индексов «строка, столбец».

## Таблица из ввода

Сначала вводят размеры, потом числа строка за строкой. Вложенные циклы читают их по порядку:

```java
int rows = sc.nextInt();
int cols = sc.nextInt();
int[][] t = new int[rows][cols];
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        t[i][j] = sc.nextInt();
    }
}
```

`sc.nextInt()` не важно, стоят числа в одной строке или в нескольких: он берёт следующее число из ввода.

## Как это работает: обход с условием

Те же два цикла проходят все ячейки. В теле — проверка, и для подходящей ячейки печатаются её индексы:

```java
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        if (t[i][j] == 0) {
            System.out.println("[" + i + "][" + j + "]");
        }
    }
}
```

Адрес ячейки записываем так же, как в коде: `[1][2]` — строка с индексом 1, столбец с индексом 2. Сколько ячеек подошло, считает накопитель, как в квесте «Циклы».

## Разбор: что выведет программа

Таблица `{{0, 4}, {7, 0}}`, ищем нули. Обход идёт по строкам: `[0][0]` — ноль, `[0][1]` — 4, `[1][0]` — 7, `[1][1]` — ноль. Выведется:

```text
[0][0]
[1][1]
```

## Твоё задание

Первые два числа ввода — число строк и столбцов, дальше сама таблица. Выведи адреса и значения всех ячеек, где число больше 5, в формате `[строка][столбец] = значение`. В конце выведи, сколько таких ячеек.

### Что должна вывести программа

При вводе

```text
3 4
3 8 1 9
5 2 7 4
6 0 2 8
```

```text
[0][1] = 8
[0][3] = 9
[1][2] = 7
[2][0] = 6
[2][3] = 8
Всего: 5
```
