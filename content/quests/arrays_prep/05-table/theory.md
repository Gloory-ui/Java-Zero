## Зачем это нужно

Расписание, журнал оценок, поле для морского боя — это таблицы: строки и столбцы. Для таблицы в Java есть **двумерный массив** — массив, каждая ячейка которого сама массив-строка.

## Как это работает

```java
int[][] t = new int[3][4];   // 3 строки по 4 столбца, все ячейки 0
t[1][2] = 7;                 // строка с индексом 1, столбец с индексом 2
```

-   Первый индекс — **строка**, второй — **столбец**. Оба считаются с нуля: `t[0][0]` — левый верхний угол, `t[2][3]` — правый нижний.
-   `t.length` — число строк (3), `t[0].length` — число столбцов в строке (4).
-   Таблицу можно записать сразу, строка за строкой:

```java
int[][] t = {
    {3, 8, 1, 9},
    {5, 2, 7, 4},
    {6, 0, 2, 8}
};
```

**Вся таблица** печатается вложенными циклами, как таблица умножения: внешний идёт по строкам, внутренний — по столбцам.

```java
for (int i = 0; i < t.length; i++) {
    for (int j = 0; j < t[i].length; j++) {
        System.out.print(t[i][j] + " ");
    }
    System.out.println();
}
```

**Одна строка** — это один цикл: номер строки фиксирован, меняется только столбец.

```java
for (int j = 0; j < t[0].length; j++) {
    System.out.print(t[0][j] + " ");   // первая строка: 3 8 1 9
}
```

## Разбор: что выведет программа

```java
int[][] m = {{1, 2}, {3, 4}, {5, 6}};
System.out.println(m.length + " " + m[0].length + " " + m[2][1]);
```

Строк три, в строке два столбца, в строке с индексом 2 и столбце 1 стоит 6. Выведется `3 2 6`.

## Твоё задание

В стартовом коде уже есть таблица 3 × 4. Выведи её целиком: каждую строку таблицы на своей строке, числа через пробел. Потом отдельно выведи вторую строку таблицы после слов `Вторая строка:`. Вторая строка — это индекс 1.

### Что должна вывести программа

```text
3 8 1 9
5 2 7 4
6 0 2 8
Вторая строка: 5 2 7 4
```

Число пробелов между значениями не важно.
