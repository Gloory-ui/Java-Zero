## Частые грабли

-   **`rnd.nextInt(6)` для кубика.** Выпадают числа 0..5: ноль есть, шестёрки нет. Нужно `rnd.nextInt(6) + 1`.
-   **`nextInt(99)` для диапазона 0..99.** Граница не входит в диапазон: так получится 0..98. Для 0..99 пиши `nextInt(100)`.
-   **Забыт `import java.util.Random;`.** Компилятор ответит `cannot find symbol: class Random`.
-   **`(int) Math.random() * 6`.** Приведение срабатывает раньше умножения: `(int) 0.73` даёт 0, и результат всегда 0. Скобки нужны вокруг произведения: `(int) (Math.random() * 6)`.
