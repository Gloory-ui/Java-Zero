## Зачем это нужно

Таблица «смены × дни», «ученики × оценки», «дни × недели» — и вопрос: у какой строки итог больше всего, а у какой меньше. Для этого считают сумму **каждой строки** отдельно и ищут максимум и минимум среди сумм.

## Как это работает

**Сумма строки** — накопитель, который обнуляется перед каждой строкой. Суммы удобно сложить в свой массив, по одной на строку:

```java
int[] sums = new int[t.length];
for (int i = 0; i < t.length; i++) {
    int sum = 0;                       // новая строка — счёт с нуля
    for (int j = 0; j < t[i].length; j++) {
        sum += t[i][j];
    }
    sums[i] = sum;
}
```

**Лучшая и худшая строка** — поиск индекса максимума и минимума в массиве `sums`, как на этапе про обмен:

```java
int maxRow = 0, minRow = 0;
for (int i = 1; i < sums.length; i++) {
    if (sums[i] > sums[maxRow]) maxRow = i;
    if (sums[i] < sums[minRow]) minRow = i;
}
```

**Названия строк** хранит массив строк `String[]` — те же ячейки и индексы, только внутри текст:

```java
String[] shifts = {"Утро", "День", "Вечер"};
System.out.println(shifts[maxRow]);    // название строки с наибольшей суммой
```

## Разбор: что выведет программа

Таблица `{{1, 2}, {5, 0}, {2, 2}}`. Суммы строк: 3, 5, 4. Индекс максимума — 1, минимума — 0. Для названий `{"А", "Б", "В"}` выведется `Б` и `А`.

## Твоё задание

Кафе считает заказы: 3 смены (утро, день, вечер) за 4 дня. Первые 12 чисел ввода — таблица 3 × 4 по строкам. Выведи сумму заказов каждой смены, затем смену с наибольшим и наименьшим числом заказов. Если сумма одинаковая, выбирай первую из них.

### Что должна вывести программа

При вводе

```text
12 15 9 14
20 18 25 22
7 11 6 10
```

```text
Утро: 50
День: 85
Вечер: 34
Больше всего заказов: День
Меньше всего заказов: Вечер
```
