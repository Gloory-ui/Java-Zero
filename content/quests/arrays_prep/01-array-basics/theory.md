## Зачем это нужно

Пять оценок, семь дней недели, десять бросков кубика — когда значений много и они одного типа, заводить `a1`, `a2`, `a3`… неудобно: по таким переменным не пройти циклом. Для набора однотипных значений есть **массив**. Если ты проходил «Калькулятор», начало этапа — повторение.

## Как это работает

```java
int[] a = new int[5];          // 5 ячеек типа int, в каждой пока 0
a[0] = 7;                      // запись в первую ячейку
System.out.println(a[0]);      // чтение: 7
System.out.println(a.length);  // длина массива: 5
```

-   `int[]` — тип «массив целых чисел», `new int[5]` создаёт пять ячеек. Размер потом не меняется.
-   Ячейки нумеруются **с нуля**: `a[0]` … `a[4]`. Номер ячейки называют **индексом**. Ячейки `a[5]` нет: обращение к ней роняет программу.
-   `a.length` — длина массива, без скобок.
-   Если значения известны сразу, массив можно записать списком: `int[] marks = {5, 4, 5};`.

Массив почти всегда заполняют и читают циклом: индекс — это счётчик `i` от 0 до `length - 1`.

```java
for (int i = 0; i < a.length; i++) {
    a[i] = (i + 1) * 3;        // 3, 6, 9, 12, 15
}
```

## Вывод через запятую

Если печатать `a[i] + ", "`, после последнего числа останется лишняя запятая. Запятую ставят **перед** каждым элементом, кроме первого:

```java
for (int i = 0; i < a.length; i++) {
    if (i > 0) {
        System.out.print(", ");
    }
    System.out.print(a[i]);
}
System.out.println();
```

## Разбор: что выведет программа

```java
int[] b = new int[4];
b[2] = 9;
for (int i = 0; i < b.length; i++) {
    if (i > 0) System.out.print(", ");
    System.out.print(b[i]);
}
```

Новый массив `int` заполнен нулями, в третью ячейку (индекс 2) записали 9. Выведется `0, 0, 9, 0`.
