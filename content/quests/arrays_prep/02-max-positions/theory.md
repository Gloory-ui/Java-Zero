## Зачем это нужно

Лучшая оценка в журнале, самый жаркий день, самый дорогой товар — задача «найти наибольшее» встречается постоянно. А если лучших несколько? Тогда нужно найти само значение и все места, где оно стоит.

## Массив из ввода

Сначала вводят количество чисел, под него создают массив и заполняют циклом:

```java
Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
int[] a = new int[n];
for (int i = 0; i < n; i++) {
    a[i] = sc.nextInt();
}
```

## Как это работает: два прохода

**Первый проход** ищет максимум. Запоминаем лучший элемент, который видели, и сравниваем с ним остальные. Начинать нужно **с первого элемента массива**, а не с нуля:

```java
int max = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] > max) {
        max = a[i];
    }
}
```

Если начать с `max = 0`, для массива `{-5, -2, -9}` программа ответит 0 — числа, которого в массиве нет.

**Второй проход** печатает индексы всех ячеек, где лежит максимум. Сравнивать с максимумом можно только после первого прохода, когда он уже известен:

```java
System.out.print("Индексы:");
for (int i = 0; i < n; i++) {
    if (a[i] == max) {
        System.out.print(" " + i);
    }
}
System.out.println();
```

## Разбор: что выведет программа

Ввод: `5`, затем `3 8 1 8 2`.

-   Первый проход: `max = 3`, при `i = 1` 8 больше 3, `max = 8`; дальше больше 8 ничего нет.
-   Второй проход: 8 лежит в ячейках с индексами 1 и 3.

Выведется `Максимум: 8` и `Индексы: 1 3`.

## Твоё задание

Первое число ввода — сколько будет чисел, дальше сами числа. Сохрани их в массив, найди наибольшее и выведи индексы всех ячеек, где оно стоит. Индексы считаются с нуля.

### Что должна вывести программа

При вводе `7` и `4 1 9 3 7 9 2`:

```text
Максимум: 9
Индексы: 2 5
```
