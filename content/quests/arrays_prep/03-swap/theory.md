## Зачем это нужно

Чтобы переставить элементы — отсортировать массив, поднять лучший результат наверх, поменять местами два значения, — мало знать само число. Нужно знать, **где** оно лежит, то есть его индекс. И нужно уметь менять два элемента местами, ничего не потеряв.

## Как это работает: индекс вместо значения

Вместо самого максимума запоминаем его индекс. Значение всегда можно достать как `a[maxIndex]`:

```java
int maxIndex = 0;
for (int i = 1; i < n; i++) {
    if (a[i] > a[maxIndex]) {
        maxIndex = i;
    }
}
```

Знак `>` строгий, поэтому при нескольких одинаковых максимумах запомнится первый.

## Обмен через temp

Если написать `a[0] = a[maxIndex]; a[maxIndex] = a[0];`, первое присваивание затрёт старое `a[0]`, и в обеих ячейках окажется одно и то же. Нужна временная переменная — как третий стакан, чтобы поменять местами сок и воду:

```java
int temp = a[0];          // 1. сохранили первый элемент
a[0] = a[maxIndex];       // 2. на его место — максимум
a[maxIndex] = temp;       // 3. на место максимума — сохранённый
```

## Вывод в фигурных скобках

Так массив записывают в задачах: `{4, -5, 0, 6, 8}`. Печатаем `{`, элементы через запятую (запятая перед всеми, кроме первого) и `}`:

```java
System.out.print("{");
for (int i = 0; i < n; i++) {
    if (i > 0) System.out.print(", ");
    System.out.print(a[i]);
}
System.out.println("}");
```

## Разбор: что выведет программа

Массив `{3, 9, 2}`. Поиск: `maxIndex = 0`, при `i = 1` 9 больше 3, `maxIndex = 1`. Обмен: `temp = 3`, `a[0] = 9`, `a[1] = 3`. Выведется `{9, 3, 2}`.

## Твоё задание

Первое число ввода — сколько будет чисел, дальше сами числа. Найди индекс наибольшего элемента (первого, если их несколько), выведи его и поменяй этот элемент местами с первым. Выведи массив после обмена в фигурных скобках.

### Что должна вывести программа

При вводе `5` и `4 -5 0 6 8`:

```text
Индекс максимума: 4
После обмена: {8, -5, 0, 6, 4}
```
