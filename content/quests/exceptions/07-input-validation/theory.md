## Зачем это нужно

Анкета просит возраст. Пользователь пишет «двадцать», потом «-5», потом «150», и только потом «25». Программа не должна падать или соглашаться на ерунду. Она объясняет, что не так, и спрашивает снова, пока не получит правильный ответ.

## Как это работает

Удобно разделить работу: метод разбирает и проверяет значение, а цикл повторяет попытки.

```java
static int parseMark(String s) {
    int mark = Integer.parseInt(s);            // может бросить NumberFormatException
    if (mark < 1 || mark > 5) {
        throw new IllegalArgumentException("Оценка должна быть от 1 до 5: " + mark);
    }
    return mark;
}
```

Цикл пробует, пока не получится, и выходит через `break`:

```java
while (sc.hasNext()) {
    try {
        mark = parseMark(sc.next());
        break;                                  // получилось — выходим
    } catch (NumberFormatException e) {
        System.out.println("Это не число");
    } catch (IllegalArgumentException e) {
        System.out.println(e.getMessage());
    }
}
```

`NumberFormatException` — **наследник** `IllegalArgumentException`. Поэтому порядок `catch` важен: частный тип — выше. Поставишь общий первым — компилятор скажет, что второй блок недостижим.

## Разбор: что выведет программа

Для ввода `семь 9 4` цикл выше напечатает:

```text
Это не число
Оценка должна быть от 1 до 5: 9
```

А `mark` станет 4, и цикл закончится на `break`.

## Твоё задание

Напиши метод `parseAge`. Он разбирает строку и бросает `IllegalArgumentException` с текстом «Возраст должен быть от 0 до 120: N», если число вне диапазона.

В `main` читай слова, пока возраст не будет принят. Для не-числа выводи «Это не число: слово», для числа вне диапазона — сообщение исключения. Когда возраст принят, выведи «Возраст принят: N». Если ввод кончился раньше, выведи «Возраст не введён».

### Что должна вывести программа

Для ввода `двадцать -5 150 25 30`:

```text
Это не число: двадцать
Возраст должен быть от 0 до 120: -5
Возраст должен быть от 0 до 120: 150
Возраст принят: 25
```
