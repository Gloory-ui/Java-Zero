## Зачем это нужно

Пользователи вводят что угодно: «12», «двенадцать», «3.5», «7x». Если читать число через `nextInt()`, на первом же слове программа упадёт. Надёжнее читать слово строкой, пробовать превратить его в число и не падать, если не вышло.

## Как это работает

`Integer.parseInt(s)` превращает строку в число. Если строка не число, бросается `NumberFormatException`:

```java
try {
    int n = Integer.parseInt("42x");
} catch (NumberFormatException e) {
    System.out.println(e.getMessage());   // For input string: "42x"
}
```

-   Знак минус допустим: `parseInt("-7")` вернёт -7.
-   Дробь для `parseInt` — не число: «3.5» бросит исключение. Для дробей есть `Double.parseDouble`.
-   Пробелы внутри или по краям тоже ломают разбор, поэтому данные обрезают через `trim()`.

Читать «слово за словом» до конца ввода помогает пара `sc.hasNext()` и `sc.next()`: они не пытаются разобрать число и не падают.

## Разбор: что выведет программа

```java
String[] raw = { "5", "пять", "-2" };
int sum = 0;
for (String s : raw) {
    try {
        sum += Integer.parseInt(s);
    } catch (NumberFormatException e) {
        System.out.println("Не число: " + s);
    }
}
System.out.println(sum);
```

«пять» пропускается, а 5 + (−2) = 3:

```text
Не число: пять
3
```

## Твоё задание

Читай слова до конца ввода. Числа складывай, про остальные слова пиши «Пропускаю: …». В конце выведи, сколько было чисел и их сумму.

### Что должна вывести программа

Для ввода `12 abc 5 3.5 -4 7x`:

```text
Пропускаю: abc
Пропускаю: 3.5
Пропускаю: 7x
Чисел: 3
Сумма: 13
```
