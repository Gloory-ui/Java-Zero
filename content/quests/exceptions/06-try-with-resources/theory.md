## Зачем это нужно

Файл, сетевое соединение, подключение к базе — **ресурсы**: их открывают, а после работы обязательно закрывают. Если в середине работы бросится исключение, до строки `close()` дело не дойдёт, и ресурс останется открытым. `try-with-resources` закрывает ресурс сам, что бы ни случилось.

## Как это работает

Ресурс — объект класса, который реализует интерфейс `AutoCloseable` с одним методом `close()`:

```java
class Lamp implements AutoCloseable {
    Lamp() { System.out.println("Свет включён"); }

    @Override
    public void close() {
        System.out.println("Свет выключен");
    }
}

try (Lamp lamp = new Lamp()) {        // ресурс объявлен в скобках
    System.out.println("Читаю");
}                                      // здесь close() вызовется сам
```

-   Ресурсы объявляют в круглых скобках после `try`. Несколько ресурсов разделяют точкой с запятой.
-   `close()` вызывается при выходе из блока: и обычном, и из-за исключения.
-   Ресурсы закрываются **в обратном порядке**: последний открытый закрывается первым.
-   Исключение из блока ловят обычным `catch`. К моменту `catch` ресурс уже закрыт.

## Разбор: что выведет программа

```java
try (Lamp lamp = new Lamp()) {
    System.out.println("Читаю");
    throw new IllegalStateException("перегорела");
} catch (IllegalStateException e) {
    System.out.println("Поймано: " + e.getMessage());
}
```

Сначала лампа гаснет, и только потом срабатывает `catch`:

```text
Свет включён
Читаю
Свет выключен
Поймано: перегорела
```

## Твоё задание

Пусть класс `Door` станет ресурсом: реализует `AutoCloseable`, а `close()` печатает «Закрыта: имя». В `main` сделай два блока `try`-with-resources:

1.  Двери A и B в одном `try`, внутри — «Прохожу».
2.  Дверь C, внутри — «Сквозняк!» и `throw new IllegalStateException("дверь заклинило")`. Поймай исключение и выведи «Поймано: …».

### Что должна вывести программа

```text
Открыта: A
Открыта: B
Прохожу
Закрыта: B
Закрыта: A
Открыта: C
Сквозняк!
Закрыта: C
Поймано: дверь заклинило
```
