## Зачем это нужно

Пользователь ввёл делитель 0, и программа упала посреди работы — остальные примеры так и не посчитались. Ошибка во время выполнения в Java называется **исключением**. Его можно поймать, сообщить о проблеме и продолжить работу.

## Как это работает

Когда случается ошибка, Java создаёт объект-исключение и «бросает» его. Если никто не поймал, программа останавливается и печатает, где случилась беда. Ловят исключения так:

```java
try {
    int x = 10 / 0;                  // здесь бросится исключение
    System.out.println("не выполнится");
} catch (ArithmeticException e) {
    System.out.println("Поймано: " + e.getMessage());
}
System.out.println("Работаем дальше");
```

-   В `try` — код, который может сломаться. Как только бросилось исключение, остаток `try` пропускается.
-   `catch (Тип e)` ловит исключения этого типа. У `e` есть `getMessage()` — текст ошибки.
-   После `catch` программа продолжает работу со следующей строки.

Частые встроенные исключения:

| Исключение | Когда бросается |
| --- | --- |
| `ArithmeticException` | целое деление на 0 |
| `ArrayIndexOutOfBoundsException` | индекс за границей массива |
| `NullPointerException` | вызов метода у `null` |
| `NumberFormatException` | строка не превращается в число |

## Разбор: что выведет программа

```java
int[] a = { 4, 8 };
try {
    System.out.println(a[1]);
    System.out.println(a[2]);
    System.out.println("конец try");
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("Нет такого индекса");
}
```

`a[1]` печатается, на `a[2]` бросается исключение, и «конец try» уже не выполнится:

```text
8
Нет такого индекса
```

## Твоё задание

Программа читает пары чисел до конца ввода и печатает частное. Если делитель 0, поймай `ArithmeticException` и выведи «деление на ноль». После всех пар выведи «Готово». Используй `try`/`catch`, а не проверку `if`.

### Что должна вывести программа

Для ввода из примера:

```text
10 / 2 = 5
7 / 0: деление на ноль
9 / 3 = 3
Готово
```
