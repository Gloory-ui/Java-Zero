## Зачем это нужно

Банковский счёт не должен уходить в минус, а пополнение на −50 рублей — бессмыслица. Метод сам знает, какие данные для него неправильные. Он может отказаться работать и **бросить** исключение, чтобы вызывающий код узнал о проблеме.

## Как это работает

```java
void setAge(int age) {
    if (age < 0) {
        throw new IllegalArgumentException("Возраст не может быть отрицательным");
    }
    this.age = age;
}
```

-   `throw` бросает объект-исключение. Метод тут же прекращает работу, код после `throw` не выполнится.
-   В скобках конструктора — сообщение, его потом вернёт `getMessage()`.
-   `IllegalArgumentException` — «передали плохой аргумент».
-   `IllegalStateException` — «аргумент нормальный, но сейчас объект не может это сделать». Например, снять 1000 можно, но на счёте только 300.

Проверку в начале метода называют **защитной**: сначала отсеиваем плохие случаи, потом делаем работу.

## Разбор: что выведет программа

```java
static int root(int x) {
    if (x < 0) {
        throw new IllegalArgumentException("минус под корнем: " + x);
    }
    return (int) Math.sqrt(x);
}

try {
    System.out.println(root(16));
    System.out.println(root(-9));
} catch (IllegalArgumentException e) {
    System.out.println("Ошибка: " + e.getMessage());
}
```

```text
4
Ошибка: минус под корнем: -9
```

Добавь в класс `Account` защитные проверки:

-   `deposit` и `withdraw` с суммой ≤ 0 бросают `IllegalArgumentException` с текстом «Сумма должна быть больше нуля»;
-   `withdraw` больше баланса бросает `IllegalStateException` с текстом «Недостаточно средств: баланс …».
