## Зачем это нужно

«Место уже занято» — не опечатка программиста, а обычная ситуация в кинотеатре. Хочется, чтобы компилятор **заставил** каждого, кто бронирует места, обработать этот случай. Для этого пишут своё проверяемое исключение.

## Как это работает

Исключения бывают двух видов:

-   **Непроверяемые** — наследники `RuntimeException`: `IllegalArgumentException`, `NullPointerException` и другие. Обычно это ошибка в коде, ловить их не обязательно.
-   **Проверяемые** — наследники `Exception`, но не `RuntimeException`. Метод, который их бросает, обязан объявить это словом `throws`, а вызывающий — поймать или тоже объявить.

```java
class LateException extends Exception {
    LateException(int minutes) {
        super("Опоздание на " + minutes + " мин");   // сообщение уходит родителю
    }
}

class Lesson {
    void enter(int late) throws LateException {    // предупреждаем вызывающих
        if (late > 10) {
            throw new LateException(late);
        }
        System.out.println("Входи");
    }
}
```

Вызвать `enter` без `try`/`catch` не получится: компилятор напишет «Unhandled exception type LateException».

## Разбор: что выведет программа

```java
Lesson l = new Lesson();
for (int late : new int[] { 5, 15 }) {
    try {
        l.enter(late);
    } catch (LateException e) {
        System.out.println(e.getMessage());
    }
}
```

```text
Входи
Опоздание на 15 мин
```

## Твоё задание

Создай проверяемое исключение `SeatTakenException` с сообщением «Место N уже занято». Метод `book` кинотеатра бросает его для занятого места и объявляет это через `throws`. Для номера вне 1–10 метод бросает `IllegalArgumentException` с текстом «Нет места N».

`main` читает номера мест до конца ввода, бронирует их и печатает результат. В конце — сколько мест свободно.

### Что должна вывести программа

Для ввода `3 5 3 12 5 7`:

```text
Место 3: забронировано
Место 5: забронировано
Место 3 уже занято
Нет места 12
Место 5 уже занято
Место 7: забронировано
Свободно мест: 7
```
