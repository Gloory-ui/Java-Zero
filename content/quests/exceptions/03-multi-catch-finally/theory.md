## Зачем это нужно

Одна операция может сломаться по-разному: номер не число, номера нет в списке, элемент пустой. На каждую беду нужен свой ответ. А что-то должно выполниться в любом случае — например, запись в журнал о том, что запрос был.

## Как это работает

```java
try {
    // код, который может сломаться по-разному
} catch (NumberFormatException e) {
    // одна беда
} catch (ArrayIndexOutOfBoundsException e) {
    // другая беда
} finally {
    // выполнится всегда: и после успеха, и после любого catch
}
```

-   Блоков `catch` может быть несколько. Java проверяет их сверху вниз и выполняет **первый подходящий**.
-   `finally` выполняется всегда, даже если в `try` был `return`.
-   Если два исключения обрабатываются одинаково, их ловят одним блоком через `|`: `catch (NumberFormatException | NullPointerException e)`.

Вызов метода у `null` бросает `NullPointerException`: у пустой ссылки нет объекта, у которого можно было бы что-то вызвать.

## Разбор: что выведет программа

```java
static int half(String s) {
    try {
        return Integer.parseInt(s) / 2;
    } catch (NumberFormatException e) {
        return -1;
    } finally {
        System.out.println("проверено: " + s);
    }
}
// System.out.println(half("8")); System.out.println(half("x"));
```

`finally` срабатывает до того, как метод вернёт значение, поэтому «проверено» печатается раньше результата:

```text
проверено: 8
4
проверено: x
-1
```

## Твоё задание

Метод `pick` получает номер элемента строкой и печатает элемент заглавными буквами. Добавь обработку трёх бед:

-   номер не число — «Не число: …»;
-   элемента с таким номером нет — «Нет элемента с номером …»;
-   элемент пустой (`null`) — «Пустой элемент».

После каждого запроса, при любом исходе, печатай «--- запрос: …».

### Что должна вывести программа

```text
КОТ
--- запрос: 0
Пустой элемент
--- запрос: 1
Нет элемента с номером 5
--- запрос: 5
Не число: два
--- запрос: два
```
