## Зачем это нужно

Дневник, журнал событий, лог сервера — туда пишут новые записи в конец, а старые остаются. Если каждый раз перезаписывать файл, история потеряется. Нужен режим **дописывания**.

## Как это работает

Вторым аргументом после текста можно передать **режимы открытия** файла:

```java
import java.nio.file.StandardOpenOption;

Files.writeString(log, "старт\n");                                   // создать или перезаписать
Files.writeString(log, "шаг 1\n", StandardOpenOption.APPEND);        // дописать в конец
Files.writeString(log, "шаг 2\n", StandardOpenOption.CREATE,
                                   StandardOpenOption.APPEND);        // создать, если нет, и дописать
```

| Режим | Что делает |
| --- | --- |
| `APPEND` | пишет в конец файла, не стирая старое |
| `CREATE` | создаёт файл, если его нет |
| `TRUNCATE_EXISTING` | очищает файл перед записью (так работает запись по умолчанию) |

-   Одного `APPEND` мало, если файла ещё нет: будет `NoSuchFileException`. Вместе с `CREATE` файл создастся.
-   `writeString` сам перевод строки не добавляет: пиши `"\n"` в конце текста.

## Разбор: что выведет программа

```java
Path p = Path.of("count.txt");
Files.writeString(p, "0\n");
for (int i = 1; i <= 2; i++) {
    Files.writeString(p, i + "\n", StandardOpenOption.APPEND);
}
System.out.println(Files.readAllLines(p));
```

Первая запись создала файл, две следующие дописали строки:

```text
[0, 1, 2]
```

## Твоё задание

Создай файл `diary.txt` с заголовком «=== Дневник ===». Каждую строку из ввода допиши в конец в виде «номер) запись». Потом прочитай файл и выведи его целиком, а в конце — число записей без заголовка.

### Что должна вывести программа

Для ввода из примера:

```text
=== Дневник ===
1) проснулся
2) выпил кофе
3) написал код
Записей: 3
```
