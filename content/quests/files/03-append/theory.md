## Зачем это нужно

Дневник, журнал событий, лог сервера — туда пишут новые записи в конец, а старые остаются. Если каждый раз перезаписывать файл новой записью, история потеряется. Нужно **дописывать**.

## Как это работает

В обычной Java на компьютере для этого есть режим открытия `APPEND`:

```java
Files.writeString(log, "шаг 1\n", StandardOpenOption.CREATE, StandardOpenOption.APPEND);
```

| Режим | Что делает |
| --- | --- |
| `APPEND` | пишет в конец файла, не стирая старое |
| `CREATE` | создаёт файл, если его нет |
| `TRUNCATE_EXISTING` | очищает файл перед записью (так работает запись по умолчанию) |

Java в этой лаборатории работает в браузере, и её файловая песочница режим `APPEND` не поддерживает: файл просто перезаписывается. Поэтому здесь дописываем вторым способом, который работает везде: **прочитать, добавить, записать**.

```java
List<String> lines = new ArrayList<>(Files.readAllLines(log));  // что уже есть
lines.add("шаг 2");                                             // новая запись
Files.write(log, lines);                                        // всё обратно
```

-   Список из `readAllLines` копируют в `new ArrayList<>(...)`: так он точно изменяемый.
-   Способ читает файл целиком, поэтому годится для небольших журналов. Для логов на гигабайты в обычной Java берут `APPEND`.

## Разбор: что выведет программа

```java
Path p = Path.of("count.txt");
Files.write(p, List.of("0"));
for (int i = 1; i <= 2; i++) {
    List<String> lines = new ArrayList<>(Files.readAllLines(p));
    lines.add(String.valueOf(i));
    Files.write(p, lines);
}
System.out.println(Files.readAllLines(p));
```

Каждый шаг читает то, что уже есть, и дописывает одну строку:

```text
[0, 1, 2]
```

## Твоё задание

Создай файл `diary.txt` с заголовком «=== Дневник ===». Каждую строку из ввода допиши в конец в виде «номер) запись» способом «прочитать, добавить, записать». Потом прочитай файл и выведи его целиком, а в конце — число записей без заголовка.

### Что должна вывести программа

Для ввода из примера:

```text
=== Дневник ===
1) проснулся
2) выпил кофе
3) написал код
Записей: 3
```
