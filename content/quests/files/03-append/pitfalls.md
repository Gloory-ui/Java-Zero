## Частые грабли

-   **Всё в одну строку.** Без `"\n"` в конце каждой записи файл станет одной длинной строкой.
-   **Заголовок с `APPEND`.** Если заголовок тоже дописывать, при каждом запуске файл будет расти: старые записи с прошлого раза останутся. Первая запись — без `APPEND`.
-   **`APPEND` без файла.** Если файла ещё нет, одно `APPEND` бросит «NoSuchFileException». Добавь `CREATE` или сначала создай файл.
