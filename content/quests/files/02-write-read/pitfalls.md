## Частые грабли

-   **Ожидание дописывания.** `Files.write` каждый раз перезаписывает файл. Чтобы добавить в конец, нужен особый режим — он в следующем этапе.
-   **`readString` вместо `readAllLines`.** `readString` вернёт одну строку с переводами строк внутри. Для пунктов по одному нужен список.
-   **Номер с нуля.** Индекс списка начинается с 0, а номер пункта — с 1: печатай `i + 1`.
