## Зачем это нужно

Список дел удобно хранить по строке на пункт. Записать его в файл и прочитать обратно — самая частая работа с файлами. В `Files` для этого есть готовые методы, и циклы по байтам писать не нужно.

## Как это работает

```java
List<String> lines = List.of("первая", "вторая");
Files.write(path, lines);                   // каждая строка — своя строка файла
List<String> back = Files.readAllLines(path); // [первая, вторая]
String all = Files.readString(path);        // весь файл одной строкой
```

-   `Files.write(path, список)` записывает строки и ставит перевод строки после каждой. Старое содержимое файла пропадает.
-   `Files.readAllLines(path)` читает файл в список строк, переводы строк отбрасываются.
-   `Files.readString(path)` читает всё целиком, вместе с переводами строк.
-   Эти методы читают весь файл в память. Для файлов на гигабайты есть построчное чтение — оно будет дальше.

Читать строки до конца ввода удобно так: `while (sc.hasNextLine()) list.add(sc.nextLine());`.

## Разбор: что выведет программа

```java
Path p = Path.of("pair.txt");
Files.write(p, List.of("кот", "пёс"));
Files.write(p, List.of("ёж"));
System.out.println(Files.readAllLines(p));
```

Вторая запись заменила файл целиком:

```text
[ёж]
```

## Твоё задание

Прочитай строки из ввода — это список дел. Запиши их в файл `todo.txt`, потом прочитай файл обратно и выведи пункты с номерами. В конце выведи, сколько строк в файле и какая из них самая длинная.

### Что должна вывести программа

Для ввода из примера:

```text
1. купить хлеб
2. сдать лабу
3. позвонить маме
Строк: 3
Самая длинная: позвонить маме
```
