## Зачем это нужно

Таблицы из Excel, выгрузки из магазина, списки студентов часто хранят в формате **CSV**: одна строка — одна запись, поля разделены запятой или точкой с запятой. Это обычный текстовый файл, и прочитать его можно тем, что ты уже знаешь: `readAllLines`, `split` и `parseDouble`.

## Как это работает

```text
имя;возраст
Аня;19
Борис;20
```

```java
List<String> lines = Files.readAllLines(csv);
for (int i = 1; i < lines.size(); i++) {         // строка 0 — заголовок, пропускаем
    String[] cells = lines.get(i).split(";");
    String name = cells[0];
    int age = Integer.parseInt(cells[1]);
}
```

-   Первая строка обычно заголовок с названиями столбцов. Её пропускают.
-   Для дробей — `Double.parseDouble("45.5")`, дробная часть отделяется точкой.
-   Отчёт удобно собирать в список строк и записывать одним `Files.write`.
-   `String.format("%.2f", x)` даёт число с двумя знаками после точки.

## Разбор: что выведет программа

```java
Files.write(p, List.of("x;y", "1;2", "3;4"));
int sum = 0;
List<String> lines = Files.readAllLines(p);
for (int i = 1; i < lines.size(); i++) {
    String[] c = lines.get(i).split(";");
    sum += Integer.parseInt(c[0]) * Integer.parseInt(c[1]);
}
System.out.println(sum);
```

1 × 2 + 3 × 4:

```text
14
```
