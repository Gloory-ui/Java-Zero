## Зачем это нужно

Почти каждая задача что-то считает: сумму, среднее, процент. В Java есть одна ловушка, на которой спотыкаются чаще всего: деление целых чисел отбрасывает дробную часть. Разберись с ней сейчас, и дальше она тебя не подведёт.

## Операторы

| Оператор | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3` (!) |
| `%` | остаток от деления | `7 % 2` | `1` |

Порядок как в математике: сначала `*`, `/`, `%`, потом `+` и `-`. Скобки меняют порядок: `(7 + 2) * 2` даёт 18, а `7 + 2 * 2` — 11.

## Целое деление

Если **оба** числа `int`, результат тоже `int`: дробная часть просто отбрасывается, без округления.

```java
System.out.println(7 / 2);     // 3
System.out.println(9 / 10);    // 0
```

Чтобы получить дробный результат, хотя бы одно число должно быть `double`:

```java
System.out.println(7.0 / 2);   // 3.5
```

Когда числа лежат в переменных `int`, одну из них **приводят** к `double` — пишут тип в скобках перед ней:

```java
int a = 7;
int b = 2;
System.out.println((double) a / b);   // 3.5
```

Приведение выполняется раньше деления, поэтому делится уже `7.0` на `2`.

## Разбор: что выведет программа

```java
int a = 7;
int b = 2;
double wrong = a / b;
System.out.println(wrong);
```

Выведется `3.0`, а не `3.5`. Сначала выполняется `a / b` — целое деление даёт 3. Только потом 3 кладётся в `double` и становится `3.0`. Переменная `double` слева не спасает: важны типы чисел, которые делятся.

## Деление на ноль

Целое число делить на 0 нельзя: программа упадёт с `ArithmeticException`. С дробными числами Java вернёт `Infinity`. В обоих случаях делитель лучше проверять заранее — это будет в калькуляторе.

## Твоё задание

В стартовом коде есть `int a = 7;` и `int b = 2;`. Выведи три строки:

1. целое деление `a` на `b`;
2. дробное деление `a` на `b` через приведение `(double)`;
3. значение выражения `a + b * 2`.

### Что должна вывести программа

```text
3
3.5
11
```
