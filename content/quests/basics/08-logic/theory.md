## Зачем это нужно

Часто условие состоит из нескольких частей: «число делится и на 2, и на 3», «кратно 5 или 7». В КТ 1 такие условия есть в заданиях 2 и 3. Части условия соединяют логическими операторами.

## Операторы

| Оператор | Смысл | Истинно, когда | Пример |
|---|---|---|---|
| `&&` | и | истинны **обе** части | `n % 2 == 0 && n % 3 == 0` |
| `\|\|` | или | истинна **хотя бы одна** часть | `n % 5 == 0 \|\| n % 7 == 0` |
| `!` | не | часть ложна | `!(n > 5)` — то же, что `n <= 5` |

Каждая часть — полноценное сравнение. Нельзя написать `n % 2 && n % 3 == 0`: у `&&` с обеих сторон должны стоять `true` или `false`.

## Скобки и порядок

`&&` выполняется раньше `||`, как умножение раньше сложения. Чтобы не гадать, ставь скобки:

```java
boolean leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
```

Java вычисляет лениво: если в `a && b` уже `a` ложно, `b` не проверяется. Если в `a || b` уже `a` истинно — тоже.

## Порядок веток в цепочке

В цепочке `else if` срабатывает первая истинная ветка. Поэтому **более строгое** условие ставят раньше:

```java
if (n % 2 == 0 && n % 3 == 0) {
    System.out.println("Делится на 6");
} else if (n % 2 == 0) {
    System.out.println("Четное");
}
```

Если поменять ветки местами, число 6 попадёт в «Четное», и до первой проверки дело не дойдёт.

## Разбор: что выведет программа

```java
int n = 35;
if (n % 5 == 0 || n % 7 == 0) {
    System.out.println("пропуск");
} else {
    System.out.println(n);
}
```

35 делится на 5 — первая часть уже истинна, и всё условие истинно. Выведется `пропуск`.

## Твоё задание

Прочитай год и выведи `Високосный` или `Обычный`. Год високосный, если он делится на 4, но не делится на 100, либо делится на 400. Поэтому 2024 и 2000 — високосные, а 1900 и 2023 — обычные.

### Что должна вывести программа

При вводе `2024`:

```text
Високосный
```

При вводе `1900`:

```text
Обычный
```
