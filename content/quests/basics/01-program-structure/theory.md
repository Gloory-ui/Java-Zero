## Зачем это нужно

Любая программа на Java — это текст, который компилятор переводит в команды для машины. Чтобы компилятор тебя понял, текст пишется по строгим правилам. Их немного, и с ними ты будешь работать в каждой задаче курса.

## Как устроена программа

```java
public class Basics {                           // класс: его имя совпадает с именем файла Basics.java
    public static void main(String[] args) {    // метод main — отсюда Java начинает выполнение
        System.out.println("Привет, Java!");    // команда: вывести строку и перейти на новую
    }
}
```

-   **Класс** `public class Basics { ... }` — коробка, в которой лежит весь код. Имя класса совпадает с именем файла, поэтому в лаборатории его не меняй.
-   **Метод `main`** — точка входа. Java находит его и выполняет команды внутри по порядку, сверху вниз. Эту строку пока просто запомни целиком: что значат `public`, `static` и `String[] args`, ты узнаешь позже.
-   **Фигурные скобки** `{ }` показывают, где начинается и заканчивается класс и метод. Каждая открытая скобка обязательно закрывается.
-   **Точка с запятой** `;` ставится в конце каждой команды. Без неё компилятор не поймёт, где команда кончилась.
-   **Текст** пишется в двойных кавычках: `"Привет, Java!"`. Такой текст называется строкой.
-   **Регистр букв важен**: `System` и `system` для Java — разные слова, и второе она не знает.

## Вывод на экран

`System.out.println(...)` печатает то, что в скобках, и переводит строку. Две команды подряд печатают две строки:

```java
System.out.println("Первая строка");
System.out.println("Вторая строка");
```

## Комментарии

Всё после `//` до конца строки компилятор пропускает. Это заметки для людей: в стартовом коде так написаны подсказки, что делать. Комментарий на несколько строк пишут между `/*` и `*/`.

## Разбор: что выведет программа

```java
public class Basics {
    public static void main(String[] args) {
        System.out.println("Раз");
        // System.out.println("Два");
        System.out.println("Три");
    }
}
```

Программа выведет две строки: `Раз` и `Три`. Вторая команда стоит в комментарии, поэтому не выполняется.

## Твоё задание

В методе `main` выведи две строки: `Привет, Java!` и `Я пишу первую программу`. Нажми «Проверить» или `Ctrl + Enter`: код скомпилирует настоящий компилятор Java и сверит вывод.

```text
Привет, Java!
Я пишу первую программу
```
