## Зачем это нужно

Программа почти всегда работает с данными: баллы, цены, количество попыток. Чтобы запомнить значение и потом использовать его, его кладут в **переменную** — коробку с именем.

## Как объявить переменную

```java
int apples = 10;        // тип, имя, знак =, значение, точка с запятой
double price = 2.5;
String name = "Аня";
```

Тип говорит, что может лежать в коробке:

| Тип | Что хранит | Пример |
|---|---|---|
| `int` | целые числа | `int count = 42;` |
| `double` | дробные числа, через точку | `double pi = 3.14;` |
| `String` | текст в двойных кавычках | `String city = "Казань";` |

Имя придумываешь сам. Принято писать с маленькой буквы, а следующие слова — с большой: `sumEven`, `maxAttempts`. Пробелы в имени нельзя.

## Значение можно поменять

Знак `=` не сравнивает, а **записывает** значение справа в переменную слева. Тип пишут только при первом объявлении:

```java
int score = 5;
score = 8;              // теперь в score лежит 8, старое 5 забыто
```

## Выражения

В переменную можно положить результат вычисления. Если сложить `int` и `double`, получится `double`:

```java
int a = 10;
double b = 2.5;
double result = a + b;  // 12.5
```

Вывести переменную — значит передать её имя в `println` **без кавычек**. С кавычками выведется само слово:

```java
System.out.println(result);    // 12.5
System.out.println("result");  // result
```

## Разбор: что выведет программа

```java
int x = 3;
x = x + 4;
System.out.println(x);
```

Сначала в `x` лежит 3. Строка `x = x + 4` берёт старое значение, прибавляет 4 и записывает 7 обратно в `x`. Программа выведет `7`.

## Твоё задание

Создай `int a = 10;`, `double b = 2.5;`, `double result = a + b;` и выведи `result`.

