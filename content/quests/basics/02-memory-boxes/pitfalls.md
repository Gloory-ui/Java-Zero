## Частые грабли

-   **`=` и `==`.** Один знак `=` записывает значение, два `==` сравнивают. Сравнения понадобятся в этапе про условия.
-   **Дробь в `int`.** `int x = 3.5;` не компилируется: «Тип double не помещается в int». Для дробных чисел нужен `double`.
-   **Запятая вместо точки.** `double b = 2,5;` — ошибка. В коде дробную часть отделяют точкой: `2.5`.
-   **Тип дважды.** `int a = 10;` и ниже снова `int a = 20;` — «a объявлена дважды». Второй раз пиши просто `a = 20;`.
-   **Имя в кавычках.** `System.out.println("result");` выведет слово result, а не значение переменной.
