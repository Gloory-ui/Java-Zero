## Частые грабли

-   **`=` вместо `==`.** `if (n = 0)` не компилируется: одним знаком записывают, двумя сравнивают.
-   **`n % 2 == 1` для отрицательных.** Для −3 остаток равен −1, и число окажется «чётным». Пиши `n % 2 != 0` или проверяй чётность через `n % 2 == 0` и `else`.
-   **Точка с запятой после if.** `if (n > 0); { ... }` — `;` заканчивает условие пустой командой, а блок в скобках выполняется всегда.
-   **Два отдельных if вместо цепочки.** Если варианты взаимоисключающие, соединяй их через `else if`: иначе могут напечататься две ветки сразу.
