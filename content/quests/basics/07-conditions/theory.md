## Зачем это нужно

До сих пор программа выполняла все команды подряд. Но почти каждая задача требует выбора: подсказать «больше» или «меньше», пропустить число, написать «Четное». Выбор делают условия `if` и `else`.

## Сравнения и boolean

Сравнение даёт ответ «да» или «нет» — значение типа `boolean`: `true` или `false`.

| Выражение | Значит | При `n = 5` |
|---|---|---|
| `n == 5` | равно | `true` |
| `n != 5` | не равно | `false` |
| `n > 0`, `n < 0` | больше, меньше | `true`, `false` |
| `n >= 5`, `n <= 4` | больше или равно, меньше или равно | `true`, `false` |

Результат сравнения можно сохранить: `boolean even = n % 2 == 0;`.

## if и else

```java
if (n > 0) {
    System.out.println("Положительное");   // выполнится, только если условие true
} else {
    System.out.println("Не положительное"); // иначе — эта ветка
}
```

Когда вариантов больше двух, ветки соединяют в цепочку `else if`. Java проверяет условия сверху вниз и выполняет **первую** ветку с истинным условием, остальные пропускает:

```java
if (n > 0) {
    System.out.println("Плюс");
} else if (n < 0) {
    System.out.println("Минус");
} else {
    System.out.println("Ноль");     // сюда попадём, только если оба условия false
}
```

`else` без условия ловит всё, что не подошло выше. Фигурные скобки ставь всегда, даже для одной команды, — так меньше ошибок.

## Разбор: что выведет программа

```java
int n = -7;
if (n % 2 == 1) {
    System.out.println("Нечетное");
} else {
    System.out.println("Четное");
}
```

Выведется `Четное`, хотя −7 нечётное. В Java `-7 % 2` равно `-1`, а не `1`, поэтому условие ложно. Надёжная проверка нечётности: `n % 2 != 0`.

## Твоё задание

Прочитай целое число `n`. В первой строке выведи его знак: `Положительное`, `Отрицательное` или `Ноль`. Во второй — `Четное` или `Нечетное`.

### Что должна вывести программа

При вводе `-3`:

```text
Отрицательное
Нечетное
```

При вводе `0`:

```text
Ноль
Четное
```
