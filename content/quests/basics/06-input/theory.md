## Зачем это нужно

Пока программа работала с числами, записанными прямо в коде. Настоящая программа получает данные от пользователя: игра «Угадай число» читает догадки, калькулятор — два числа и знак. Ввод с клавиатуры читает класс `Scanner`.

## Как подключить Scanner

```java
import java.util.Scanner;                       // 1. подключить класс — самая первая строка файла

public class Basics {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);    // 2. создать «читателя» ввода
        int a = sc.nextInt();                   // 3. прочитать целое число
        System.out.println(a * 2);
    }
}
```

-   `import java.util.Scanner;` говорит компилятору, где искать класс. Без этой строки будет ошибка «Тип Scanner не найден».
-   `new Scanner(System.in)` создаёт объект, который читает стандартный ввод. Одного `Scanner` хватает на всю программу.

## Методы чтения

| Метод | Что читает | Пример ввода |
|---|---|---|
| `sc.nextInt()` | целое число | `42` |
| `sc.nextDouble()` | дробное число, через точку | `3.5` |
| `sc.next()` | одно слово до пробела | `Аня` |

Каждый вызов берёт **следующее** значение. Значения разделяют пробелом или переводом строки: ввод `7 5` и ввод из двух строк `7` и `5` читаются одинаково.

## Как вводить в лаборатории

-   Кнопка «Запуск с вводом» открывает поле «Ввод для программы». Напиши туда значения и нажми «Запустить».
-   Кнопка «Проверить» подаёт программе свой ввод из тестов. Твоё поле на неё не влияет.
-   Если программа читает больше значений, чем ты ввёл, она упадёт с сообщением «Ввод закончился».

## Разбор: что выведет программа

```java
Scanner sc = new Scanner(System.in);
int a = sc.nextInt();
int b = sc.nextInt();
System.out.println("Разница: " + (a - b));
```

При вводе `10 4` первый `nextInt` прочитает 10, второй — 4. Программа выведет `Разница: 6`.
