## Частые грабли

-   **Нет import.** Без `import java.util.Scanner;` компилятор не знает, что такое `Scanner`.
-   **Не тот метод.** Ввод `3.5` для `nextInt()` — программа упадёт: «Ввод не подходит по типу». Для дробных чисел нужен `nextDouble()`.
-   **Пустой ввод.** Если нажать «Запустить» с пустым полем, программе нечего читать, и она падает. Заполни «Ввод для программы».
-   **Запятая в дроби.** В лаборатории дробь вводят через точку: `3.5`. На компьютере с русскими настройками `nextDouble()` может ждать запятую — об этом в справочнике.
-   **Сумма без скобок.** `"Сумма: " + a + b` склеит числа. Нужно `"Сумма: " + (a + b)`.
