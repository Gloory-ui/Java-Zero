## Зачем это нужно

Оператор `%` встречается в задачах постоянно: проверить, чётное ли число, делится ли оно на 3, вывести числа без кратных 5. Всё это — остаток от деления.

## Как это работает

`a % b` — остаток, который останется, если разделить `a` на `b` нацело:

```java
System.out.println(7 % 2);    // 1   (7 = 3 * 2 + 1)
System.out.println(10 % 5);   // 0   (делится нацело)
System.out.println(17 % 5);   // 2   (17 = 3 * 5 + 2)
System.out.println(3 % 10);   // 3   (делимое меньше делителя — остаток равен ему самому)
```

## Три приёма, которые пригодятся

| Задача | Выражение | Почему |
|---|---|---|
| Число чётное? | `n % 2 == 0` | чётные делятся на 2 без остатка |
| Число кратно 3? | `n % 3 == 0` | то же для любого делителя |
| Последняя цифра | `n % 10` | остаток от деления на 10 — последняя цифра |

Знак `==` проверяет равенство. Такие проверки ты будешь писать в условиях `if` через пару этапов, а пока просто посчитай остатки.

## Разбор: что выведет программа

```java
int n = 245;
System.out.println(n % 10);
System.out.println(n / 10 % 10);
```

`245 % 10` — последняя цифра, `5`. `245 / 10` — целое деление, `24`, а `24 % 10` даёт `4`, предпоследнюю цифру. Программа выведет `5` и `4`.

## Твоё задание

В стартовом коде есть `int n = 17;`. Выведи три строки: остаток от деления `n` на 2, остаток от деления `n` на 5 и последнюю цифру `n`.

### Что должна вывести программа

```text
1
2
7
```
