## Частые грабли

-   **`/` вместо `%`.** `17 / 5` — это 3, сколько раз пятёрка поместилась. `17 % 5` — это 2, сколько осталось.
-   **Остаток отрицательного числа.** В Java `-7 % 2` равно `-1`, а не `1`. Поэтому нечётность надёжнее проверять так: `n % 2 != 0`.
-   **Ответ вместо вычисления.** `System.out.println(7);` выведет правильную цифру, но не для другого `n`. Тесты проверяют, что в коде есть `% 2` и `% 10`.
