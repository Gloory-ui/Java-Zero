## Зачем это нужно

Голое число на экране мало что говорит. Программа должна подписывать результат: «Сумма четных: 110», «Попытка 3». Для этого текст склеивают со значениями переменных.

## Строки

Текст хранят в переменных типа `String`. Значение пишут в двойных кавычках:

```java
String name = "Аня";
System.out.println(name);        // Аня
```

## Склейка через +

Если с одной стороны `+` стоит строка, Java склеивает, а не складывает. Число превращается в текст и приклеивается:

```java
int age = 19;
System.out.println("Возраст: " + age);   // Возраст: 19
```

Пробел после двоеточия пишется **внутри кавычек**. Без него получится `Возраст:19`.

## Главная ловушка

`+` выполняется слева направо. Как только слева появилась строка, дальше всё склеивается:

```java
int score = 85;
int bonus = 10;
System.out.println("Баллы: " + score + bonus);    // Баллы: 8510
System.out.println("Баллы: " + (score + bonus));  // Баллы: 95
```

Во второй строке скобки заставляют сначала сложить числа, а уже потом приклеить результат к тексту. А если числа стоят в начале, они успевают сложиться: `2 + 3 + " яблок"` даёт `5 яблок`.

## print и спецсимволы

-   `System.out.print(...)` печатает без перевода строки, следующий вывод продолжит ту же строку.
-   `\t` внутри строки — табуляция, выравнивает колонки: `"Имя\tБаллы"`.
-   `\n` — перевод строки внутри текста.
-   `\"` — кавычка внутри строки: `"Он сказал \"да\""`.

## Разбор: что выведет программа

```java
int a = 2;
int b = 3;
System.out.print("Сумма: ");
System.out.println(a + b);
System.out.println(a + b + " = итог");
```

`print` не переводит строку, поэтому `5` встанет сразу после «Сумма: ». В третьей строке `a + b` стоят в начале и складываются в 5. Вывод: `Сумма: 5` и `5 = итог`.
