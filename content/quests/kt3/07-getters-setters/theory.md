## Задание 7 (Формулировка из билета)

**Написать геттеры и сеттеры для полей name и age (или title и pages), добавив проверки (например, возраст > 0, количество страниц > 0).**

**Требования к выполнению:**

-   Закрой поля `name` и `age` модификатором `private`. Методы внутри `Animal` по-прежнему видят их напрямую, а код снаружи — только через геттеры и сеттеры.
-   Геттеры `getName()` и `getAge()` возвращают значения полей.
-   `setAge(int age)` записывает возраст, только если он **больше 0**. Иначе выводит «Ошибка: возраст должен быть больше 0», и старое значение остаётся.
-   `setName(String name)` не принимает пустое имя. Проверка: `name == null || name.isEmpty()`, где `isEmpty()` — метод строки, «пустая ли она». Сообщение: «Ошибка: имя не может быть пустым».
-   В `main`: Барсик трёх лет, затем `n` попыток задать возраст из ввода — после каждой выводи имя и возраст через геттеры. В конце попробуй пустое имя, потом «Василий».

### Что повторить

Если застрял, вернись к темам «Классы и объекты»: этап «private, геттеры и сеттеры с проверкой». В лекции проверка была `age >= 0`, а в билете — строго больше нуля.

### Что должна вывести программа

При вводе `4` и `4 -1 0 7`:

```text
Барсик: 4
Ошибка: возраст должен быть больше 0
Барсик: 4
Ошибка: возраст должен быть больше 0
Барсик: 4
Барсик: 7
Ошибка: имя не может быть пустым
Новое имя: Василий
```
