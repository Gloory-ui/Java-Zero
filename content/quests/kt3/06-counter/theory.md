## Задание 6 (Формулировка из билета)

**Добавить в класс Animal (или Book) статическое поле counter, которое считает количество созданных объектов, и статический метод для его вывода.**

**Требования к выполнению:**

-   Поле `static int counter = 0;` — одно на весь класс.
-   Счётчик растёт в конструкторе: каждый `new Animal(...)` — плюс один.
-   Конструктор по умолчанию вызывает второй через `this(...)`, поэтому `counter++` достаточно написать только в конструкторе с параметрами. Если написать в обоих, животное по умолчанию посчитается дважды.
-   Метод `static void printCounter()` выводит счётчик. Вызов — через имя класса: `Animal.printCounter()`.
-   В `main` создай животных из ввода, выведи счётчик, создай ещё одно конструктором по умолчанию и выведи счётчик снова.

### Что повторить

Если застрял, вернись к темам «Классы и объекты»: этап «static: общий счётчик объектов».

### Что должна вывести программа

При вводе `2`, `Барсик кот 3`, `Шарик собака 5`:

```text
Создано животных: 2
Создано животных: 3
```
