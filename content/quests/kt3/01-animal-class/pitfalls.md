## Частые грабли на защите

-   Конструктор с `void` перед именем — уже не конструктор, а обычный метод, и `new Animal("Барсик", "кот", 3)` не скомпилируется.
-   `name = name` без `this` оставит поле `null`.
-   Если есть только конструктор с параметрами, `new Animal()` не скомпилируется: пустой конструктор Java добавляет, только когда своих нет.
