## Зачем это нужно

Метод получил число и изменил его — изменится ли число в `main`? А если метод получил кота и поменял ему возраст? Ответы разные, и на этом вопросе проверяют, понимаешь ли ты, как Java передаёт значения в методы.

## Как это работает

В Java параметр — всегда **копия** того, что передали.

-   **Примитив** (`int`, `double`, `boolean`) — копируется само значение. Метод меняет свою копию, а переменная в `main` остаётся прежней.
-   **Объект** — копируется **ссылка**. Копия ссылки указывает на тот же объект в куче, поэтому изменения полей видны снаружи.

```java
class TimeMachine {
    void goToFuture(int year) {
        year = year + 10;            // меняется только копия
    }

    void goToFuture(Cat cat) {
        cat.age = cat.age + 10;      // меняется сам кот
    }
}
```

```java
int year = 2026;
machine.goToFuture(year);          // year в main всё ещё 2026

Cat barsik = new Cat("Барсик", 3);
machine.goToFuture(barsik);        // barsik.age теперь 13
```

Обрати внимание: у `goToFuture` две версии — это перегрузка из прошлого этапа. Компилятор выбирает версию по типу аргумента: `int` или `Cat`.

## Разбор: ловушка с новым объектом

```java
void replace(Cat cat) {
    cat = new Cat("Том", 1);     // копия ссылки теперь смотрит на другого кота
}
```

После `replace(barsik)` Барсик остался Барсиком. Метод перенаправил свою копию ссылки на нового кота, а переменная `barsik` в `main` по-прежнему указывает на старого. Меняются только **поля** объекта, на который смотрит ссылка.

## Твоё задание

Опиши класс `TimeMachine` с двумя версиями `goToFuture`: для года и для кота. В `main` прочитай год и возраст Барсика, отправь в будущее сначала год, потом кота. До и после каждой поездки выведи значения.

### Что должна вывести программа

При вводе `2026 3`:

```text
Год до поездки: 2026
Год после поездки: 2026
Возраст Барсика до поездки: 3
Возраст Барсика после поездки: 13
```
