## Зачем это нужно

Создать кота и потом по одному заполнять поля — долго, и легко забыть какое-нибудь поле: кот останется без имени. **Конструктор** заполняет поля прямо в момент создания: `new Cat("Барсик", 3)` — и кот сразу готов.

## Как это работает

```java
class Cat {
    String name;
    int age;

    Cat(String name, int age) {    // конструктор: имя как у класса, без типа результата
        this.name = name;
        this.age = age;
    }

    void printInfo() {
        System.out.println("Кот: " + name + ", возраст: " + age);
    }
}
```

-   Конструктор называется так же, как класс, и не имеет типа результата — даже `void`.
-   Он выполняется один раз, при `new`. Значения в скобках `new Cat("Барсик", 3)` попадают в его параметры.
-   **`this`** — ссылка на объект, который сейчас создаётся. Параметр `name` и поле `name` называются одинаково. `this.name` — поле объекта, просто `name` — параметр.
-   Если в классе нет ни одного конструктора, Java добавляет пустой конструктор без параметров. Как только ты написал свой, пустой пропадает, и `new Cat()` перестаёт компилироваться.

## Разбор: что выведет программа

```java
class Box {
    int size;
    Box(int size) {
        size = size;     // без this!
    }
}
```

`new Box(5).size` окажется равен 0. Строка `size = size` присвоила параметр самому себе, а поле осталось со значением по умолчанию. Нужно `this.size = size`.

## Твоё задание

Добавь в класс `Cat` конструктор с параметрами имени и возраста и метод `printInfo()`. В `main` прочитай из ввода двух котов — имя и возраст каждого, — создай их конструктором и выведи через `printInfo()`.

### Что должна вывести программа

При вводе `Барсик 3 Мурка 5`:

```text
Кот: Барсик, возраст: 3
Кот: Мурка, возраст: 5
```
