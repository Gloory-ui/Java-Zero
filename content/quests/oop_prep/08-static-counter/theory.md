## Зачем это нужно

Талоны в очереди нумеруются по порядку: первый клиент получает №1, второй — №2. Номер — у каждого талона свой, а счётчик выданных — **один на всех**. Такие общие данные класса помечают словом `static`.

## Как это работает

```java
class Coupon {
    static int issued = 0;    // одно поле на весь класс
    int number;               // у каждого талона своё

    Coupon() {
        issued++;             // общий счётчик растёт при каждом new
        number = issued;
    }

    static void printIssued() {
        System.out.println("Выдано талонов: " + issued);
    }
}
```

-   **`static`-поле** существует в одном экземпляре, сколько бы объектов ни создали, и даже когда объектов нет. В лекции это поле `cnt` в классе `Proba2`: у `obj1` и `obj2` оно общее.
-   **`static`-метод** не привязан к объекту. Его вызывают через имя класса: `Coupon.printIssued()`.
-   Внутри `static`-метода нет `this`, поэтому обычные поля вроде `number` ему недоступны без объекта. Общие `static`-поля — доступны.
-   Ты уже пользовался `static`-методами: `Math.random()`, да и сам `main` — `static`.

## Разбор: что выведет программа

```java
Coupon a = new Coupon();
Coupon b = new Coupon();
System.out.println(a.number + " " + b.number + " " + Coupon.issued);
```

Первый `new` сделал `issued = 1` и `a.number = 1`, второй — `issued = 2` и `b.number = 2`. Выведется `1 2 2`.

## Твоё задание

Опиши класс `Coupon` со `static`-счётчиком, номером талона и `static`-методом `printIssued()`. В `main` прочитай `n`, выдай `n` талонов и напечатай номер каждого, затем вызови `Coupon.printIssued()`.

### Что должна вывести программа

```text

Талон №2
```
