## Зачем это нужно

Два последних приёма работы с классами:

-   **Сравнение объектов.** Какой грузовик поднимет больше, какой кот старше. Оператор `>` для объектов не работает, а `==` сравнивает не содержимое, а ссылки.
-   **Статическая фабрика.** Метод класса, который создаёт объект с готовыми значениями: «стандартный пикап», «котёнок из приюта».

## Как это работает: сравнение

Сравнение пишут методом объекта. Он получает второй объект параметром и сравнивает поля — свои и чужие:

```java
boolean carriesMoreThan(Truck other) {
    return capacity > other.capacity;   // this.capacity и other.capacity
}
```

Вызов читается как фраза: `kamaz.carriesMoreThan(pickup)` — «КамАЗ везёт больше, чем пикап?». Если нужно три исхода — больше, меньше, поровну, — проверяют оба направления или возвращают разность `capacity - other.capacity`: плюс, минус или ноль.

А `a == b` для объектов проверяет, одна ли это ссылка. Два разных грузовика с одинаковыми полями не равны по `==`.

## Как это работает: фабрика

```java
static Truck createPickup() {
    return new Truck("Пикап", 1);    // предустановленные значения
}
```

-   Метод `static`: объекта ещё нет, поэтому фабрику вызывают через класс — `Truck.createPickup()`.
-   Внутри обычный `new` и `return`. Вызывающему коду не нужно помнить, какие значения у «стандартного пикапа».
-   Так устроены многие методы Java: `Integer.valueOf(5)`, `List.of(1, 2, 3)`.

## Разбор: что выведет программа

```java
Truck a = new Truck("Газель", 2);
Truck b = new Truck("Газель", 2);
System.out.println((a == b) + " " + a.carriesMoreThan(b));
```

Это два разных объекта, `==` даёт `false`. 2 не больше 2 — тоже `false`. Выведется `false false`.

## Твоё задание

Добавь в `Truck` метод `carriesMoreThan` и фабрику `createPickup()` — пикап грузоподъёмностью 1 т. В `main` создай пикап фабрикой и выведи его. Прочитай модель и грузоподъёмность второго грузовика и сравни: кто везёт больше или везут поровну.

### Что должна вывести программа

При вводе `КамАЗ 20`:

```text
Фабрика выпустила: Пикап, 1 т
КамАЗ везёт больше, чем Пикап
```
