## Зачем это нужно

Приют, библиотека, журнал группы — везде много однотипных объектов. Их складывают в **массив объектов** и обрабатывают циклом, как массив чисел: выводят, ищут самого старшего, считают.

## Как это работает

```java
Cat[] cats = new Cat[3];           // три пустые ячейки для ссылок на котов
cats[0] = new Cat("Барсик", 3);    // в ячейку кладём ссылку на нового кота
```

-   `new Cat[3]` создаёт **не котов**, а три ячейки для ссылок. Сначала в каждой лежит `null` — «никакого кота».
-   Котов создают отдельно, по одному `new Cat(...)` на ячейку.
-   Обращение к полю или методу через `null` роняет программу с `NullPointerException`.

```java
for (int i = 0; i < cats.length; i++) {
    cats[i].printCard(i + 1);      // метод каждого кота
}
```

## Карточка — метод объекта

Вывод одного кота удобно спрятать в метод. Кот сам знает свои поля, а номер карточки ему передают:

```java
void printCard(int number) {
    System.out.println("--- Карточка " + number + " ---");
    System.out.println("Имя: " + name);
    System.out.println("Возраст: " + age);
}
```

Поиск по массиву объектов — как по массиву чисел, только сравнивают поле: `cats[i].age > cats[oldest].age`. Запоминают индекс, как на этапе про обмен в «Массивах».

## Разбор: что выведет программа

```java
Cat[] cats = new Cat[2];
cats[0] = new Cat("Том", 4);
System.out.println(cats[1] == null);
```

Во вторую ячейку никого не положили, там `null`. Выведется `true`. Строка `cats[1].printCard(2)` упала бы с `NullPointerException`.

## Твоё задание

Первое число ввода — сколько котов, дальше имя и возраст каждого. Сохрани котов в массив `Cat[]`, выведи карточку каждого методом `printCard`, затем имя самого старшего. Если старших несколько, выводи первого.

### Что должна вывести программа

При вводе `3`, `Барсик 3`, `Мурка 5`, `Том 2`:

```text
--- Карточка 1 ---
Имя: Барсик
Возраст: 3
--- Карточка 2 ---
Имя: Мурка
Возраст: 5
--- Карточка 3 ---
Имя: Том
Возраст: 2
Самый старший: Мурка
```
