## Зачем это нужно

Иногда о коте известно всё, а иногда ничего: подобрали на улице. Иногда кот здоровается с одним гостем, иногда с двумя. Писать для каждого случая метод с новым именем неудобно. **Перегрузка** — несколько конструкторов или методов с одним именем, но разными параметрами.

## Как это работает

```java
class Cat {
    String name;
    int age;

    Cat() {                              // конструктор по умолчанию
        this("Безымянный", 1);           // вызывает второй конструктор
    }

    Cat(String name, int age) {          // конструктор с параметрами
        this.name = name;
        this.age = age;
    }

    void sayHi(String guest) {
        System.out.println(name + ": Привет, " + guest + "!");
    }

    void sayHi(String first, String second) {
        System.out.println(name + ": Привет, " + first + " и " + second + "!");
    }
}
```

-   Компилятор выбирает версию по **параметрам вызова**: `sayHi("Аня")` — первая, `sayHi("Аня", "Петя")` — вторая.
-   Версии должны отличаться числом или типами параметров. Только имена параметров или тип результата различием не считаются.
-   `this(...)` внутри конструктора вызывает другой конструктор этого же класса. Так значения по умолчанию задаются в одном месте. `this(...)` должен стоять первой строкой.

## Разбор: что выведет программа

```java
Cat c = new Cat();
c.sayHi("Оля");
```

Пустые скобки — сработал `Cat()`, он передал «Безымянный» и 1 во второй конструктор. Один гость — первая версия `sayHi`. Выведется `Безымянный: Привет, Оля!`.

## Твоё задание

Добавь в `Cat` конструктор по умолчанию (имя «Безымянный», возраст 1) и две версии `sayHi`. В `main` создай кота без параметров и Барсика трёх лет, выведи обоих через `printInfo()`. Потом прочитай из ввода имена двух гостей: пусть Барсик поздоровается с первым, а затем с обоими.

### Что должна вывести программа

При вводе `Аня Петя`:

```text
Кот: Безымянный, возраст: 1
Кот: Барсик, возраст: 3
Барсик: Привет, Аня!
Барсик: Привет, Аня и Петя!
```
