## Зачем это нужно

У кота есть имя, возраст, вес. Если котов десять, держать для каждого три отдельные переменные неудобно, и легко перепутать, чей возраст где. **Класс** описывает, из чего состоит кот. **Объект** — конкретный кот Барсик, сделанный по этому описанию.

## Как это работает

```java
class Cat {          // класс — чертёж
    String name;     // поля — данные, которые есть у каждого кота
    int age;
}
```

```java
Cat barsik = new Cat();        // объект — кот по чертежу
barsik.name = "Барсик";
barsik.age = 3;
System.out.println(barsik.name);   // Барсик
```

-   `class Cat` — новый тип данных, как `int` или `String`, только свой.
-   `new Cat()` создаёт объект в куче. В переменной `barsik` лежит **ссылка** на него, как у массива.
-   Точка — доступ к полю объекта: `barsik.age`.
-   Поля нового объекта заполнены значениями по умолчанию: `null` у строк, 0 у чисел.
-   У каждого объекта свои поля: у Мурки своё `age`, и Барсику оно не мешает.

## Где писать класс

В лаборатории весь код в одном файле. Сверху `public class OopPrep` с методом `main`, под ним `class Cat` — без слова `public`. В файле может быть только один `public`-класс, и его имя совпадает с именем файла. В IDE каждый класс обычно лежит в своём файле: `Cat.java`, `Main.java`.

## Разбор: что выведет программа

```java
Cat a = new Cat();
a.name = "Том";
Cat b = a;
b.age = 7;
System.out.println(a.name + " " + a.age);
```

`b = a` копирует ссылку, а не объект: обе переменные смотрят на одного и того же кота. Возраст, записанный через `b`, виден и через `a`. Выведется `Том 7`.
