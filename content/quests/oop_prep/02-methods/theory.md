## Зачем это нужно

Объект — это не только данные, но и действия с ними. Грузовик умеет посчитать свой объём, кот — мяукнуть. Действие объекта — это **метод**: набор команд внутри класса, который работает с полями своего объекта.

## Как это работает

```java
class Truck {
    int length;
    int width;
    int height;

    void printInfo() {                    // void — метод ничего не возвращает
        System.out.println("Грузовик " + length + " на " + width + " на " + height);
    }

    int getVolume() {                     // int — метод возвращает целое число
        return length * width * height;
    }
}
```

-   Метод вызывают через точку у объекта: `truck.printInfo()`. Скобки обязательны, даже пустые.
-   Внутри метода поля пишутся просто по имени: `length` — это поле того грузовика, у которого вызвали метод.
-   `void` — метод только что-то делает, результата у него нет.
-   Тип перед именем (`int`) — метод **возвращает** значение. `return` отдаёт его наружу и сразу завершает метод. Результат можно положить в переменную или напечатать: `int v = truck.getVolume();`.

Метод может принимать **параметры** — значения на вход, как `println` принимает текст. О них — на следующих этапах.

## Разбор: что выведет программа

```java
Truck t = new Truck();
t.length = 5;
t.width = 2;
t.height = 2;
int v = t.getVolume();
System.out.println(v + 1);
```

`getVolume()` вернёт 5 · 2 · 2 = 20, в переменную `v` попадёт 20. Выведется `21`.

## Твоё задание

Опиши класс `Truck` с полями `length`, `width`, `height` и двумя методами: `printInfo()` печатает размеры, `getVolume()` возвращает объём. В `main` прочитай три размера из ввода, запиши их в поля грузовика, вызови `printInfo()` и выведи объём.

### Что должна вывести программа

При вводе `4 2 3`:

```text
Грузовик 4 на 2 на 3
Объём: 24
```
