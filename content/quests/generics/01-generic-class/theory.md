## Зачем это нужно

`ArrayList<String>` хранит строки, `ArrayList<Integer>` — числа, а класс при этом один. Тип элементов подставляется в угловые скобки. Так же можно написать свой класс: один раз, для любого типа. Такие классы называют **обобщёнными**, или дженериками.

## Как это работает

```java
class Box<T> {                 // T — параметр типа, «какой-то тип»
    private T value;

    Box(T value) {
        this.value = value;
    }

    T get() {
        return value;
    }
}

Box<String> name = new Box<>("Аня");   // здесь T = String
Box<Integer> age = new Box<>(19);      // здесь T = Integer
int len = name.get().length();         // компилятор знает, что get() вернёт String
```

-   `T` — имя параметра типа. Принято: `T` — тип, `E` — элемент, `K` и `V` — ключ и значение.
-   Параметров может быть несколько: `class Pair<A, B>`.
-   `new Box<>(...)` — «ромб»: тип в правой части компилятор выведет сам.
-   Без дженериков пришлось бы хранить `Object` и приводить тип вручную: `(String) box.get()`. Ошибка в приведении всплыла бы только при запуске.

## Разбор: что выведет программа

```java
Box<Double> price = new Box<>(9.5);
Box<Box<Double>> wrapped = new Box<>(price);
System.out.println(wrapped.get().get() * 2);
```

Коробка внутри коробки: `wrapped.get()` возвращает `Box<Double>`, второй `get()` — число:

```text
19.0
```
