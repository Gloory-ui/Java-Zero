## Зачем это нужно

Все коллекции Java — обобщённые классы, написанные обычным кодом. Самое честное упражнение — написать такую коллекцию самому. Заодно станет видно, где дженерики упираются в свои ограничения.

## Как это работает

Дженерики существуют только **при компиляции**. Компилятор проверяет типы, а потом стирает их: в работающей программе `MyStack<String>` и `MyStack<Integer>` — один и тот же класс, а `T` превращается в `Object`. Это называется **стиранием типов**. Из-за него:

-   `new T()` и `new T[10]` написать нельзя: при запуске неизвестно, что такое `T`;
-   `x instanceof List<String>` не скомпилируется — проверить можно только `List<?>`;
-   два метода `print(List<String>)` и `print(List<Integer>)` после стирания совпадут, и компилятор их не пропустит.

Поэтому элементы обобщённой коллекции хранят в `Object[]`, а при выдаче приводят к `T`:

```java
private Object[] data = new Object[2];

@SuppressWarnings("unchecked")
T get(int i) {
    return (T) data[i];     // безопасно: кладём туда только T
}
```

Когда массив заполнен, его расширяют: `data = Arrays.copyOf(data, data.length * 2);` создаёт копию вдвое длиннее.

## Разбор: что выведет программа

```java
List<String> a = new ArrayList<>();
List<Integer> b = new ArrayList<>();
System.out.println(a.getClass() == b.getClass());
```

После стирания это один класс `ArrayList`:

```text
true
```

## Твоё задание

Допиши класс `MyStack<T>`:

-   `push` кладёт элемент наверх и расширяет массив вдвое, когда места нет;
-   `pop` снимает и возвращает верхний элемент, а у пустого стека бросает `IllegalStateException` с текстом «Стек пуст»;
-   `peek` возвращает верхний элемент без снятия;
-   `size` и `isEmpty`.

### Что должна вывести программа

```text
Сверху: в
Снято: в
Снято: б
Размер: 1
Сумма: 15
Ошибка: Стек пуст
```
