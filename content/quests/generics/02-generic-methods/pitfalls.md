## Частые грабли

-   **`<T>` не на месте.** `static T firstOrDefault(...)` без объявления — «T cannot be resolved to a type». Параметр объявляют перед типом результата: `static <T> T ...`.
-   **`==` для объектов.** `list.get(i) == target` сравнивает ссылки. Для строк и чисел больше 127 результат будет неверным. Используй `equals`.
-   **`int[]` вместо `Integer[]`.** `swap(new int[] {1, 2}, 0, 1)` не скомпилируется: `T` не может быть примитивом.
