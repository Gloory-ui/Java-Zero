## Зачем это нужно

Метод «первый элемент списка или значение по умолчанию» одинаково работает для строк, чисел и студентов. Писать его трижды незачем. Метод тоже можно сделать обобщённым: параметр типа объявляется прямо у метода.

## Как это работает

```java
static <T> T lastOf(List<T> list) {       // <T> перед типом результата
    return list.get(list.size() - 1);
}

String s = lastOf(List.of("а", "б"));     // T = String — компилятор вывел сам
Integer n = lastOf(List.of(1, 2, 3));     // T = Integer
```

-   `<T>` стоит перед типом результата и объявляет параметр для этого метода.
-   Тип подставляется по аргументам — указывать его при вызове не нужно.
-   Объекты типа `T` сравнивают через `equals`: о `T` известно только то, что это объект.
-   Обобщённый метод работает с массивами объектов (`Integer[]`, `String[]`), но не с `int[]`: примитивы не подходят на место `T`.

`Arrays.toString(массив)` печатает массив в квадратных скобках, как список.

## Разбор: что выведет программа

```java
static <T> void repeat(T value, int times) {
    for (int i = 0; i < times; i++) {
        System.out.print(value + " ");
    }
    System.out.println();
}
// repeat("эй", 2); repeat(7, 3);
```

```text
эй эй
7 7 7
```

## Твоё задание

Напиши три обобщённых метода:

-   `firstOrDefault(List<T> list, T def)` — первый элемент или `def` для пустого списка;
-   `countEqual(List<T> list, T target)` — сколько элементов равны `target` по `equals`;
-   `swap(T[] arr, int i, int j)` — обменять два элемента массива.
