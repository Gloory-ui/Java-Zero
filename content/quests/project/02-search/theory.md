## Зачем это нужно

Библиотекарю нужно быстро ответить: есть ли книга с номером B3, что у нас есть Булгакова, какие книги со словом «мир». Поиск — первое, что делают с любым каталогом. Здесь пригодятся `Optional` и потоки.

## Как это работает

-   **По номеру** — прямо из словаря. Книги может не быть, поэтому метод возвращает `Optional<Book>`: `Optional.ofNullable(books.get(id))`. `get` вернёт `null` для незнакомого номера, а `ofNullable` превратит его в пустую коробку.
-   **По автору и по слову** — потоком по книгам с `filter`.
-   Люди пишут «булгаков» и «Булгаков». Сравнение без учёта регистра — `equalsIgnoreCase`. Для поиска части слова обе строки приводят к нижнему регистру: `title.toLowerCase().contains(part.toLowerCase())`.

```java
List<Book> recent = books.values().stream()
    .filter(b -> b.year() > 1900)
    .toList();
```

## Разбор: что выведет программа

```java
Optional<Book> found = Optional.ofNullable(null);
System.out.println(found.map(Book::title).orElse("не найдена"));
```

Коробка пустая, `map` не срабатывает, и выводится запасное значение:

```text
не найдена
```
