## Зачем это нужно

Ты прошёл классы, коллекции, исключения, потоки данных и файлы. Пора собрать всё в одну настоящую программу: консольную библиотеку. В ней есть каталог книг, поиск, выдача читателям, меню команд, сохранение в файл и отчёт. Каждый этап добавляет одну часть, а код переходит из этапа в этап.

## Как это работает

Программу делят на слои, у каждого своя работа:

| Слой | Что делает |
| --- | --- |
| `record Book` | хранит данные одной книги |
| `class Library` | правила библиотеки: добавить, найти, выдать |
| `class LibraryApp` | общается с человеком: читает команды, печатает ответы |

Каталог хранится в `LinkedHashMap<String, Book>`: ключ — номер книги, значение — сама книга. Словарь находит книгу по номеру сразу, а `LinkedHashMap` ещё и помнит порядок добавления.

```java
class Shelf {
    private final Map<String, Book> books = new LinkedHashMap<>();

    List<Book> all() {
        return new ArrayList<>(books.values());   // копия, а не сам словарь
    }
}
```

`all()` отдаёт **копию** списка. Если отдать наружу внутреннюю коллекцию, любой код сможет менять каталог в обход правил библиотеки. Это инкапсуляция из квеста про классы.

## Разбор: что выведет программа

```java
record Book(String id, String title, String author, int year) {
    String line() {
        return id + " | " + title;
    }
}
System.out.println(new Book("X1", "Азбука", "Народ", 1900).line());
```

В записи можно объявлять свои методы, и они видят компоненты по имени:

```text
X1 | Азбука
```

## Твоё задание

Допиши три метода:

-   `Book.line()` — строка «номер | название | автор | год»;
-   `Library.add(book)` — положить книгу в каталог по её номеру;
-   `Library.all()` — все книги в порядке добавления, копией.

### Что должна вывести программа

```text
B1 | Мастер и Маргарита | Булгаков | 1967
B2 | Война и мир | Толстой | 1869
B3 | Собачье сердце | Булгаков | 1925
B4 | Преступление и наказание | Достоевский | 1866
Книг в каталоге: 4
```
