## Зачем это нужно

Финал: библиотекарь в конце дня хочет сводку — сколько книг, сколько на руках, кто самый популярный автор и у кого что лежит. Отчёт печатается и сохраняется в файл, чтобы его можно было отправить. Заодно у меню появится `help` — список команд для новичка.

## Как это работает

Отчёт удобно строить как список строк: его можно и напечатать, и записать одним `Files.write`.

Для «читатель → его книги» нужен словарь, где значение — список. Новый метод `computeIfAbsent` берёт список по ключу, а если его нет, сначала создаёт:

```java
Map<String, List<String>> byReader = new TreeMap<>();
byReader.computeIfAbsent("Вика", r -> new ArrayList<>()).add("Идиот");
byReader.computeIfAbsent("Вика", r -> new ArrayList<>()).add("Собачье сердце");
// {Вика=[Идиот, Собачье сердце]}
```

-   Лямбда во втором аргументе вызывается, только если ключа ещё нет.
-   Для самого частого автора подойдёт `countByAuthor()` из прошлых этапов и поиск максимума строгим `>`: при равенстве останется первый по алфавиту.

## Разбор: что выведет программа

```java
Map<String, Long> counts = new TreeMap<>(Map.of("Гоголь", 1L, "Блок", 2L, "Фет", 2L));
String top = "нет";
long best = 0;
for (Map.Entry<String, Long> e : counts.entrySet()) {
    if (e.getValue() > best) {
        best = e.getValue();
        top = e.getKey();
    }
}
System.out.println(top);
```

У Блока и Фета по 2, но Блок раньше по алфавиту, а `>` не заменяет равного:

```text
Блок
```
