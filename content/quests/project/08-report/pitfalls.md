## Частые грабли

-   **`get` + `put` для списков.** `byReader.get(name).add(title)` для нового читателя бросит «NullPointerException». `computeIfAbsent` создаёт список сам.
-   **`>=` при поиске автора.** С `>=` при равенстве победит Достоевский, последний по алфавиту из равных.
-   **Отчёт только на экран.** Если не записать строки в файл, `report.txt` не появится. Список строк отдаёт `Files.write` одним вызовом.
