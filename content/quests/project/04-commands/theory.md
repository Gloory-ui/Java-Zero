## Зачем это нужно

Пока библиотека работает по заранее записанному сценарию. Настоящая программа слушает человека: он пишет команду, программа отвечает, и так, пока он не скажет «выход». Это меню команд — сердце любой консольной программы.

## Как это работает

Строку делят на команду и её аргумент. `split("\\s+", 2)` режет строку **не больше чем на две части**, поэтому аргумент с пробелами остаётся целым:

```java
String[] parts = "borrow B2 Анна Каренина".split("\\s+", 2);
// parts[0] = "borrow", parts[1] = "B2 Анна Каренина"
String cmd = parts[0].toLowerCase();
String arg = parts.length > 1 ? parts[1] : "";
```

Дальше `switch` со стрелками выбирает действие. Ошибки библиотеки ловит один общий `try` вокруг `switch`: какая бы команда ни сломалась, программа напишет «Ошибка: …» и продолжит слушать.

```java
try {
    switch (cmd) {
        case "list" -> list(lib);
        case "return" -> lib.giveBack(arg);
        default -> System.out.println("Неизвестная команда: " + cmd);
    }
} catch (BookNotFoundException | IllegalStateException e) {
    System.out.println("Ошибка: " + e.getMessage());
}
```

-   В ветке со стрелкой можно написать блок в фигурных скобках, если действий несколько.
-   «exit» проверяют до `switch`: оттуда `return` выходит из метода и заканчивает цикл.

## Разбор: что выведет программа

Для строки `borrow B2` у команды нет имени читателя: `arg.split("\\s+", 2)` даст массив из одного элемента. Поэтому длину проверяют заранее и печатают подсказку:

```text
Формат: borrow номер имя
```

## Твоё задание

Допиши `list` — каталог, где у выданных книг в конце « — у Имя». Потом допиши `switch` в `run`:

-   `list` — каталог;
-   `find слово` — «Найдено: [названия]»;
-   `borrow номер имя` — выдача, без имени — «Формат: borrow номер имя»;
-   `return номер` — «номер возвращена»;
-   любая другая команда — «Неизвестная команда: …».

Ошибки библиотеки печатай как «Ошибка: …».

### Что должна вывести программа

Для ввода из примера:

```text
B2 выдана: Аня
B1 | Мастер и Маргарита | Булгаков | 1967
B2 | Война и мир | Толстой | 1869 — у Аня
B3 | Собачье сердце | Булгаков | 1925
B4 | Преступление и наказание | Достоевский | 1866
Найдено: [Собачье сердце]
B2 возвращена
Ошибка: Книга B2 и так в библиотеке
Неизвестная команда: fly
До встречи!
```
