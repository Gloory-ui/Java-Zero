## Зачем это нужно

Библиотекарю нужны порядок и цифры: книги по году или по алфавиту, сколько у нас каждого автора, какая книга самая старая. Здесь соберутся компараторы и коллекторы из прошлых квестов.

## Как это работает

Правило сортировки выбирают по слову из команды. `switch` со стрелками умеет **возвращать значение**, так что правило получается одной конструкцией:

```java
Comparator<Book> order = switch (key) {
    case "year" -> Comparator.comparingInt(Book::year);
    case "title" -> Comparator.comparing(Book::title);
    default -> throw new IllegalArgumentException("Не знаю такой сортировки");
};
return books.values().stream().sorted(order).toList();
```

-   В ветке `switch` можно бросить исключение — тогда значения у неё нет, и компилятор это понимает.
-   Статистика — готовые коллекторы и числовые потоки: `groupingBy(..., TreeMap::new, counting())`, `mapToInt(...).average()`, `min(компаратор)`.
-   `average()` и `min()` возвращают «может быть, значение»: у пустого каталога среднего года нет.

## Разбор: что выведет программа

```java
List<Integer> years = List.of(1925, 1866);
System.out.println(years.stream().mapToInt(Integer::intValue).average().orElse(0));
```

(1925 + 1866) / 2:

```text
1895.5
```

## Твоё задание

Меню уже знает команды `sort` и `stats`. Допиши в `Library`:

-   `sortedBy(key)` — по году (`year`), по названию (`title`) или по автору, а у одного автора по названию (`author`). Для другого ключа — `IllegalArgumentException` с текстом «Сортировка: year, title или author»;
-   `countByAuthor()` — число книг по авторам, авторы по алфавиту;
-   `averageYear()` — средний год;
-   `oldest()` — самая старая книга.
