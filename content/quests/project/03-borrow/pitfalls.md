## Частые грабли

-   **Проверки в неправильном порядке.** Если сначала проверять «уже выдана», для несуществующей книги сообщение будет странным. Сначала — есть ли книга вообще.
-   **`put` без проверки.** `borrowedBy.put(id, reader)` для выданной книги молча заменит читателя: книга «перейдёт» от Ани к Борису.
-   **Нет `throws`.** Методы, которые бросают проверяемые исключения, объявляют их: `void borrow(...) throws BookNotFoundException, AlreadyBorrowedException`.
