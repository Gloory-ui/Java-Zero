## Зачем это нужно

Пользователь может ввести что угодно: книгу из 3000 года, год словом «давно», номер, который уже занят, или вообще строку без разделителей. Если такие данные попадут в каталог, отчёты и файлы станут враньём. Проверки ставят в двух местах: там, где создаётся объект, и там, где разбирают ввод.

## Как это работает

**Объект сам себя защищает.** Компактный конструктор записи не даст создать книгу с невозможным годом, откуда бы её ни создавали: из меню, из файла, из теста.

```java
record Book(String id, String title, String author, int year) {
    Book {
        if (year < 1450 || year > 2026) {
            throw new IllegalArgumentException("Год вне диапазона: " + year);
        }
    }
}
```

**Библиотека защищает правила.** `add` отказывается от уже занятого номера.

**Меню переводит ошибки на человеческий язык.** Разбор команды `add номер;название;автор;год`:

-   частей не 4 — подсказать формат;
-   год не число — `NumberFormatException`, сообщить, что год должен быть числом;
-   остальное (год вне диапазона, занятый номер) — `IllegalArgumentException`, его уже ловит общий `catch` меню.

`NumberFormatException` — наследник `IllegalArgumentException`. Поэтому его ловят прямо в разборе, иначе общий `catch` напечатал бы невнятное «For input string».

## Разбор: что выведет программа

```java
try {
    new Book("X", "Свиток", "Писец", 1000);
} catch (IllegalArgumentException e) {
    System.out.println(e.getMessage());
}
```

```text
Год вне диапазона: 1000
```

## Твоё задание

1.  Добавь в `Book` компактный конструктор с проверкой года: от 1450 до 2026.
2.  В `Library.add` брось `IllegalArgumentException` «Номер N уже занят» для повторного номера.
3.  Допиши `addBook`: разбери строку по «;», обрежь пробелы, создай и добавь книгу, напечатай «Добавлена: …». Неверный формат и год-не-число обработай по правилам выше.
