## Задание 5 (Формулировка из билета)

**Реализовать игру «Угадай число». Программа загадывает число, вы вводите догадки, после каждой попытки выводится подсказка «больше» или «меньше». Ограничить число попыток.**

**Архитектура решения:**

-   Загадай число. В лаборатории оно фиксированное, `int target = 42;`, чтобы тесты знали ответ. На защите можно показать случайное: `(int)(Math.random() * 100) + 1`.
-   Задай лимит: `int maxAttempts = 5;` и счетчик `int attempts = 0;`.
-   Ввод: `Scanner sc = new Scanner(System.in);` уже есть в стартовом коде. Каждый вызов `sc.nextInt()` читает следующее число из поля «Ввод для программы» (кнопка «Запуск с вводом»).
-   В цикле `while (attempts < maxAttempts)` считывай догадку `int guess = sc.nextInt();`:
    -   Если `guess == target`: выведи «Угадал!» и сделай `break;`
    -   Если `guess < target`: выведи «больше»
    -   Если `guess > target`: выведи «меньше»
-   Если за пять попыток число не угадано, цикл заканчивается сам, и программа просто завершается.

### Что должна вывести программа

При вводе `10`, `90`, `42`:

```text
больше
меньше
Угадал!
```
