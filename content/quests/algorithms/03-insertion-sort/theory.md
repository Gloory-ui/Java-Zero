## Зачем это нужно

Так сортируют карты в руке: берут следующую карту и вставляют её на нужное место среди уже упорядоченных. **Сортировка вставками** на почти отсортированных данных работает очень быстро, поэтому её используют внутри «взрослых» сортировок для маленьких кусков.

## Как это работает

```java
for (int i = 1; i < a.length; i++) {
    int key = a[i];                 // карта, которую вставляем
    int j = i - 1;
    while (j >= 0 && a[j] > key) {  // сдвигаем большие вправо
        a[j + 1] = a[j];
        j--;
    }
    a[j + 1] = key;                 // ставим в освободившееся место
}
```

-   Левая часть `a[0..i-1]` всегда отсортирована.
-   Элементы не меняются попарно, а **сдвигаются** вправо, освобождая место для `key`.
-   Если массив уже почти отсортирован, `while` почти не работает, и сортировка идёт за линейное время.

## Разбор: что выведет программа

Для `[3, 1, 2]`:

-   `key = 1`: 3 больше, сдвигаем → `[1, 3, 2]`, один сдвиг;
-   `key = 2`: 3 больше, сдвигаем, 1 не больше → `[1, 2, 3]`, ещё один сдвиг.

```text
[1, 3, 2]
[1, 2, 3]
Сдвигов: 2
```

## Твоё задание

Отсортируй числа из ввода вставками. После вставки каждого элемента печатай массив, в конце — число сдвигов.

### Что должна вывести программа

Для ввода `12 11 13 5 6`:

```text
Вставлен 11: [11, 12, 13, 5, 6]
Вставлен 13: [11, 12, 13, 5, 6]
Вставлен 5: [5, 11, 12, 13, 6]
Вставлен 6: [5, 6, 11, 12, 13]
Сдвигов: 7
```
