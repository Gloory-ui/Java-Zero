## Зачем это нужно

Пузырёк делает много обменов: каждое сравнение может двигать элементы. **Сортировка выбором** меняет элементы местами не больше одного раза за шаг. Это важно, когда перемещать данные дорого — например, тяжёлые записи на медленном носителе.

## Как это работает

На каждом шаге ищем минимум в неотсортированной части и ставим его на первое свободное место:

```java
for (int i = 0; i < a.length - 1; i++) {
    int min = i;                           // индекс минимума в хвосте
    for (int j = i + 1; j < a.length; j++) {
        if (a[j] < a[min]) {
            min = j;
        }
    }
    int tmp = a[i];                        // один обмен за шаг
    a[i] = a[min];
    a[min] = tmp;
}
```

-   Левая часть массива растёт и всегда отсортирована.
-   Хранят **индекс** минимума, а не само значение: иначе не узнать, с какой позицией меняться.
-   Сравнений по-прежнему около n² / 2, но обменов — не больше n.

## Разбор: что выведет программа

Для `[4, 3, 1]`:

-   шаг 1: минимум всего массива — 1, меняем с 4 → `[1, 3, 4]`;
-   шаг 2: минимум в `[3, 4]` — 3, он уже на месте → `[1, 3, 4]`.

```text
[1, 3, 4]
[1, 3, 4]
```

## Твоё задание

Отсортируй числа из ввода выбором. На каждом шаге печатай найденный минимум и массив после обмена.

### Что должна вывести программа

Для ввода `64 25 12 22 11`:

```text
Шаг 1: минимум 11 → [11, 25, 12, 22, 64]
Шаг 2: минимум 12 → [11, 12, 25, 22, 64]
Шаг 3: минимум 22 → [11, 12, 22, 25, 64]
Шаг 4: минимум 25 → [11, 12, 22, 25, 64]
```
