## Зачем это нужно

**Быстрая сортировка** на практике обычно обгоняет слияние и не требует копий массива. На ней основаны многие стандартные сортировки. Идея: выбрать элемент-**опору** и разложить массив так, чтобы слева от опоры были меньшие, а справа — большие.

## Как это работает

Разбиение по схеме Ломуто: опора — последний элемент отрезка.

```java
static int partition(int[] a, int lo, int hi) {
    int pivot = a[hi];
    int i = lo - 1;                     // граница зоны «меньше опоры»
    for (int j = lo; j < hi; j++) {
        if (a[j] < pivot) {
            i++;
            swap(a, i, j);              // переносим меньший в зону
        }
    }
    swap(a, i + 1, hi);                 // опора встаёт между зонами
    return i + 1;                       // её окончательное место
}

static void quickSort(int[] a, int lo, int hi) {
    if (lo < hi) {
        int p = partition(a, lo, hi);
        quickSort(a, lo, p - 1);        // слева от опоры
        quickSort(a, p + 1, hi);        // справа от опоры
    }
}
```

-   После разбиения опора стоит на своём окончательном месте, и её больше не трогают.
-   Сортировка идёт на месте: копий массива нет.
-   В среднем O(n log n). Но если опора всё время крайняя (например, массив уже отсортирован), выходит O(n²). Поэтому на практике опору выбирают хитрее.

## Разбор: что выведет программа

Разбиение `[3, 1, 2]` с опорой 2: 3 не меньше 2, 1 меньше — меняем с 3 → `[1, 3, 2]`. В конце опора встаёт на индекс 1:

```text
[1, 2, 3], опора на месте 1
```

## Твоё задание

Допиши `partition` по схеме Ломуто. После каждого разбиения печатай опору и массив целиком. В конце выведи итог.

### Что должна вывести программа

Для ввода `4 9 2 7 5`:

```text
Опора 5: [4, 2, 5, 7, 9]
Опора 2: [2, 4, 5, 7, 9]
Опора 9: [2, 4, 5, 7, 9]
Итог: [2, 4, 5, 7, 9]
```
