## Зачем это нужно

`Collections.sort` сортирует за тебя, но на собеседованиях и экзаменах просят написать сортировку руками. К тому же, когда понимаешь, как устроены алгоритмы, проще выбрать правильный инструмент. Начнём с самого наглядного — **сортировки пузырьком**.

## Как это работает

Идём по массиву и сравниваем соседей. Если левый больше правого — меняем их местами. За один проход самый большой элемент «всплывает» в конец, как пузырёк. Повторяем проходы, пока массив не отсортируется.

```java
for (int i = 0; i < a.length - 1; i++) {          // номер прохода
    boolean swapped = false;
    for (int j = 0; j < a.length - 1 - i; j++) {  // конец уже отсортирован
        if (a[j] > a[j + 1]) {
            int tmp = a[j];
            a[j] = a[j + 1];
            a[j + 1] = tmp;
            swapped = true;
        }
    }
    if (!swapped) break;                           // обменов не было — готово
}
```

-   После прохода `i` последние `i + 1` элементов уже на местах, поэтому внутренний цикл идёт до `a.length - 1 - i`.
-   Флаг `swapped` останавливает сортировку, когда обменов не было: массив уже упорядочен.
-   `Arrays.toString(a)` печатает массив в квадратных скобках.
-   Список чисел из ввода превращают в массив так: `list.stream().mapToInt(Integer::intValue).toArray()`.

## Разбор: что выведет программа

Для массива `[3, 1, 2]` первый проход: 3 и 1 меняются, потом 3 и 2 меняются — `[1, 2, 3]`. Второй проход обменов не делает, и сортировка заканчивается.

```text
[1, 2, 3] — после первого прохода
[1, 2, 3] — после второго, обменов нет
```

## Твоё задание

Отсортируй числа из ввода пузырьком. После каждого прохода печатай массив. Когда за проход не было ни одного обмена, остановись. В конце выведи, сколько всего было обменов.

### Что должна вывести программа

Для ввода `5 1 4 2 8`:

```text
Проход 1: [1, 4, 2, 5, 8]
Проход 2: [1, 2, 4, 5, 8]
Проход 3: [1, 2, 4, 5, 8]
Обменов: 4
```
