## Зачем это нужно

Найти слово в словаре на тысячу страниц можно, листая с первой. А можно открыть посередине, понять, в какой половине слово, и отбросить другую. Так за десять шагов найдётся любое слово. Это **бинарный поиск**, и работает он только на отсортированных данных.

## Как это работает

```java
int lo = 0, hi = a.length - 1;
while (lo <= hi) {
    int mid = (lo + hi) / 2;          // середина отрезка
    if (a[mid] == target) {
        return mid;                   // нашли
    } else if (a[mid] < target) {
        lo = mid + 1;                 // искомое правее
    } else {
        hi = mid - 1;                 // искомое левее
    }
}
return -1;                            // отрезок пуст — не нашли
```

-   Каждый шаг отбрасывает половину оставшегося отрезка.
-   Для миллиона элементов хватает 20 шагов, для миллиарда — 30.
-   Массив обязан быть отсортирован, иначе отбрасывать половины нельзя.
-   Для огромных массивов середину считают как `lo + (hi - lo) / 2`, чтобы `lo + hi` не переполнило `int`.

## Разбор: что выведет программа

Ищем 7 в `[1, 3, 5, 7, 9]`:

-   `lo = 0, hi = 4, mid = 2`: там 5, это меньше 7 → `lo = 3`;
-   `lo = 3, hi = 4, mid = 3`: там 7 — нашли за 2 шага.

```text
индекс 3, шагов 2
```

## Твоё задание

Массив уже отсортирован. Для каждого числа из ввода найди его бинарным поиском и выведи индекс и число шагов. Шаг — одна проверка середины. Если числа нет, выведи «не найден» и сколько шагов понадобилось, чтобы это понять.

### Что должна вывести программа

Для ввода `42 3 104 50`:

```text
42: индекс 4, шагов 1
3: индекс 0, шагов 3
104: индекс 9, шагов 4
50: не найден, шагов 3
```
