## Зачем это нужно

Пузырёк, выбор и вставки работают за O(n²): миллион чисел они сортируют триллион шагов. **Сортировка слиянием** справляется за O(n log n) — примерно 20 миллионов шагов. Её идея: разделить задачу пополам, решить половинки и объединить ответы.

## Как это работает

1.  Массив из одного элемента уже отсортирован — это база рекурсии.
2.  Иначе делим массив пополам и сортируем каждую половину **рекурсивно**.
3.  Сливаем две отсортированные половины в одну.

```java
static int[] mergeSort(int[] a) {
    if (a.length <= 1) return a;
    int mid = a.length / 2;
    int[] left = mergeSort(Arrays.copyOfRange(a, 0, mid));
    int[] right = mergeSort(Arrays.copyOfRange(a, mid, a.length));
    return merge(left, right);
}

static int[] merge(int[] l, int[] r) {
    int[] out = new int[l.length + r.length];
    int i = 0, j = 0, k = 0;
    while (i < l.length && j < r.length) {
        out[k++] = l[i] <= r[j] ? l[i++] : r[j++];   // берём меньший из голов
    }
    while (i < l.length) out[k++] = l[i++];          // дописываем остаток
    while (j < r.length) out[k++] = r[j++];
    return out;
}
```

-   `Arrays.copyOfRange(a, from, to)` — копия куска с `from` включительно до `to` не включая.
-   Слияние идёт одним проходом: головы обеих половин сравниваются, меньшая уходит в результат.
-   Уровней деления — log n, на каждом уровне сливается n элементов. Отсюда O(n log n).

## Разбор: что выведет программа

`merge([2, 9], [4, 5])`: 2 < 4 → 2; 9 > 4 → 4; 9 > 5 → 5; остаток левой — 9.

```text
[2, 4, 5, 9]
```

## Твоё задание

Допиши `merge`, а в `mergeSort` рекурсию. Каждое слияние печатай в виде «Слияние левая + правая → результат». В конце выведи итог.

### Что должна вывести программа

Для ввода `38 27 43 3`:

```text
Слияние [38] + [27] → [27, 38]
Слияние [43] + [3] → [3, 43]
Слияние [27, 38] + [3, 43] → [3, 27, 38, 43]
Итог: [3, 27, 38, 43]
```
