## Частые грабли

-   **Нет базы рекурсии.** Без `if (a.length <= 1) return a;` деление пойдёт бесконечно и закончится «StackOverflowError».
-   **Забытый остаток.** Когда одна половина кончилась, во второй остаются элементы. Без двух дописывающих циклов они потеряются.
-   **`<` вместо `<=`.** Результат будет отсортирован, но равные элементы из правой половины обгонят левые. С `<=` сортировка устойчивая.
