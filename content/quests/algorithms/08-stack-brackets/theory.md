## Зачем это нужно

Компилятор проверяет, что каждая скобка закрыта парной: `{ [ ( ) ] }`. Эта задача решается **стеком**: открывающие скобки кладём, а на каждую закрывающую снимаем верхнюю и сверяем пару. В финале квеста напишем стек сами — на массиве, без готовых классов.

## Как это работает

Стек на массиве — это массив и счётчик заполненных ячеек:

```java
class IntStack {
    private int[] data = new int[16];
    private int size;

    void push(int x) {
        if (size == data.length) data = Arrays.copyOf(data, size * 2);
        data[size++] = x;
    }

    int pop() {
        return data[--size];
    }

    boolean isEmpty() {
        return size == 0;
    }
}
```

Проверка скобок:

1.  Открывающую `(`, `[`, `{` кладём в стек.
2.  На закрывающую: если стек пуст или сверху не её пара — ошибка в этой позиции.
3.  В конце стек должен быть пуст. Иначе какие-то скобки не закрыты.

Остальные символы пропускаем. Пару удобно проверять так: `"([{".indexOf(open) == ")]}".indexOf(close)`.

## Разбор: что выведет программа

Для строки `[(])`:

-   `[` и `(` уходят в стек;
-   `]` на позиции 3 — сверху лежит `(`, пара не та.

```text
ошибка в позиции 3
```

## Твоё задание

Допиши класс `CharStack` на массиве и проверку скобок. Для каждой строки из ввода выведи:

-   «OK», если всё сбалансировано;
-   «ошибка в позиции N» — для первой неправильной закрывающей скобки, позиции с единицы;
-   «не закрыто N», если в конце в стеке осталось N скобок.

### Что должна вывести программа

Для ввода из примера:

```text
(a[b]{c}): OK
([)]: ошибка в позиции 3
{[()()]}: OK
((x): не закрыто 1
)(: ошибка в позиции 1
```
