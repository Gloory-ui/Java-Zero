# Изменения

Версии — по [SemVer](https://semver.org/lang/ru/).

## 1.1.0 — 2026-10-02

### Честная таблица лидеров

- Опыт в лидерборде и на публичной странице профиля считается только за настоящие этапы, достижения и квесты дня курса и не больше честного максимума: этап — 70 XP, задание КТ — 110 XP. Выдуманные этапы и опыт сверх возможного в рейтинг не попадают.
- Квесты дня, присланные задним числом, в рейтинг не идут. Опыт на самом сайте у студента не меняется.
- Список этапов и достижений сервер обновляет сам при каждом запуске: новые этапы сразу идут в рейтинг.

### Админка (`/admin`)

- «Лидерборд»: все студенты, признаки накрутки, снятие с рейтинга с причиной и возврат. Прогресс студента при этом не меняется.
- «Квесты»: правки названий, теории, частых ошибок, подсказок и вопроса квиза поверх файлов курса, с предпросмотром. Правка появляется на сайте при следующем открытии страницы.
- Права админа выдаются в SQL Editor, см. `docs/admin.md`. Вкладки «Обзор» и «Группа» появятся в следующих версиях.

Перед выкладкой выполнить в Supabase `supabase/migrations/20261001120000_admin_core.sql`.

## 1.0.1 — 2026-10-01

- Публичные переменные окружения можно задавать и без приставки `NEXT_`: `PUBLIC_SITE_URL`, `PUBLIC_SUPABASE_URL`, `PUBLIC_SUPABASE_ANON_KEY`, `PUBLIC_YANDEX_CLIENT_ID`. Так они заведены на боевом сервисе. Раньше с такими именами сайт собирался без аккаунтов и без входа через Яндекс.

## 1.0.0 — 2026-10-01

Сайт переписан с нуля. Старый сайт на HTML, JavaScript и Express удалён.

### Обучение

- Настоящая Java в браузере вместо симулятора: компилятор ECJ в CheerpJ, программы запускаются с вводом, бесконечные циклы останавливаются.
- Контент — отдельные файлы в `content/quests`. `npm run content:check` проверяет каждый этап настоящим JDK.
- Этапы по единому шаблону:
  - теория с точным выводом;
  - грабли;
  - квиз;
  - три вопроса защиты;
  - три подсказки по шагам;
  - вкладка «Память».
- Ошибки компилятора объясняются по-русски.
- Два раздела:
  - **«Java с нуля»** — для всех, 16 квестов и 117 этапов: от первой программы через циклы, массивы, классы, наследование и интерфейсы, строки, исключения, коллекции, обобщения, лямбды и Stream API, файлы, алгоритмы и многопоточность до итогового проекта «Библиотека»;
  - **«Группа»** — по ссылке-приглашению: подготовка и контрольные точки КТ 1, КТ 2 и КТ 3, 22 задания по билетам.

### Игра и профиль

- Опыт, уровни до 999, 100 рангов, анимированные значки достижений, квесты дня, серия дней.
- Свои уровни и звания раздела «Группа».
- Аккаунты: регистрация с ником и паролем и 6-значным кодом из письма, вход по нику или почте, «Забыл пароль» по коду, вход через GitHub, Google и Яндекс. Синхронизация прогресса, старый прогресс из браузера переносится.
- Неоновый профиль, публичная страница `/u/ник`, лидерборд.

### Прочее

- Java прогревается заранее, пока студент на карте курса или в разделе «Группа»: этап открывается с уже готовым компилятором.
- AI-ментор отвечает потоком, с запасными моделями и лимитами.
- Справочник, доступность по WCAG (проверки axe), светлая и тёмная темы.
