# План курса Java-Zero

Курс делится на два раздела:

- **«Java с нуля»** (`/course`) — для всех. Порядок тем от первой программы до многопоточности и итогового проекта.
- **«Группа»** (`/group`) — контрольные точки (КТ) из вуза, только для одногруппников. Попасть туда можно по ссылке-приглашению.

Каждый квест — 5–10 этапов по шаблону из `content/README.md`: теория, грабли, квиз, три вопроса защиты, три подсказки, тесты.

## Правила

- Этап опирается только на то, что объяснили раньше. Если в задании нужна новая конструкция, её объясняют в теории этого этапа или добавляют этап перед ним.
- Квесты общего курса открываются по цепочке `unlockAfter`. КТ в эту цепочку не входят.
- id этапов после выкатки не меняются: по ним хранится прогресс. Новые этапы в пройденном квесте получают `isNew: true` (см. `content/README.md`).
- Звание за квест (`rank` в `quest.yaml`) — это титул. Его не путать с рангами уровня из `lib/game/ranks.ts`: названия не должны совпадать.
- Опыт: этап ≈ 70 XP, задание КТ ≈ 110 XP. Баланс кривой уровней проверяет `tests/unit/gamification.test.ts`.

## Раздел «Группа»

Одна цепочка: сначала вся подготовка к КТ, потом сама КТ, дальше следующая. Порядок задаёт `content/group.yaml`.

| Шаг | Подготовка (квесты общего курса) | КТ | Заданий |
|---|---|---|---|
| 1 | Фундамент Java, Циклы | КТ 1 (готова) | 6 |
| 2 | Массивы и таблицы | КТ 2 (готова) | 7 |
| 3 | Классы и объекты | КТ 3 — билет есть, вариант Animal | 9 |

Будущие КТ встают следующими шагами. Подготовка к ним берётся из квестов 05–15 общего курса по темам билета.

## Порядок работы

1. **Классы и объекты (04) + КТ 3**. Примеры — из лекций: `Cat barsik`, `Truck`, `TimeMachine`, `Proba`.
2. **Наследование (05)** — по лекции «Конструкторы базовых классов».
3. Дальше по таблице, по одному-два квеста за выкатку.

Каждый квест проходит `npm run content:check` на настоящем JDK и ручную проверку в браузере.

## Как добавить КТ, когда придёт билет

Подробно — в `content/README.md`, раздел «Как добавить КТ». Коротко:

1. Найти в общем курсе квесты, которые закрывают темы билета. Если какой-то темы нет, сначала добавить этап или квест в общий курс.
2. Создать `content/quests/ktN/`:
   - в `quest.yaml` указать `track: group`, `unlockAfter: null`, `stageBadge: "КТ N // ЗАДАНИЕ {n}"`, титул за КТ и файл `KTN.java`;
   - формулировки билета не менять.
3. Добавить шаг в `content/group.yaml`: `prep` — подготовительные квесты, `kt` — ktN.
4. Каждое задание — этап с блоком «Что повторить» (ссылки на этапы подготовки) и тестами.
   - Случайные данные проверяются через `match: regex`.
   - Данные с ввода — через `stdin`.
5. `npm run content:check`, юнит- и e2e-тесты, ручной проход.
