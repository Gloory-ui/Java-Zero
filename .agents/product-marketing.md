## Product Overview
**One-liner:** Java-Zero — тренажёр, на котором студент учит Java с нуля и готовится к контрольным точкам. Он пишет код, а настоящий компилятор проверяет его в браузере.
**What it does:** Курс разбит на квесты по темам вузовской программы. В каждом этапе есть теория, разбор типичных ошибок, квиз, задание в редакторе с автопроверкой и защита у «профессора» на время. AI-ментор объясняет ошибки компиляции и не пишет решение за студента.
**Product category:** интерактивный курс и тренажёр по Java для студентов (так ищут: «java для начинающих», «задачи на java с решениями», «подготовка к контрольной по java»).
**Product type:** веб-приложение, B2C.
**Business model:** бесплатно. ❓ Планы на монетизацию не обсуждались.

## Target Audience
**Target users:** студенты первого курса, у которых в программе Java, и новички, которые учат язык с нуля. ❓ Уточнить вуз и курс автора: задания КТ 1 взяты из его билетов.
**Primary use case:** подготовиться к контрольной точке и защите: решить задачи из билета и объяснить преподавателю, почему код работает.
**Jobs to be done:**
- Сдать КТ и защиту с первого раза.
- Понять, почему код не компилируется, не копируя готовый ответ.
- Набить руку на типовых задачах: циклы, условия, массивы, `Scanner`, рекурсия.
**Use cases:**
- Вечер перед КТ: прогнать все шесть заданий и вопросы защиты.
- Пара по программированию: разобрать пример с лекции в лаборатории.
- Самостоятельный старт без установки JDK и IDE.

## Problems & Pain Points
**Core problem:** на лекции показывают синтаксис, а на КТ спрашивают решение и объяснение. Между ними у студента нет практики с быстрой обратной связью.
**Why alternatives fall short:**
- IDE требует установить JDK, настроить проект и разобраться в интерфейсе до первой строчки кода.
- Нейросети выдают готовое решение: задание сдано, а на защите объяснить нечего.
- Платные курсы учат по своей программе, а не по билетам конкретного вуза.
**What it costs them:** пересдачу, потерянные баллы, вечера перед КТ без понимания.
**Emotional tension:** страх защиты («спросят, почему так, а я не знаю») и стыд перед одногруппниками.

## Competitive Landscape
**Direct:** JavaRush — геймифицированный курс Java на русском. Он платный, и его программа не совпадает с вузовскими КТ. ❓ Сверить цены и программу перед сравнением на сайте.
**Direct:** курсы по Java на Stepik — в основном лекции и тесты, мало игровой практики, нет подготовки к защите.
**Secondary:** учебник + IntelliJ IDEA — тяжёлый старт и нет проверки задач.
**Indirect:** ChatGPT и другие нейросети — решают за студента, и он не учится.

## Differentiation
**Key differentiators:**
- Задания повторяют билеты контрольных точек вуза.
- Настоящая компиляция и запуск Java в браузере без установки.
- Защита у «профессора» на время: вопросы с подвохом, как на экзамене.
- AI-ментор подсказывает, но по правилам не пишет готовое решение.
- Бесплатно и на русском.
**How we do it differently:** студент пишет код сам, компилятор находит ошибки, ментор объясняет их, а защита проверяет понимание.
**Why that's better:** студент приходит на КТ с решёнными задачами и умеет их объяснить.
**Why customers choose us:** ❓ пока нет отзывов; собрать после релиза.

## Objections
| Objection | Response |
|-----------|----------|
| «Это очередной тест с вариантами ответов» | Код компилирует и запускает настоящий компилятор Java. Тесты сверяют вывод программы, а не текст. |
| «Нейросеть сделает всё за меня» | Ментор объясняет ошибку и даёт намёк. Готовое решение открывается только после пяти своих попыток. |
| «Надо ставить Java» | Не надо: всё работает в браузере. Первая загрузка движка занимает до полминуты. |
| «Прогресс пропадёт» | С аккаунтом прогресс хранится в облаке и открывается с любого устройства. |

**Anti-persona:** опытные разработчики; те, кому нужен Spring, бэкенд или подготовка к собеседованию (пока).

## Switching Dynamics
**Push:** непонятные ошибки `javac`, страх защиты, нехватка практики.
**Pull:** быстрая проверка кода, задания из своих билетов, ранги и трофеи.
**Habit:** гуглить ответы и спрашивать нейросеть.
**Anxiety:** «задания не совпадут с моей программой», «сохранится ли прогресс», «не сложно ли начать».

**Words to avoid:** «революционный», «уникальный», «легко и просто», «без усилий», «в один клик», «погрузитесь», «откройте для себя» и другие штампы; обещания «выучишь Java за неделю».
**Glossary:**
| Term | Meaning |
|------|---------|
| Квест | Раздел курса по теме: «Фундамент Java», «Подготовка к КТ 1», «КТ 1», «Калькулятор» |
| Этап | Одна задача квеста: теория, грабли, квиз, код, защита |
| КТ | Контрольная точка — аттестация в вузе; квест «КТ 1» повторяет её билет |
| Защита | Дуэль с профессором Душновым: вопросы на время, HP профессора и нервы студента |
| Лаборатория | Экран с редактором, терминалом и вкладками этапа |
| Стрик | Серия сданных подряд этапов без ошибок |
| Шпора старосты | Одноразовая подсказка-алгоритм на этап, сбрасывает стрик |
| Ранг | Звание по прогрессу: от «Байт-падавана» до «Сеньора-кибердеда» |
