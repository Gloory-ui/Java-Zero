# API Java-Zero

Сервер (`server/server.js`) делает две вещи: раздаёт фронтенд из `client/` и проксирует запросы AI-ментора к Google Gemini. Ключ Gemini хранится только на сервере в `server/.env` и никогда не попадает в браузер.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт HTTP-сервера |
| `GEMINI_API_KEY` | — | ключ Google Gemini, без него AI-ментор отвечает ошибкой `503` |

## Маршруты

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/api/ai/analyze` | вопрос AI-ментору |
| `GET` | `/*` | статические файлы из `client/`, для остальных путей — `index.html` |

## POST /api/ai/analyze

Отправляет код студента и вопрос ментору, возвращает ответ в Markdown.

### Тело запроса (JSON)

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `userCode` | string | одно из двух | текущий код из редактора |
| `userMessage` | string | одно из двух | вопрос студента |
| `stageTitle` | string | нет | название квеста и этапа, например `"Калькулятор — Рекурсивный факториал n!"` |
| `compilerError` | string \| null | нет | текст ошибки компиляции |
| `failedTest` | string \| null | нет | название непройденного теста |
| `persona` | string | нет | характер ментора: `chill` (по умолчанию), `dushny`, `bigtech` |

Неизвестное значение `persona` заменяется на `chill`.

| `persona` | Характер | Температура |
|---|---|---|
| `chill` | Сеньор на чилле: простые аналогии, подбадривает | 0.4 |
| `dushny` | Душный профессор: придирается к стилю, ссылается на JLS | 0.2 |
| `bigtech` | Интервьюер в Бигтех: оценивает O(N) и расход памяти | 0.2 |

### Пример

```bash
curl -X POST http://localhost:3000/api/ai/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "stageTitle": "Фундамент Java — Оператор остатка % и деление",
    "userCode": "double r = 7 / 2;",
    "userMessage": "Почему получается 3.0, а не 3.5?",
    "persona": "chill"
  }'
```

### Ответы

| Код | Тело | Когда |
|---|---|---|
| `200` | `{ "reply": "<текст в Markdown>" }` | ментор ответил |
| `400` | `{ "error": "Код или сообщение отсутствуют." }` | нет ни `userCode`, ни `userMessage` |
| `429` | `{ "error": "Слишком много запросов к AI-ментору..." }` | превышен лимит запросов |
| `503` | `{ "error": "Серверы нейросети перегружены..." }` | ни одна модель не ответила |

### Как сервер выбирает модель

Модели перебираются по очереди, пока одна не ответит: `gemini-3.6-flash` → `gemini-2.5-flash` → `gemini-2.0-flash`. Длина ответа ограничена 600 токенами.

### Правила ментора

Системная инструкция запрещает писать готовое решение целиком: ментор указывает на ошибку и подсказывает, но строку кода студент дописывает сам. Ответ — на русском, до 150–200 слов.

### Лимит запросов

Не больше **20 запросов за 15 минут с одного IP**. Сервер возвращает стандартные заголовки `RateLimit-*`, по ним видно остаток лимита.
