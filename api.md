# API Java-Zero

Почти всё работает в браузере: страницы собираются заранее, Java компилируется и запускается в Web Worker, прогресс и профиль идут прямо в Supabase. На сервере остаётся один маршрут — AI-ментор. Ключ Gemini хранится только на сервере и в браузер не попадает.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `GEMINI_API_KEY` | ключ Google Gemini. Без него ментор отвечает `503` |
| `GEMINI_MODELS` | необязательно: порядок моделей через запятую. При перегрузке запрос уходит следующей модели |
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase: по токену входа ментор узнаёт пользователя и даёт ему лимит побольше |
| `NEXT_PUBLIC_SITE_URL` | адрес сайта для метаданных и ссылок |
| `SITE_INDEX` | `true` открывает сайт для поисковиков |

## POST /api/ai

Вопрос ментору по этапу. Условие задачи сервер берёт из `content/` по ключу этапа, а не из запроса.

### Тело запроса (JSON)

| Поле | Тип | Описание |
|---|---|---|
| `stageKey` | string | этап в виде `квест/этап`, например `kt2/min-all` |
| `message` | string | вопрос студента, непустой |
| `code` | string | код из редактора, до 20 000 символов |
| `persona` | string | характер ментора: `chill` (по умолчанию), `dushny`, `bigtech` |
| `compileErrors` | массив | до 20 ошибок компилятора: `{ line, message }` |
| `failedTests` | массив | до 10 непройденных тестов: `{ name, status?, message?, expected?, actual? }` |
| `history` | массив | до 8 прошлых реплик: `{ role: "user" \| "model", text }` |

Необязательный заголовок `Authorization: Bearer <токен Supabase>` — запрос считается от пользователя, а не от гостя.

### Ответ

`200`, `Content-Type: text/plain; charset=utf-8` — ответ ментора потоком, в Markdown. Клиент читает его по кускам и показывает по мере прихода.

Ошибки приходят в JSON: `{ "error": "текст для студента" }`.

| Код | Когда |
|---|---|
| `400` | тело не JSON, поля не прошли проверку или этап не найден |
| `429` | лимит вопросов: гость — 20, вошедший — 40 за 15 минут. Заголовок `Retry-After` — через сколько секунд можно снова |
| `503` | нет ключа Gemini или все модели перегружены |

### Характеры ментора

| `persona` | Характер |
|---|---|
| `chill` | Сеньор на чилле: простые аналогии, подбадривает |
| `dushny` | Душный профессор: придирается к стилю, ссылается на спецификацию |
| `bigtech` | Интервьюер в Бигтех: спрашивает про сложность и память |

Ментор объясняет ошибку и даёт намёк, но полное решение не пишет.
