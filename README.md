# ☕ Java-Zero — кибер-тренажёр Java
Изучение языка программирования Java с нуля

Интерактивный тренажёр: теория, задания с автопроверкой, симулятор защиты и AI-ментор.

## Страницы

| Страница | Что там |
|---|---|
| **Главная** (`index.html`) | карта курса с прогрессом по квестам, ранг и кнопка «Продолжить» |
| **Лаборатория** (`lab.html`) | теория, редактор, терминал, защита и AI-ментор |
| **Профиль** (`profile.html`) | текущий ранг, статистика, трофеи и табель о рангах |
| **Справочник** (`handbook.html`) | шпаргалка по темам курса: типы, деление, циклы, `switch`, массивы, `Scanner`, рекурсия |

## Возможности

- **Квесты и этапы** — курс разбит на квесты, каждый следующий открывается после сдачи предыдущего:
  1. `00` Фундамент Java — память, типы, переменные
  2. `01` Подготовка к КТ 1 — циклы `for`/`while`, `break`, флаги
  3. `КТ` Контрольная точка 1 — 6 аттестационных заданий
  4. `02` Калькулятор — `switch`, массивы, рекурсия
- **Редактор кода** — нумерация строк, автоскобки, шорткаты `sout` + Tab и `psvm` + Tab, форматирование.
- **Симулятор `javac`** — проверка синтаксиса и стресс-тесты этапа с логом в терминале и Diff при ошибке.
- **Интерактивный режим** — имитация `Scanner`: программа задаёт вопросы, ты отвечаешь в терминале.
- **Визуализатор памяти** — стек вызовов и куча JVM для каждого этапа.
- **Защита (босс-файт)** — вопросы на время, критический удар за быстрый ответ; ошибки снимают HP студента, итоговая оценка.
- **Трассировщик циклов** — после сдачи таблицы умножения анимирует порядок итераций `for i → for j`.
- **AI-ментор** на Gemini — три характера: «Сеньор на чилле», «Душный препод», «Интервьюер в Бигтех». Подсказывает, но не пишет решение целиком.
- **Ранги, стрик и ачивки** — прогресс хранится в `localStorage` браузера.

## Стек

| Часть | Технологии |
|---|---|
| Клиент | HTML, CSS, JavaScript (ES-модули, без фреймворков) |
| Сервер | Node.js, Express |
| AI | Google Gemini (`@google/genai`), лимит запросов `express-rate-limit` |

## Запуск

Нужен Node.js 18+ и API-ключ Gemini.

```bash
cd server
npm install
cp .env.example .env    # впиши свой GEMINI_API_KEY
npm start
```

Открой http://localhost:3000. Без ключа платформа работает, недоступен только AI-ментор.

## Структура

```
client/            фронтенд: 4 страницы, css/, js/
  js/quests.js     весь учебный контент: теория, задания, тесты
  js/app.js        лаборатория: точка входа и навигация по этапам
  js/site.js       общая шапка Главной, Профиля и Справочника
  js/progress.js   сводка прогресса по курсу
server/          Express: раздаёт client/ и проксирует запросы к Gemini
  routes/ai.js   POST /api/ai/analyze
```

Описание API — в [api.md](api.md).

## Как ведётся разработка

Проект следует **GitHub Flow**: `main` всегда рабочий, каждая задача делается в короткой ветке и вливается через merge.

- `feature/<что-делаем>` — новая функциональность
- `fix/<что-чиним>` — исправления

Версии нумеруются по **SemVer** (`MAJOR.MINOR.PATCH`), релизы отмечаются тегами, например `v0.2.0`.
