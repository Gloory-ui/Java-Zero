# ☕ Java-Zero — Java с нуля, шаг за шагом

Тренажёр по Java в браузере: теория короткими этапами, задания, которые проверяет настоящий компилятор Java, защита у профессора на время и AI-ментор, который подсказывает, но не решает за тебя.

Сайт: https://java-zero.onrender.com

## Разделы

- **«Java с нуля»** (`/course`) — курс для всех. Квесты открываются по порядку, от первой программы:
  1. Фундамент Java;
  2. Циклы;
  3. Калькулятор;
  4. Массивы и таблицы;
  5. Классы и объекты;
  6. Наследование и полиморфизм.
- **«Группа»** (`/group`) — контрольные точки из вуза для одногруппников. Раздел открывается по ссылке-приглашению. Путь строго по порядку: подготовка → КТ 1 → подготовка → КТ 2 → подготовка → КТ 3.

## Возможности

- **Настоящая Java в браузере.** Компилятор ECJ и запуск программ работают в CheerpJ, в Web Worker. Устанавливать JDK не нужно.
- **Тесты этапа.** Сравнивают вывод программы с ожидаемым, проверяют структуру кода, ошибки компилятора показывают по-русски.
- **Защита у профессора.** Вопросы на время, быстрый верный ответ бьёт критом, ошибки бьют по нервам студента.
- **AI-ментор на Gemini** с тремя характерами. Видит код и результат проверки, объясняет ошибку, но готовый код не пишет.
- **Игровой слой.** Опыт, уровни до 999 и 100 рангов, достижения со своими значками, квесты дня, серия дней. У раздела «Группа» свои уровни и звания.
- **Аккаунты.** Вход через Supabase: почта, GitHub, Google. Прогресс хранится в браузере и синхронизируется с аккаунтом. Есть публичный профиль, лидерборд и неоновое оформление профиля.

| Сайт | Next.js 16, React 19, TypeScript, Tailwind CSS 4, Motion |

## Запуск

Нужен Node.js 20.9+.

```bash
npm ci
cp .env.example .env.local    # ключи Supabase и Gemini, без них сайт работает, но без входа и ментора
npm run dev
```

Открой http://localhost:3000.

## Проверки

```bash
npm run check          # Biome, типы, юнит-тесты
npm run content:check  # каждый этап курса: эталон проходит тесты, стартовый код — нет. Нужен JDK 17+
npm run test:e2e       # Playwright на десктопе и телефоне
```

## Структура

```
app/                  страницы и маршрут /api/ai
components/           интерфейс: лаборатория, карта курса, профиль, игровой слой
lib/                  контент, прогресс, игра, Java-движок, AI, Supabase
content/quests/       курс: квест — папка, этап — папка с теорией, кодом и тестами
content/group.yaml    путь раздела «Группа» и код приглашения
java/, public/java/   драйвер компилятора и файлы движка для браузера
supabase/migrations/  схема базы
docs/                 план курса, настройка Supabase и деплой
```

Как добавить этап или новую КТ — в [content/README.md](content/README.md). Маршрут AI-ментора описан в [api.md](api.md).

## Как ведётся разработка

Проект следует **GitHub Flow**: `main` всегда рабочий, каждая задача делается в короткой ветке и вливается через merge.

- `feature/<что-делаем>` — новая функциональность
- `fix/<что-чиним>` — исправления

Версии нумеруются по **SemVer** (`MAJOR.MINOR.PATCH`), релизы отмечаются тегами, например `v1.0.0`. Что изменилось в каждой версии — в [CHANGELOG.md](CHANGELOG.md).
