➗ Деление и остаток

int a = 7 / 2;              // 3   — int / int отбрасывает дробную часть
double b = 7 / 2;           // 3.0 — сначала целое деление, потом перевод в double
double c = 7.0 / 2;         // 3.5 — хотя бы один операнд double
double d = (double) 7 / 2;  // 3.5 — явное приведение типа
int r = 7 % 2;              // 1   — остаток от деления
boolean even = n % 2 == 0;  // проверка на чётность
  • Целое деление на ноль (5 / 0) бросает ArithmeticException.
  • Вещественное деление на ноль (10.0 / 0) даёт Infinity — поэтому в калькуляторе нужна проверка b == 0.

🔁 Циклы for и while

for (int i = 1; i <= 10; i++) {  // 10 итераций: i = 1, 2, …, 10
    System.out.println(i);
}

int attempts = 0;
while (attempts < 3) {           // условие проверяется ДО каждой итерации
    attempts++;
}

for (int i = 1; i <= 50; i++) {
    if (i % 5 == 0) continue;     // пропустить остаток итерации
    if (i == 41) break;           // выйти из цикла совсем
    System.out.println(i);
}
  • Во вложенных циклах внутренний проходит целиком на каждой итерации внешнего — посмотри трассировку после сдачи таблицы умножения в КТ 1.

🔀 Выбор через switch

switch (op) {
    case '+':
        System.out.println(a + b);
        break;
    case '/':
        if (b == 0) {
            System.out.println("Ошибка: деление на ноль!");
        } else {
            System.out.println(a / b);
        }
        break;
    default:
        System.out.println("Неизвестная операция");
}
  • Без break выполнение «проваливается» в следующий case.

⌨️ Ввод с клавиатуры: Scanner

import java.util.Scanner;

Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
double x = sc.nextDouble();
String word = sc.next();          // одно слово до пробела
char op = sc.next().charAt(0);    // первый символ слова
  • На компьютере с русской локалью nextDouble() ждёт дробь через запятую: 3,5. Ввод 3.5 бросит InputMismatchException.
  • Чтобы вводить через точку: new Scanner(System.in).useLocale(Locale.US) и import java.util.Locale;.

🌀 Рекурсия

static long factorial(int n) {
    if (n <= 1) return 1;          // базовый случай — останавливает рекурсию
    return n * factorial(n - 1);   // рекурсивный шаг
}
  • Без базового случая вызовы не заканчиваются, и JVM бросает StackOverflowError.
  • long вмещает факториал только до 20! — дальше переполнение.
